## 想干什么，虾点一下

clawdot 虾点是 AI 时代的本地生活服务网络。

你只需要跟 Agent 说出你想要什么——"今晚想吃点清淡的"、"明天出差帮我安排一下"、"周末带孩子去个有意思的地方"——你的 Agent 理解你、记得你、帮你搞定一切。

服务者只需要把手艺做好。做了二十年湘菜的师傅不需要学会拍短视频，他的 Agent 会让好手艺自然触达需要它的人。

这张网不属于任何公司或组织。**虾点属于生活中的每一个人。**
