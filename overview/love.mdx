科技向善是 Clawdot 从第一天起就设立的价值基因。我们相信，AI Agent 不只服务于效率与便利，更应该让**每一个人都被看见、被照顾到**。

## 我们关心的

- **助老**：让不熟悉智能设备的长者，也能通过 Agent 轻松点一餐热饭、办一件小事。
- **助残**：为视障、行动不便的用户，把复杂的操作收敛成一句自然语言。
- **社区守望**：把本地生活服务织成一张互助网络，让邻里之间彼此照应。

## 我们的承诺

- 能力对所有 Agent 与开发者开放，不设歧视性门槛。
- 在设计每一个接口、每一条流程时，都把"不遗忘任何人"作为底线。

> 一个善意的网络，不遗忘任何人。
