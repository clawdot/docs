[Clawdot 开发者中心](https://hub.clawdot.net/#/account) 是你管理 API 接入的自助入口。本指南带你从注册账号开始，一步步创建 Agent、拿到 API Key、做一次测试绑定，再到管理渠道与升级档位。文档里其他页面提到的「控制台」链接，现在都指向这里。

登录后，左侧导航共七项：

| 页面 | 用途 |
| --- | --- |
| [**我的密钥**](https://hub.clawdot.net/#/account/keys) | 新建、轮换、删除 Agent；测试绑定；查看每个 Agent 已配置的渠道 |
| [**用量与配额**](https://hub.clawdot.net/#/account/usage) | 查看今日请求与订单、每分钟限流、最近 7 天用量 |
| [**直连内核**](https://hub.clawdot.net/#/account/direct) | 自己写代码直连时用的地址、绑定流、错误码与工具清单 |
| [**渠道**](https://hub.clawdot.net/#/account/channels) | 申请平台代办、录入自有渠道、指派或解除（superagent / platform 档专属） |
| [**档位升级**](https://hub.clawdot.net/#/account/upgrade) | 对比各档位、提交升级申请、查看进度 |
| [**问题反馈**](https://hub.clawdot.net/#/account/feedback) | 提交 Bug 或需求，查看处理进度 |
| [**账号设置**](https://hub.clawdot.net/#/account/settings) | 修改资料与登录密码 |

开发者中心首页（[账号概览](https://hub.clawdot.net/#/account)）展示你的名字、邮箱、公司、档位、邮箱验证状态与注册时间，并列出以上七个入口。

<Note>
  没登录时直接打开上面任何一个页面的链接，会在原地显示登录框，可以放心把链接当深链使用。
</Note>

## 1. 注册与登录

打开[开发者中心](https://hub.clawdot.net/#/account)，用邮箱注册：

1. 在 **注册** 页签填写 **邮箱**，点击 **发送验证码** 获取邮箱验证码。
2. 填写 **名字**、**公司**（选填）、**密码**（至少 6 位）和 **邮箱验证码**。
3. 点击 **注册**。

开发者中心用邮箱 + 密码登录，不支持 Google 一键登录。

<Note>
  注册成功后会自动为你创建一个默认 Agent，页面展示它的 Key，请当场复制保存。之后随时可以在 **我的密钥** 页取回或轮换这把 Key，见[第 3 节](#3-我的密钥)。
</Note>

已有账号则在 **登录** 页签用邮箱 + 密码登录。

**用 Google 注册的老账号**没有设置过密码：点击 **忘记密码**，填邮箱并点 **发送重置码**，再填 **重置码** 和 **新密码**，点 **重设密码**，然后用新密码登录即可。

原来的控制台仍然开放，同一个账号两边都能登录。

## 2. 用量与配额

[**用量与配额**](https://hub.clawdot.net/#/account/usage) 用于日常观察调用量与余量。页面上方是 **今日配额**：

- **今日请求 / 上限**：今日已用请求数 / 每日请求上限
- **今日订单 / 上限**：今日已下单数 / 每日订单上限
- **限流**：当前档位的每分钟请求上限
- **档位**：你当前所在的档位

下方 **最近 7 天** 表格逐日列出 **请求数**、**请求失败数（HTTP）** 和 **平均耗时**。

<Note>
  **请求失败数（HTTP）** 只统计 HTTP 状态码 ≥ 400 的请求，不含 MCP 工具调用的业务报错（这类报错 HTTP 仍是 200）。
</Note>

超出限流或配额时，当次调用会被拒绝并返回 `RATE_LIMITED`，已经提交成功的订单不受影响。接近上限时，建议提前到 **档位升级** 申请，避免触顶被限流。配额上限由档位决定，详见[第 6 节](#6-账号设置与档位升级)。

## 3. 我的密钥

在这里创建 Agent、管理 API Key。一个 **Agent** 对应你的一个接入方（一个应用、一个机器人、一条业务线），每个 Agent 持有独立的 API Key。可创建数量由档位决定。

[**我的密钥**](https://hub.clawdot.net/#/account/keys) 列出你名下所有 Agent。每个 Agent 一块卡片，展示名称、描述、Agent ID、创建日期、已开通的能力标签，以及 Key。

### 3.1 创建 Agent

<Steps>
  <Step title="点击新建 Agent">
    在页面右上角点击 **新建 Agent**。
  </Step>
  <Step title="填写名称">
    在输入框里给这个 Agent 起个名字，点击 **创建**。
  </Step>
  <Step title="保存 API Key">
    创建成功后，页面展示 **新 Agent 的 Key**，请当场复制保存；之后也可以在卡片上点 **显示** / **复制** 取回。
  </Step>
</Steps>

### 3.2 卡片上的日常操作

| 操作 | 说明 |
| --- | --- |
| **显示 / 隐藏** | 切换 Key 是否以明文展示，未展示时只显示前缀。明文由服务端返回，随时可看。 |
| **复制** | 复制完整 Key，随时可复制。 |
| **轮换** | 生成新 Key 并**立即作废旧 Key**。会先出现二次确认，点 **确认轮换** 后执行；执行前请确认线上服务已准备好换 Key，避免调用中断。新 Key 生成后直接显示，之后同样可以点 **显示** / **复制** 取回。 |
| **删除** | 删除该 Agent。Key 立即失效，它的用户授权与渠道指派一并解除，**不可恢复**，会先出现二次确认，点 **确认删除** 后执行。 |
| **测试绑定** | 用自己的手机号拿一枚用户授权凭证（见 3.3）。 |

<Note>
  只有早期创建的少数 Key 取不到明文：点 **显示** 后会看到「服务端未回明文，轮换后可见」，点 **轮换** 换一把新的即可。
</Note>

### 3.3 测试绑定

Agent 代表用户下单前，需要先拿到该用户的授权凭证（Consent Grant ID）。**测试绑定** 让你用**自己的手机号**走一遍这个流程，拿到一枚凭证用来联调。点击卡片上的 **测试绑定**，在右侧抽屉里操作：

<Steps>
  <Step title="选链路、输入手机号">
    在 **绑定链路** 里选 **外卖链路** 或 **跑腿链路**，填写你自己的 11 位手机号，点击 **发送验证码**。
  </Step>
  <Step title="输入验证码">
    填入收到的 6 位短信验证码（5 分钟内有效），点击 **验证并拿凭证**。60 秒后可点 **重新发送**，也可点 **换个号码** 返回上一步。
  </Step>
  <Step title="保存用户授权凭证">
    绑定成功后，抽屉里展示 **用户授权凭证**，并注明有效期。调用业务工具时把它作为 `consent_grant_id` 参数传入，即代表以该用户身份操作，详见[认证机制](/gateway/authentication)。
  </Step>
</Steps>

<Warning>
  **用户授权凭证只显示一次**，服务端只存哈希，关闭抽屉后取不回来，请立即复制保存。再绑一次会签发新凭证，**旧的随即失效**，请以最新一次为准，并同步更新你的服务配置。
</Warning>

每个 Agent 能授权的用户数按档位计算，免费版是 1 个，见[第 6 节](#6-账号设置与档位升级)。

测试绑定只用来联调。为你的真实终端用户拿授权，要在自己的服务里调用绑定工具，流程见[认证机制](/gateway/authentication)；自己写代码直连时，也可以看 [**直连内核**](https://hub.clawdot.net/#/account/direct) 页的绑定流说明。

Agent 已经有人绑定后，卡片上会出现「已授权 N 个用户」，并按外卖、跑腿分别计数。点击它打开 **已授权用户** 抽屉：可以按 **全部 / 外卖 / 跑腿** 切换，也可以在搜索框里输入手机号（输尾号即可）过滤，手机号均以掩码显示。

### 3.4 查看 Agent 的已配置渠道

如果你的档位开放了渠道功能，Agent 卡片下方会多出一行 **渠道**，只读列出该 Agent 已配置的渠道：渠道编号、来源、打码的密钥和状态。没配渠道时，这一行会提示订单走平台默认渠道、不算到你名下。非渠道档不显示这一行。

这一行只用来看，渠道的录入、指派和解除都在 **渠道** 页，见[第 5 节](#5-渠道池)。

## 4. 渠道之前：先看档位能力

在使用渠道功能之前，先了解一下不同档位能做什么。渠道功能仅对 SUPERAGENT 与 PLATFORM 开放。档位详情见[第 6 节](#6-账号设置与档位升级)。

## 5. 渠道池

<Note>
  非 superagent / platform 档打开 [**渠道**](https://hub.clawdot.net/#/account/channels) 页，会看到「渠道要升级后才能用」的说明，页面上有申请升级的入口。
</Note>

渠道决定订单算在谁名下。**渠道池是账户级的**：一条渠道验证通过后，可以指派给你名下的 Agent。一个 Agent 同一时间只用一条渠道；没指派时走平台默认渠道，订单不算到你名下。目前渠道只作用于外卖链路。获得渠道有两条路径。

### 5.1 已有外卖平台渠道：录入渠道

如果你已经拿到自己的渠道凭证，点击页面右上角的 **录入渠道** 直接录入：

| 字段 | 说明 |
| --- | --- |
| 渠道编号（必填） | 形如 `mobile.xxxx` |
| 签名密钥（必填） | 渠道方下发的签名密钥；**加密保存，提交后不再显示** |
| 登录标识（选填） | 不带 `mobile.` 前缀的来源标识 |
| 支付码（选填） | 接三方收银时才需要 |
| 备注名（选填） | 方便自己识别 |

点击 **提交入池** 后，渠道进入「**待验证**」状态。平台核验凭证有效后转为「**已验证**」，才能指派给 Agent，避免错误凭证导致订单归因错误。

### 5.2 还没有渠道：申请代办

没有渠道也可以点击 **申请代办**，由平台代你去办：

<Steps>
  <Step title="填写基本信息">
    填写 **渠道平台名称** 和 **合作方 logo 地址**（都是必填；logo 地址以 `http://` 或 `https://` 开头，建议 200×200 像素）。
  </Step>
  <Step title="（可选）接入三方收银">
    需要接入三方收银台时，勾选 **同时接入三方收银**，补充展开的六项信息（都是必填）：三方测试支付接口、三方生产支付接口、三方 RSA2 公钥、客服电话、代扣 PID、代扣账号。
  </Step>
  <Step title="提交并跟踪进度">
    点击 **提交申请**。页面下方的 **代办申请** 表格跟踪进度：**处理中**（平台正在办理）、**已办好**（渠道已自动进入渠道列表，直接指派即可）、**未通过**（同一行会显示未通过的原因）。
  </Step>
</Steps>

### 5.3 渠道列表与指派

渠道列表按 **全部 / 已验证 / 待验证 / 已停用** 分组，每行展示渠道名、渠道编号、状态和正在使用它的 Agent。

- **指派**：仅已验证的渠道可用。点击后在抽屉里选一个 Agent，点 **确认指派**。下一次调用起生效，该 Agent 原来在用的渠道自动解除。
- **详情**：查看渠道编号、登录标识、支付码、录入时间和正在使用它的 Agent。签名密钥只显示「已保存，不再显示」。点某个 Agent 旁的 **解除指派**，它就回到平台默认渠道。

## 6. 账号设置与档位升级

### 6.1 账号设置

[**账号设置**](https://hub.clawdot.net/#/account/settings) 分两块。

**资料**：修改 **名字**（必填）与 **公司**（选填）后点击 **保存资料**。邮箱是登录账号，不能修改；要换邮箱，请到 **问题反馈** 告诉我们。

**登录密码**：填写 **当前密码**、**新密码**（至少 6 位）并再输一次，点击 **修改密码**，下次登录用新密码。

### 6.2 档位

[**档位升级**](https://hub.clawdot.net/#/account/upgrade) 页用表格对比四个档位，你当前所在的档位带 **当前** 标记：

| 档位 | Agent 数 | 每分钟请求 | 每日请求 | 每日订单 | 每个 Agent 授权人数 |
| --- | --- | --- | --- | --- | --- |
| 免费版（FREE） | 3 | 30 次 | 1K | 10 | 1 |
| 专业版（PRO） | 3 | 120 次 | 50K | 500 | 10 |
| 超级 Agent（SUPERAGENT） | 100 | 600 次 | 500K | 5K | 1 万 |
| 平台版（PLATFORM） | 不限 | 600 次 | 500K | 5K | 10 万 |

渠道功能仅对超级 Agent 与平台版开放。

### 6.3 申请升级

<Steps>
  <Step title="点击申请升级">
    在 **档位升级** 页的档位表里，高于当前档位的一列点击 **申请升级**（只能向上申请）。
  </Step>
  <Step title="填写申请信息">
    填写 **用途**（必填）、**预估量**（必填，如「日请求 30 万 / 日订单 3000」）、**联系方式**（选填，便于沟通），点击 **提交申请**。
  </Step>
  <Step title="等待审核">
    同一时间只能有一个处理中的申请，此时其他档位会显示「已有申请在处理」。页面下方的 **申请记录** 展示每次申请的状态：**处理中**、**已通过**、**未通过**（会写明驳回理由）。审核通过后立即生效。
  </Step>
</Steps>

## 7. 问题反馈

遇到 Bug 或想要新能力，到 [**问题反馈**](https://hub.clawdot.net/#/account/feedback) 提交。先切换 **Bug 反馈** 或 **需求反馈**，再填标题和描述（必填），紧急程度、涉及模块和联系方式按需选择。Bug 反馈可以补充复现步骤和期望结果，需求反馈可以补充期望价值。

提交后，在页面下方的 **我的反馈** 里查看处理进度：**待处理**、**处理中**、**已解决**、**已关闭**。

## 8. 直连内核

[**直连内核**](https://hub.clawdot.net/#/account/direct) 面向自己写代码直连的开发者：按能力列出 MCP 地址与鉴权方式，并附绑定流、错误码分流和完整工具清单。用不到直连的话，可以不看这一页。

## 常见问题

<AccordionGroup>
  <Accordion title="API Key 忘记保存了怎么办？">
    到 **我的密钥** 页找到对应 Agent，点 **显示** 或 **复制** 即可取回完整 Key，无需轮换。只有早期创建、页面提示「服务端未回明文，轮换后可见」的 Key，才需要点 **轮换** 换一把新的（会立即作废旧 Key，请先做好服务切换准备）。
  </Accordion>
  <Accordion title="我是 Google 注册的老账号，登录提示邮箱或密码不对？">
    Google 注册的账号没有设置过密码。在登录框点 **忘记密码**，用注册邮箱收重置码并设一个新密码，之后用邮箱 + 新密码登录。
  </Accordion>
  <Accordion title="用户授权凭证丢了怎么办？">
    重新做一次 **测试绑定**（或为该用户重走绑定流程）即可拿到新凭证；旧凭证会随之失效，记得同步更新到你的服务。
  </Accordion>
  <Accordion title="为什么我用不了渠道功能？">
    渠道仅对 SUPERAGENT / PLATFORM 档开放。到 **档位升级** 页申请升级。
  </Accordion>
  <Accordion title="渠道录入后为什么不能立刻指派？">
    新录入的渠道需平台先验证凭证有效性（「待验证」→「已验证」），验证通过后才能指派，避免错误凭证导致订单归因错误。
  </Accordion>
  <Accordion title="配额不够用了怎么办？">
    到 **用量与配额** 页看今日余量。接近上限时，建议提前到 **档位升级** 申请升级，避免触顶后请求被限流。
  </Accordion>
</AccordionGroup>
