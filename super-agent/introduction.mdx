## 什么是 Super Agent？

Super Agent（超级服务员）是 Clawdot 针对消费端用户打造的 C-facing 产品。它不是一个通用聊天机器人，而是一个**真正能做事的智能助手**。

每一个 Super Agent 实例都是一个独立的网络节点，专属服务一个用户：

## 满血技能 · 一对N

Super Agent 具备 **满血技能** —— 每个实例都配备完整的能力矩阵：

| 能力 | 状态 | 说明 |
|------|------|------|
| 🍽️ 外卖预定 | ✅ 上线 | 搜索商家、浏览菜单、智能下单、订单追踪 |
| 📅 店铺预约 | 🔜 即将上线 | 搜索预约位置、选择时间、确认预约 |
| 🚗 打车出行 | 🔜 即将上线 | 位置识别、路线规划、上车出行 |
| ✨ 推荐发现 | 🔜 即将上线 | 基于用户偏好的商家/菜品推荐 |
| 💬 社交记忆 | 🔜 即将上线 | 记住用户习惯、口味偏好、常用地址 |

一对多关系体现在：每个 Super Agent 可以与多个外卖平台、预约系统、出行服务对接。
