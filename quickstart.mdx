Clawdot Gateway 把外卖能力以统一接口开放给 AI Agent。本指南带你从零跑通一次完整下单。

- **REST API**（本指南主线）：`http://eleme-gateway.hicaspian.com/api/v1`
- **MCP**（工具调用）：`http://eleme-gateway.hicaspian.com/mcp/v1`（每步附对应工具名）

<Note>
  两层身份：**API Key**（`clw_` 前缀）标识你的 Agent，所有请求都要带；**consent grant**（`cg_` 前缀）标识已授权的外卖用户，操作用户资源的请求要带。详见 [认证机制](/gateway/authentication)。
</Note>

## 前置：拿到 API Key

在 [Clawdot Portal](http://console.hicaspian.com/agents) 创建 Agent、开通外卖能力，得到 API Key。之后每个请求都带：

```
Authorization: Bearer clw_your_api_key
```

<Steps>
<Step title="绑定用户授权">
下单要代表一个真实外卖用户，先让 ta 授权（SMS 验证码模式）。

```bash
# 1) 发起绑定 → 拿 bind_id，用户收到验证码
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/auth/bind/request" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"phone": "18800000000", "auth_type": "sms"}'

# 2) 用户告知验证码后确认 → 拿 consent_grant_id
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/auth/bind/verify" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"auth_type": "sms", "bind_id": "<上一步的 bind_id>", "code": "123456"}'
# → { "consent_grant_id": "cg_...", "scopes": ["taobao_flash.delivery"], "expires_at": "..." }
```

拿到 `consent_grant_id` 后，下面每个请求都带 `X-Consent-Grant-Id: cg_...`。

<Note>MCP：对应工具 `request_user_bind` / `verify_user_bind`；`consent_grant_id` 之后作为各工具参数传入（不走请求头）。也支持 H5 模式（`auth_type: "h5"` 返回授权链接），见 [发起绑定](/api-reference/user/bind-request)。</Note>
</Step>

<Step title="搜索店铺">
```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/shops/search" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{"keyword": "瑞幸咖啡", "lat": 31.23, "lng": 121.47}'
# → { "shops": [ { "shop_id": "...", "cart_id": "...", "name": "...", ... } ] }
```

每个店铺带 `shop_id` 和 `cart_id`（`cart_id` 已封装店铺与配送坐标，后续步骤原样回传）。

<Note>MCP：`search_shops`</Note>
</Step>

<Step title="查看菜单、选商品">
```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/shops/menu" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{"shop_id": "<来自搜索>", "cart_id": "<来自搜索>"}'
# → items[]：每项含 item_id / sku_id / ingredient_options ...
```

记下要买的 `item_id` 和 `sku_id`。

<Note>MCP：`get_shop_menu`</Note>
</Step>

<Step title="确定收货地址">
```bash
# 搜地址 → 拿 suggestion token
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/addresses/search" \
  -H "Authorization: Bearer clw_your_api_key" -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" -d '{"keyword": "上海市黄浦区人民广场"}'
# → suggestions[].token

# 保存地址 → 拿 address_id
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/addresses/select" \
  -H "Authorization: Bearer clw_your_api_key" -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{"suggestion_token": "<上一步 token>", "contact_name": "张三", "contact_phone": "18800000000"}'
# → { "address_id": "...", ... }
```

<Note>MCP：`search_addresses` / `select_address`</Note>
</Step>

<Step title="算价（购物车报价）">
```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/cart/quote" \
  -H "Authorization: Bearer clw_your_api_key" -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "shop_id": "<来自搜索>", "cart_id": "<来自搜索>", "address_id": "<来自选址>",
    "items": [{"item_id": "<来自菜单>", "sku_id": "<来自菜单>", "quantity": 1}]
  }'
# → { "quote_id": "...", "payable_price": 1500, ... }
```

<Warning>所有金额字段单位为**分（整数）**，`1500` 表示 ¥15.00。</Warning>
<Note>MCP：`quote_cart`</Note>
</Step>

<Step title="预览订单">
```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/orders/preview" \
  -H "Authorization: Bearer clw_your_api_key" -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "shop_id": "<来自搜索>", "cart_id": "<来自搜索>", "address_id": "<来自选址>",
    "items": [{"item_id": "<来自菜单>", "sku_id": "<来自菜单>", "quantity": 1}]
  }'
# → { "preview_id": "prv_...", "confirmation_token": "cf_...", "price": {...}, ... }
```

<Note>MCP：`preview_order`</Note>
</Step>

<Step title="正式下单">
用预览返回的 `preview_id` + `confirmation_token`：

```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/orders/create" \
  -H "Authorization: Bearer clw_your_api_key" -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{"preview_id": "prv_...", "confirmation_token": "cf_..."}'
# → { "order_id": "ord_...", "status": "pending_payment", "payment_action": {...} }
```

<Note>MCP：`create_order`</Note>
</Step>

<Step title="支付签约 + 查询订单">
首次下单需用户完成免密支付签约（返回 H5 链接交给用户完成）；之后可随时查订单状态。

```bash
# 发起免密签约
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/payment/sign-action" \
  -H "Authorization: Bearer clw_your_api_key" -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" -d '{"return_url": "https://your-app.example.com/done"}'

# 查询订单状态
curl "http://eleme-gateway.hicaspian.com/api/v1/orders/ord_..." \
  -H "Authorization: Bearer clw_your_api_key" -H "X-Consent-Grant-Id: cg_your_consent_grant"
```

<Note>MCP：`get_sign_action` / `get_order_status` / `get_sign_status`</Note>
</Step>
</Steps>

## 完整链路一览

`search_shops`（得 shop_id + cart_id）→ `get_shop_menu`（得 item_id / sku_id）→ `quote_cart`（得 quote_id）→ `select_address`（得 address_id）→ `preview_order`（得 preview_id + confirmation_token）→ `create_order`（得 order_id）→ `get_sign_action`（免密签约）

所有跨步骤的 ID（`shop_id` / `cart_id` / `address_id` / `preview_id` …）都由网关签发、**原样回传**，不要自行构造。
