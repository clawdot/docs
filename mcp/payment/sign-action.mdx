## get_sign_action

为当前授权用户发起免密支付签约：网关先查询用户签约状态，未签约则向上游申请签约地址，并签发一个用于打开签约 H5 页的 `action`。已签约的用户不会返回签约链接。

<Note>
  **签约链路**：先调用本工具拿到 `action`；若 `action.action_type` 为 `open_h5`，把用户引导到 `action.action_url`（H5 签约页）完成签约，签约完成后浏览器跳回你传入的 `return_url`。随后用 `get_sign_status` 轮询签约结果。若 `action.action_type` 为 `none`，说明用户已签约，无需再打开页面。免密签约是发起免密支付类订单的前置条件。
</Note>

### 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `consent_grant_id` | string | 是 | — | 用户授权 ID（`cg_` 前缀，来自 `verify_user_bind`），标识已授权用户 |
| `return_url` | string | 是 | — | 用户在 H5 签约页完成签约后浏览器跳回的地址，由调用方提供；网关原样透传给上游签约页 |

### 返回

```json
{
  "action": {
    "action_id": "act_7c1d...",
    "action_type": "open_h5",
    "action_url": "https://render.alipay.com/p/s/...",
    "expires_at": "2026-06-16T08:30:00+00:00"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `action` | object | 待执行动作对象 |
| `action.action_id` | string | 动作 ID（`act_` 前缀），网关签发，用于追踪该动作 |
| `action.action_type` | string | `open_h5`（需打开 `action_url` 完成签约）或 `none`（用户已签约，无需任何操作）|
| `action.action_url` | string \| null | 签约 H5 页地址；`action_type` 为 `none` 时为 `null`，应原样在浏览器/WebView 打开，不要改写 |
| `action.expires_at` | string | 动作过期时间（ISO 8601，UTC）；有效期 30 分钟，过期后需重新发起 |

### 错误码

| code | 说明 |
|------|------|
| `CONSENT_GRANT_REQUIRED` | 缺少用户授权（未传 `consent_grant_id`）|
| `CONSENT_GRANT_INVALID` | 用户授权无效 |
| `CONSENT_GRANT_EXPIRED` | 用户授权已过期，需重新授权 |
| `CAP_NOT_BOUND` | 该 Agent 未开通该能力 |
| `CONSENT_GRANT_WRONG_CAP` | 授权属于其它能力 / 服务商 |
| `SIGN_ADDRESS_NOT_FOUND` | 上游响应未返回签约地址 |
| `ELEME_ERROR` | 淘宝闪购 / 饿了么上游 API 错误 |
| `PROVIDER_NOT_AVAILABLE` | 服务商适配器暂不可用 |

完整错误码见 [错误处理](/gateway/error-handling)。

### 调用示例

```json
{
  "name": "get_sign_action",
  "arguments": {
    "consent_grant_id": "cg_your_consent_grant",
    "return_url": "https://your-app.example.com/sign/callback"
  }
}
```
