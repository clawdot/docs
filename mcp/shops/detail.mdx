## get_shop_menu

拉取一个店铺的菜单。返回的每个菜单项带网关生成的 `item_id`（及可选 `sku_id` / `option_id`），这些 ID 是后续 `quote_cart`、`preview_order`、`create_order` 唯一可用的下单凭据。菜单可能很大（100+ 项），支持 `keyword` 过滤与 `limit` / `offset` 分页（渐进式披露）。

<Note>
  **下单链路**：`search_shops` 得 `shop_id` + `cart_id`（已含配送坐标）→ **`get_shop_menu`** 选商品得 `item_id` / `sku_id` → `quote_cart` 算价得 `quote_id` → `select_address` 得 `address_id` → `preview_order` 得 `preview_id` + `confirmation_token` → `create_order`。菜单必须基于一个已存在的 `cart_id`，且 `shop_id` 必须与该 `cart_id` 匹配（同一次 `search_shops` 返回）。
</Note>

### 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `consent_grant_id` | string | 是 | — | 用户授权 ID（`cg_` 前缀，来自 `verify_user_bind`），标识已授权用户 |
| `shop_id` | string | 是 | — | 店铺 ID（来自 `search_shops`），原样回传 |
| `cart_id` | string | 是 | — | 购物车上下文 ID（来自 `search_shops`，已封装店铺与配送坐标）|
| `address_id` | string \| null | 否 | `null` | 网关地址 ID（来自 `select_address`）；提供后用其坐标解析配送位置 |
| `lat` | float \| null | 否 | `null` | 配送位置纬度；不传则回退到 `cart_id` 内已封装的坐标 |
| `lng` | float \| null | 否 | `null` | 配送位置经度；不传则回退到 `cart_id` 内已封装的坐标 |
| `keyword` | string \| null | 否 | `null` | 关键词过滤，按商品名 / 分类名 / 描述匹配（大小写不敏感）|
| `limit` | integer \| null | 否 | `null` | 本页返回数量，≥ 1；不传则返回（过滤后的）全部 |
| `offset` | integer | 否 | `0` | 分页偏移，≥ 0；与上一次响应的 `next_offset` 配合翻页 |
| `full_menu` | boolean | 否 | `false` | 菜单大纲模式：`true` 时一次返回全部分类的全部商品卡片，**不含规格 / 配料且不可直接下单**（见下方说明）；显式传 `keyword` / `limit` / `offset` 时优先于本参数 |
| `grouped` | boolean | 否 | `false` | 配料是否按组返回。`false` / 不传：配料平铺在 `ingredient_options` 里，每条自带 `group_name`；`true`：改为按组返回 `ingredient_groups`，组信息只出现一次 |

<Note>
  `address_id` / `lat` / `lng` 三者用于解析配送坐标，通常无需传：`cart_id` 已封装搜索时的坐标。三者同时不传时使用 `cart_id` 内坐标。
</Note>

<Note>
  **菜单大纲（`full_menu=true`）**：一次返回**全部分类的全部商品卡片**（`item_id` / `name` / `price` / `available` / `image_url` 及营销字段），**`sku_options` / `ingredient_options` 恒为空数组**——适合大菜单先速览全貌（不逐品拉规格，响应快）。大纲商品的 `item_id` 稳定（同一 `cart_id` 内与富化后相同），但**不可直接下单**：大纲 id 未写入购物车，直接传给 `quote_cart` / `preview_order` / `create_order` 会报 `PUBLIC_REFERENCE_INVALID`。要下单先富化目标商品——再调 `get_shop_menu`（用 `keyword` / `limit` 定位该商品）或用 [`get_item_options`](/mcp/shops/item-options) 按需批量拉取规格，随后用同一 `item_id` 下单。显式传 `keyword` / `limit` / `offset` 任一时**优先于 `full_menu`**：即便 `full_menu=true` 也按富化分页返回。
</Note>

### 返回

<Warning>
  所有金额字段（`price` / `original_price` / `price_delta`）单位为**分（整数）**，不是元。例如 `price: 1600` 表示 ¥16.00。
</Warning>

<Note>
  **配料按规格区分。** 配料与具体规格（SKU）绑定——不同杯型可选的配料及其内部标识可能不同。顶层 `items[].ingredient_options` 对应**默认规格**；选其他规格时请使用该规格 `items[].sku_options[].ingredient_options` 里的 `option_id`。若沿用默认规格的 `option_id` 下非默认规格，网关会按「组名 + 选项名」自动映射到该规格的对应配料；该规格不存在的配料会在 `quote_cart` / `preview_order` 阶段报错（而非到 `create_order` 才失败）。
</Note>

<Note>
  **店铺级必选商品组。** 部分店铺（麻辣烫、部分套餐店）要求整单必须包含某类商品——如麻辣烫的「必选好汤」，不选汤底上游会拒单。这类约束通过 `required_groups` 暴露：下单前须从每个 `required_groups[].candidate_item_ids` 里至少选 `min_select` 个商品，作为普通条目加入 `items[]`（候选详情直接看 `required_groups[].candidates`——含 name/price/available、始终完整；带 `keyword` 或分页拉菜单时必选候选可能不在当前页 `items[]` 中）。未选满时 `quote_cart` 返回 `can_checkout=false` + `blocking_reason`，`preview_order` 直接报 `MISSING_REQUIRED_SELECTION`（HTTP 400）。这与商品内的**配料必选组**（`ingredient_options` 里的必选做法组，如奶茶必选温度 / 糖度）是两个层次：前者是「必须再点一个商品」，后者是「某商品内部必须选够做法」。
</Note>

| 字段 | 类型 | 说明 |
|------|------|------|
| `shop.shop_id` | string | 店铺 ID（原样回传请求中的 `shop_id`）|
| `shop.cart_id` | string | 购物车上下文 ID（原样回传请求中的 `cart_id`）|
| `shop.name` | string | 店铺名称 |
| `shop.logo_url` | string \| null | 店铺 logo URL，与 `search_shops` 的 `shops[].logo_url` 同源（菜单上游不返回 logo，值取自搜索时随 `cart_id` 保存的上下文）；本字段上线前获取的 `cart_id` 返回 `null` |
| `shop.min_order_amount` | integer \| null | 起送价（**分**），与 `search_shops` 的 `shops[].min_order_amount` 同值（菜单上游不返回起送价，值取自搜索时随 `cart_id` 保存的快照），下单前可据此提示用户凑单；本字段上线前获取的 `cart_id` 返回 `null` |
| `shop.lat` | number \| null | 店铺纬度，与请求 `lat` / `lng` 同坐标系（高德 GCJ-02），可与配送定位直接比较 / 同图展示；取自菜单上游 `shopDetails` 的店铺坐标（`search_shops` 不返回店铺坐标，故最早在 `get_shop_menu` 才有值），本字段上线前获取的 `cart_id` 或上游未返回坐标时为 `null` |
| `shop.lng` | number \| null | 店铺经度，其余同 `shop.lat` |
| `shop.available` | boolean | 店铺是否可下单（当前恒为 `true`）|
| `categories` | array | 本页商品按分类的轻量索引 |
| `categories[].name` | string | 分类名 |
| `categories[].items` | array | 该分类下的商品，带卡片四要素：`item_id`/`name`/`price`/`available`/`image_url`——客户端可直接用 categories 渲染分类导航+卡片页，规格从本响应 `items[]` 按 `item_id` 查 |
| `categories[].required` | boolean | 该分类是否为店铺级必选组（仅必选分类返回）|
| `categories[].min_select` | integer | 必选分类至少需选的商品数（仅必选分类返回）|
| `items` | array | 本页完整商品列表（见下）；`full_menu=true` 时为全量商品卡片（`sku_options` / `ingredient_options` 为空数组、不可直接下单）|
| `items[].item_id` | string | 商品 ID（`item_`），**下单必需**；传给 `quote_cart`、`preview_order` 的 `items[].item_id` |
| `items[].name` | string | 商品名 |
| `items[].category_name` | string \| null | 所属分类名 |
| `items[].description` | string \| null | 商品描述 |
| `items[].image_url` | string \| null | 商品图片 URL |
| `items[].price` | integer | 当前价（分）|
| `items[].original_price` | integer \| null | 原价（分）；无折扣时为 `null` |
| `items[].tip_texts` | array | 营销展示文案（上游现成文案，如 `["月售 1000+", "好评率 100%"]`）；无则为 `[]`。仅供展示，不是下单入参 |
| `items[].promo_labels` | array | 折扣/促销标签，主副结构；无则为 `[]`。也可能出现配送限制标签（如「单点不送」＝该商品不可单独下单，建议加购时提示搭配正常商品，否则 `quote_cart` 会返回 `blocking_code=1`）|
| `items[].promo_labels[].text` | string | 主标签文案（如「66折」）|
| `items[].promo_labels[].sub_texts` | array | 副标签文案列表（如 `["限3份"]`）|
| `items[].recommend_reasons` | array | 推荐理由文案（如 `["7天内15人下单"]`）；无则为 `[]`。仅供展示 |
| `items[].available` | boolean | 是否有货 |
| `items[].unavailable_reason` | string \| null | 不可用原因；售罄时为 `"sold_out"`，否则 `null` |
| `items[].min_purchase` | integer | 起购份数，≥ 1；`1` 表示无起购约束。`quantity` 低于它时 `quote_cart` 返回 `can_checkout=false`，`preview_order` 报 `BELOW_MIN_PURCHASE` |
| `items[].available_quantity` | integer \| null | 库存余量（份）：正整数=当前剩余可购份数，`0` 售罄，`null` 库存充足或未知。**菜单快照、仅供展示参考**，实际可购以下单时校验为准（超库存会在 `quote_cart` / `preview_order` 阶段被拦截） |
| `items[].sku_options` | array | 规格选项（如杯型）；下单时在 `items[].sku_id` 传所选 `sku_id` |
| `items[].sku_options[].sku_id` | string | SKU ID（`sku_`），原样回传到下单的 `sku_id` |
| `items[].sku_options[].name` | string | 规格名（如「大杯」）|
| `items[].sku_options[].price` | integer | 该规格价（折后现价，分）|
| `items[].sku_options[].original_price` | integer \| null | 该规格划线原价（优惠前，分）；该规格**无折扣时为 `null`**。同一商品各规格折扣可不同，请逐规格取用，勿套用 `items[].original_price` |
| `items[].sku_options[].promo_labels` | array | 该规格自己的折扣 / 促销标签 `[{text, sub_texts}]`，如 `[{"text": "9.2折", "sub_texts": ["限1份"]}]`；无则为空数组。**多规格商品请以本字段为准**——`items[].promo_labels` 是商品卡片文案，多规格时可能只写「8.59折起」这类**最低档**说法，看不出所选规格的实际折扣。仅供展示，不参与价格计算 |
| `items[].sku_options[].available` | boolean | 该规格是否可选 |
| `items[].sku_options[].ingredient_options` | array | 该规格**专属**的配料/做法选项（字段同 `items[].ingredient_options`）；**仅非默认规格返回**。配料随规格而变（如不同杯型可选「温度」不同），下单选该规格时用此处的 `option_id`。|
| `items[].ingredient_options` | array | 配料 / 做法选项（如温度、糖度），对应**默认规格**；非默认规格见 `items[].sku_options[].ingredient_options` |
| `items[].ingredient_options[].option_id` | string | 选项 ID（`opt_`），原样回传到下单的 `items[].ingredient_option_ids` |
| `items[].ingredient_options[].group_name` | string | 选项组名（如「糖度」）|
| `items[].ingredient_options[].name` | string | 选项名（如「标准糖」）|
| `items[].ingredient_options[].price_delta` | integer | 选 1 份的加价（分），默认 `0`。加多份不是简单相乘，看 `price_steps` |
| `items[].ingredient_options[].price_steps` | array | 分档价目表，`[{min_quantity, max_quantity, total_price}]`。`total_price` 是买该份数时的**总**加价（分）。只有「加不同份数、价格也不同」的选项才有这个字段；没有它就表示加多少份都收 `price_delta` 那个数，同样不要乘 |
| `items[].ingredient_options[].selected_by_default` | boolean | 是否为默认选项 |
| `items[].ingredient_options[].max_quantity` | integer | 该选项最多可加几份；`1` 表示只能选、不能加份。**同组各选项的上限可能不同**，按每个选项自己的值为准 |
| `items[].ingredient_options[].default_quantity` | integer | 商家推荐份数，仅供展示；不传 `ingredient_quantities` 时按 **1 份**下单 |
| `items[].ingredient_options[].required` | boolean | 该选项所在的组是否必选；必选组你没选时会自动补上该组默认项 |
| `items[].ingredient_options[].multi_select` | boolean | 该组能否同时选多项；`false` 时同组只能选一项，选两项会下单失败 |
| `items[].ingredient_options[].max_select` | integer \| null | 该组最多可选几**种**（不是几份，份数看 `max_quantity`）；单选组为 `1`，`null` 表示不限种类 |
| `items[].ingredient_options[].available` | boolean | 该选项是否可选：只表示它本身有没有售罄 / 下架，**不含选项之间的互斥**（见下方提示）|
| `total_items` | integer | 过滤（`keyword`）后的商品总数 |
| `has_more` | boolean | 是否还有下一页 |
| `next_offset` | integer \| null | 下一页的 `offset`；`has_more` 为 `false` 时为 `null` |
<Note>
  **菜单里的 `available` 不含互斥判定。** 有些商品的选项分层级——先选咖啡豆，再选萃取方式，能选的萃取只有那款豆对应的几种。这种可选性取决于「当前选了什么」，而本接口没有表达当前选择的入参，所以菜单只列出候选、`available` 只反映售罄 / 下架。

  **要判断当前选择下某项能不能选，用 `get_item_options`**（它接收当前选择、能逐级收敛）。菜单里的 `option_id` 仍可直接用于下单。
</Note>

| `required_groups` | array | 店铺级必选商品组（如麻辣烫「必选好汤」）；整单须从每组 `candidate_item_ids` 至少选 `min_select` 个商品才能下单，无此约束时为 `[]` |
| `required_groups[].name` | string | 必选组名（如「必选好汤」）|
| `required_groups[].required` | boolean | 恒为 `true` |
| `required_groups[].min_select` | integer | 该组至少需选的商品数（当前恒为 `1`）|
| `required_groups[].candidate_item_ids` | array | 候选商品的 `item_id` 列表；从中至少选 `min_select` 个，作为普通商品加入下单 `items[]` |
| `required_groups[].candidates` | array | 候选商品详情 `[{item_id, name, price, available}]`，与 `candidate_item_ids` 一一对应且**始终完整**（与 `keyword`/分页解耦）；agent 直接据此展示候选，无需回查 `items[]` |

<Tip>
  **渐进式披露**：用 `keyword` 缩小范围，或用 `limit` + `offset` 翻页。`has_more` 为 `true` 时，带 `offset=next_offset` 继续调用，直到 `has_more` 为 `false`。同一 `cart_id` 上之前各次调用返回的 `item_id` 在购物车存活期内仍可下单。大菜单也可先 `full_menu=true` 一次速览全貌，再对目标商品富化（`keyword` / `limit` 或 `get_item_options`）。
</Tip>


<Note>
  **`grouped=true` 时配料换一种形状返回。** 传 `grouped=true` 后，配料不再是平铺的 `ingredient_options`，而是按组返回 `ingredient_groups`：组信息（`group_name` / `required` / `multi_select` / `max_select`）只出现在组上一次，不再逐条重复；选项本身放在 `options[]` 里，字段与平铺形式逐字段一致。两种形式**二选一，不会同时出现**，内容完全相同。

  ```json
  "ingredient_groups": [
    {"group_name": "温度", "required": true, "multi_select": false, "max_select": 1,
     "options": [
       {"option_id": "opt_1", "name": "冰", "price_delta": 0, "selected_by_default": true, "max_quantity": 1, "default_quantity": 1, "available": true},
       {"option_id": "opt_2", "name": "热", "price_delta": 0, "selected_by_default": false, "max_quantity": 1, "default_quantity": 1, "available": true}
     ]},
    {"group_name": "加料", "required": false, "multi_select": true, "max_select": 5,
     "options": [
       {"option_id": "opt_5", "name": "珍珠", "price_delta": 200, "selected_by_default": false, "max_quantity": 3, "default_quantity": 1, "available": true}
     ]}
  ]
  ```
</Note>

### 错误码

| code | 说明 |
|------|------|
| `CONSENT_GRANT_REQUIRED` | 缺少用户授权（未传 `consent_grant_id`）|
| `CONSENT_GRANT_INVALID` | 用户授权无效 |
| `CONSENT_GRANT_EXPIRED` | 用户授权已过期，需重新授权 |
| `CAP_NOT_BOUND` | 该 Agent 未开通外卖能力 |
| `CONSENT_GRANT_WRONG_CAP` | 授权属于其它能力 / 服务商 |
| `PUBLIC_REFERENCE_INVALID` | `cart_id` 无效或过期，`shop_id` 无效，或 `shop_id` 与 `cart_id` 不匹配 |
| `ELEME_ERROR` | 上游获取菜单失败 |

完整错误码见 [错误处理](/gateway/error-handling)。

### 调用示例

```json
{
  "name": "get_shop_menu",
  "arguments": {
    "consent_grant_id": "cg_your_consent_grant",
    "shop_id": "<来自 search_shops>",
    "cart_id": "<来自 search_shops>",
    "keyword": "拿铁",
    "limit": 20,
    "offset": 0
  }
}
```
