## get_shop_share_url

为某个店铺生成一条可分享的 H5 短链（短 URL）。网关把服务商原始 scheme（内含内部 ID 与 UA）包装成短链返回，调用方只会看到我们的短链，不会接触到内部 ID。

<Note>
  **链路**：`search_shops` 得 `shop_id` → **`get_shop_share_url`** 得 `share_url`。`shop_id` 必须原样使用 `search_shops` 返回的值，不要自行拼造。
</Note>

### 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `consent_grant_id` | string | 是 | — | 用户授权 ID（`cg_` 前缀，来自 `verify_user_bind`），标识已授权用户 |
| `shop_id` | string | 是 | — | 店铺 ID（`shop_` 前缀，来自 `search_shops`），原样回传 |

### 返回

| 字段 | 类型 | 说明 |
|------|------|------|
| `share_url` | string | 店铺 H5 分享短链。短链服务未配置或出错时，降级返回服务商原始 scheme（此时内部信息可能可见）|

<Note>
  本工具返回中不含任何金额字段，也不回显 `shop_id`（同步单店调用，调用方已持有）。
</Note>

### 错误码

| code | 说明 |
|------|------|
| `CONSENT_GRANT_REQUIRED` | 缺少用户授权（未传 `consent_grant_id`）|
| `CONSENT_GRANT_INVALID` | 用户授权无效 |
| `CONSENT_GRANT_EXPIRED` | 用户授权已过期，需重新授权 |
| `CAP_NOT_BOUND` | 该 Agent 未开通外卖能力 |
| `CONSENT_GRANT_WRONG_CAP` | 授权属于其它能力 / 服务商 |
| `PUBLIC_REFERENCE_INVALID` | `shop_id` 无效、过期或不属于当前授权用户 |
| `ELEME_ERROR` | 上游未能生成分享 scheme |

完整错误码见 [错误处理](/gateway/error-handling)。

### 调用示例

```json
{
  "name": "get_shop_share_url",
  "arguments": {
    "consent_grant_id": "cg_your_consent_grant",
    "shop_id": "<来自 search_shops>"
  }
}
```
