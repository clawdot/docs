## 持续扩展

Clawdot Skills 正在将更多本地生活服务能力封装为标准化的技能包。以下是计划中的方向：

| 服务类型 | 典型场景 | 状态 |
|---------|---------|------|
| **商超配送** | 超市购物、日用品采购、生鲜水果 | 规划中 |
| **鲜花蛋糕** | 节日送花、生日蛋糕预订配送 | 规划中 |
| **医药服务** | 常备药品配送、处方药代购 | 规划中 |
| **跑腿代办** | 取件寄件、代买代送 | 规划中 |
| **家政服务** | 保洁、维修、搬家预约 | 探索中 |

每个新 Skill 都将遵循统一的封装标准——包含 `skill.yaml` 定义、`GUIDE.md` 交互 SOP、多平台适配层，Agent 安装后开箱即用。
