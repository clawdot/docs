## 即将推出

到店服务 Skill 正在开发中，将覆盖以下场景：

**预约管理** — 餐厅预订座位、美发店预约时间段、康养中心预约课程等。Agent 可以查询可用时间、创建预约、修改或取消预约。

**排号等位** — 到店后自动取号排队，实时获取排队进度和预计等待时间，轮到时通知用户。

**到店核销** — 生成核销码或二维码，用户到店出示即可完成核销。

## 计划支持的 Action

| Action | 说明 | 状态 |
|--------|------|------|
| `availability` | 查询可用时间段和座位 | 规划中 |
| `booking` | 创建/修改/取消预约 | 规划中 |
| `queue` | 取号排队、查询进度 | 规划中 |
| `verify` | 到店核销 | 规划中 |
