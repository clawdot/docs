## 什么是 Skills？

**Skill 是建立在网关之上、可安装的技能包。** 把它装进你的 Agent（Claude Code / OpenClaw / Codex），Agent 就立刻具备了对应的本地生活能力——比如"点外卖"。你不需要从零拼接调用链，技能包里已经封装好了完整的动作和一套交互"灵魂"。

底层走的仍是同一个网关：网关整合了下游平台（饿了么等）与本地生活服务，对外暴露一套标准化的菜单查询、下单履约、地址管理、订单追踪能力。Skill 就是把这套能力针对一个具体场景封装成"开箱即用"的形态。

## Skill 和 MCP 有什么区别？

两者面向不同的接入方式，互为补充：

| | **MCP（裸工具）** | **Skill（技能包）** |
|---|---|---|
| 你拿到的 | 18 个原子工具 | 一个封装好的能力（如 takeout） |
| 编排 | 自己写：搜店→菜单→预览→下单的链路由你拼 | 已封装：动作 + GUIDE 帮你串好流程 |
| 上手 | 灵活，但要自己定义交互 | 开箱即用，装上即具备能力 |
| 适合 | 想精细控制底层、自建 Agent 逻辑 | 想让 Agent 直接会"点外卖" |

简单说：**MCP 给你零件，Skill 给你成品。** 如果你想自己编排底层的 18 个工具、做更精细的控制，看 [MCP 概览](/mcp/overview)。

## Skill 的组成

每个 Skill 是一个标准化的目录，主要包含以下几部分：

| 组成部分 | 说明 |
|---------|------|
| **skill.yaml** | 技能元信息：名称、版本、鉴权模型、环境依赖（`requires`）、动作列表（`actions`）、支持平台（`platforms`） |
| **GUIDE.md** | 交互指南，技能的"灵魂"——平台无关地规定 Agent 何时调用哪个动作、如何对用户说话、成功/失败如何处置 |
| **scripts/** | 执行脚本：实际调用网关的逻辑代码（如 `takeout.py`，内含 open-gateway 客户端与各个 action） |
| **platforms/** | 平台适配层：针对 Claude Code（SKILL.md）、OpenClaw（SKILL.md）、Codex（AGENTS.md）各一份 |

## 一行安装

技能托管在 GitHub Release，安装脚本会下载、校验 sha256、解压到 Agent 平台对应的位置。以 Claude Code 为例：

```bash
curl -fsSL https://raw.githubusercontent.com/clawdot/open-gateway-clawdot-skill/main/install.sh | bash -s -- takeout claude-code
```

装完在 skill 根目录放一个 `.env`，填入你的 `API_KEY`（agent 身份，`clw_` 前缀，在[控制台](https://console.hicaspian.com/agents)创建 Agent 时拿到）；`GATEWAY_URL` 用默认的 `https://eleme-gateway.hicaspian.com` 即可。三个平台各自的安装与触发方式见[安装与平台](/skills/supported-platforms)。
