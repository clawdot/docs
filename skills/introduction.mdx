## 什么是 Skills？

Clawdot 整合了下游的外卖平台（饿了么、美团等）、生活服务平台（高德等），以及商户自有的 Agent 服务能力。在此基础上，Clawdot 定义了一套**标准化的服务 SOP 和接口协议**——统一的菜单查询、下单履约、地址管理、订单追踪等流程。

**Skills** 就是基于这套标准，封装出来的**面向 AI Agent 的技能包**。每个 Skill 是一个独立的、可安装的能力单元，Agent 安装后即可具备对应的本地生活服务能力。

## 架构思路

Skills 的设计遵循三层分离的原则：

**第一层：平台能力汇聚。** Clawdot 对接了多家外卖平台和本地生活服务的 API，将它们的能力统一归拢。商户不需要做任何改动——Clawdot 的 Proxy 层负责完成格式转换和协议适配。对于大型连锁品牌，也支持商户自建 Agent 直接实现标准协议。

**第二层：标准化协议与 SOP。** 在平台能力之上，Clawdot 定义了统一的接口规范和交互流程。无论底层是饿了么还是美团，上层的 Agent 都使用同一套标准链路：`search_shops`（搜店）→ `get_shop_menu`（菜单）→ `quote_cart`（算价）→ `select_address`（选址）→ `preview_order`（预览）→ `create_order`（下单）→ `get_sign_action`（免密签约）。商品的规格（specs）、属性（attrs）、加料（ingredients）等复杂定制体系，也被统一为标准数据结构。所有金额字段单位为**分（整数）**。完整链路见 [下单流程](/gateway/order-flow)。

**第三层：Skill 技能封装。** 基于标准化的协议和 SOP，Clawdot 将每类服务封装为独立的 Skill。每个 Skill 包含完整的交互引导（GUIDE）、动作定义（Actions）、平台适配层（Platforms），Agent 安装后开箱即用。

## Skill 的组成

每个 Skill 是一个标准化的包，包含以下几个部分：

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| **skill.yaml** | 技能元信息：名称、版本、动作列表、环境依赖 | `name: takeout`、`actions: [search_shops, get_shop_menu, preview_order, create_order]` |
| **GUIDE.md** | 交互 SOP：Agent 应该如何与用户对话、何时调用哪个动作 | "先做完，再说话。说结论，不说过程。" |
| **scripts/** | 执行脚本：实际调用 Gateway API 的逻辑代码 | `takeout.py` — 搜店、选品、下单的完整实现 |
| **platforms/** | 平台适配层：针对不同 Agent 平台的 SKILL.md 配置 | Claude Code、OpenClaw、Codex 各一份 |

## 认证模型

Skills 采用 **双层认证**：**API Key** 标识 Agent 身份，**用户授权（consent grant）** 标识已授权的外卖用户。Agent 持有自己的 API Key，再为每个用户走绑定流程拿到一个 `consent_grant_id`（`cg_` 前缀），二者配合即可代表该用户操作。每个授权独立、可随时撤销，天然形成安全隔离，无需复杂的权限管理系统。

- **API Key（Agent 身份）：** 通过 `Authorization: Bearer clw_...` 请求头传递，MCP 与 REST 都一样；在 Portal 创建 Agent 时生成。
- **用户授权（consent grant）：** REST 通过 `X-Consent-Grant-Id` 请求头传递；MCP 作为每个工具的 `consent_grant_id` 参数传入（不走请求头）。

适用于：个人助手、桌面端 Agent（Claude Desktop、Cursor 等）、各类 Agent 平台集成。完整说明见 [认证机制](/gateway/authentication)。

## 支持的平台

Skills 的平台适配层让同一个 Skill 可以运行在多种 Agent 环境中：

| 平台 | 调用方式 | 适用场景 |
|------|---------|---------|
| **Claude Code** | Python 脚本 + SKILL.md 指令 | 桌面端开发者、个人 Agent |
| **OpenClaw** | Tool SDK + camelCase 参数 | 开放平台集成 |
| **Codex** | Python 脚本 + AGENTS.md | OpenAI Codex Agent |
| **自建 Agent** | REST API 直接调用 | 钉钉、Kimi、QCloud 等任意平台 |
