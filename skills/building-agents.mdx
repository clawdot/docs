## 概述

本指南将带你使用 Clawdot Gateway，从零构建一个完整的本地生活 Agent。通过遵循最佳实践和处理边界情况，你将能够创建一个健壮、用户友好的应用。

下面的示例以 **REST API** 写法为主；同样的能力也通过 **MCP** 工具暴露，参数除 `consent_grant_id`（MCP 是工具参数，REST 是 `X-Consent-Grant-Id` 请求头）外完全一致，可按需切换。

## 架构设计

一个完整的本地生活 Agent 由以下模块组成：

```
┌─────────────────────────────────────────────┐
│         用户交互层 (Agent 应用)              │
│  Claude Desktop / Kimi / 钉钉 / 自建 Agent   │
└────────────────────┬────────────────────────┘
                     │
┌────────────────────▼────────────────────────┐
│        业务逻辑层 (你的代码)                  │
│  • 用户授权管理      • 下单链路管理          │
│  • 本地缓存         • 错误处理               │
└────────────────────┬────────────────────────┘
                     │
┌────────────────────▼────────────────────────┐
│     Clawdot Gateway (REST / MCP)             │
│  • 商家搜索     • 订单预览 / 创建            │
│  • 菜单查询     • 免密签约                   │
│  • 地址管理     • 优惠券管理                │
└─────────────────────────────────────────────┘
```

<Info>
Gateway 同时提供 18 个 REST 端点与 18 个一一对应的 MCP 工具，覆盖完全相同的能力。本页用 REST 演示，MCP 工具名与端点对应关系见 [MCP 概览](/mcp/overview)。
</Info>

    </Warning>
  </Step>

<Info>
API Key 标识 **Agent**，通过 `Authorization: Bearer clw_...` 请求头传递，所有 REST 与 MCP 请求都需要它。后续操作用户资源时，还需要下一步获取的**用户授权（consent grant）**。详见 [认证机制](/gateway/authentication)。
</Info>

## Step 2：获取用户授权

操作用户资源（搜店、下单、查地址等）需要双层认证：API Key 标识 Agent，**用户授权（consent grant）** 标识已授权的外卖用户。用户走一次绑定流程后，你拿到 `consent_grant_id`（`cg_` 前缀），后续业务接口凭它调用。

绑定支持两种模式：`sms`（向手机号下发验证码）与 `h5`（返回授权链接，用户在链接中登录授权）。下面以 `sms` 模式演示。

### 绑定流程

```python
import requests
import os

api_key = os.getenv("CLAWDOT_API_KEY")
base_url = "http://eleme-gateway.hicaspian.com/api/v1"

# Step 2a：发起绑定，下发短信验证码
def request_user_bind(phone: str) -> str:
    """
    发起 SMS 授权绑定
    返回: bind_id（用于后续确认）
    """
    url = f"{base_url}/auth/bind/request"
    payload = {"phone": phone, "auth_type": "sms"}
    headers = {"Authorization": f"Bearer {api_key}"}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    data = response.json()
    print(f"验证码已发送至 {data['masked_phone']}，{data['expires_in']} 秒内有效")
    return data["bind_id"]  # 返回给用户，等待他们输入验证码


# Step 2b：确认绑定，换取 consent_grant_id
def verify_user_bind(bind_id: str, code: str) -> str:
    """
    核验短信验证码，换取 consent_grant_id
    返回: consent_grant_id（后续 API 调用必需）
    """
    url = f"{base_url}/auth/bind/verify"
    payload = {"auth_type": "sms", "bind_id": bind_id, "code": code}
    headers = {"Authorization": f"Bearer {api_key}"}

    response = requests.post(url, json=payload, headers=headers)

    if response.status_code == 400:
        # 验证码无效或已过期
        raise ValueError("验证码错误或已过期，请重新获取")

    response.raise_for_status()

    data = response.json()
    consent_grant_id = data["consent_grant_id"]

    # 存储 consent_grant_id（用于后续 API 调用）
    # 建议使用安全的本地存储或会话管理
    print(f"用户授权成功！授权范围: {data['scopes']}，过期时间: {data['expires_at']}")
    return consent_grant_id
```

### 完整绑定 UI 流程

```python
def bind_user_interactive():
    """
    交互式用户授权（Agent 对话流程）
    """
    print("欢迎使用本地生活 Agent，请先授权你的账号")
    print("=" * 50)

    # 第一步：获取用户电话号码
    phone = input("请输入你的手机号码: ").strip()

    # 第二步：发起绑定，下发验证码
    try:
        bind_id = request_user_bind(phone)
    except requests.exceptions.RequestException as e:
        print(f"发起绑定失败：{e}")
        return None

    # 第三步：用户输入验证码
    max_attempts = 3
    for attempt in range(max_attempts):
        code = input(f"\n请输入验证码 (剩余 {max_attempts - attempt} 次): ").strip()

        try:
            consent_grant_id = verify_user_bind(bind_id, code)
            print("\n授权成功！现在你可以开始使用本地生活服务了。")
            return consent_grant_id
        except ValueError as e:
            print(f"验证失败：{e}")

    print("\n验证次数过多，请稍后重试或重新发起绑定")
    return None


# 使用示例
consent_grant_id = bind_user_interactive()
if consent_grant_id:
    # 保存 consent_grant_id 供后续使用
    # 例如存储到文件或数据库
    pass
```

<Info>
绑定成功返回的 `expires_at` 是授权过期时间（ISO 8601）。**重授权即轮换**：同一用户每次成功绑定都会铸造新的 `consent_grant_id`，旧的立即失效。`consent_grant_id` 明文仅本次返回一次，落库仅存哈希，请妥善保存。授权可随时通过 `POST /auth/unbind` 撤销。
</Info>

## Step 3：核心业务流程

实现从搜索、浏览、算价、预览到下单、签约的完整链路。整条链路是**有状态的**：每一步返回的 ID 必须原样回传给下一步，不可自造或跨链路混用。

```
search_shops → get_shop_menu → quote_cart → select_address
            → preview_order → create_order → get_sign_action
```

<Warning>
所有金额字段单位为**分（整数）**，不是元。例如 `payable_price: 1500` 表示 ¥15.00。
</Warning>

下面所有请求都带两个认证头：

```python
headers = {
    "Authorization": f"Bearer {api_key}",
    "X-Consent-Grant-Id": consent_grant_id,
    "Content-Type": "application/json"
}
```

### Phase 1：搜索商家

```python
def search_shops(consent_grant_id: str, keyword: str = None, address_id: str = None):
    """
    搜索 / 浏览附近的商家
    - 不传 keyword：浏览模式，返回附近至多 20 家店铺
    - 传 keyword：精确搜索（约 5 家），支持店名 / 品类 / 商品名
    """
    url = f"{base_url}/shops/search"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {"keyword": keyword, "address_id": address_id}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    shops = response.json()["shops"]
    return shops


# 使用示例
shops = search_shops(consent_grant_id, keyword="生椰拿铁", address_id="addr_...")

for shop in shops[:5]:  # 显示前 5 家
    # 金额字段单位为分，展示时除以 100
    print(f"""
    【{shop['name']}】
    评分: {shop.get('rating')}⭐
    距离: {shop.get('distance_text')}
    送达时间: {shop.get('delivery_time_text')}
    起送价: ¥{shop['min_order_amount'] / 100:.2f} | 配送费: {shop.get('delivery_fee_text')}
    """)
```

每个结果都附带 `shop_id` 与 `cart_id`：`cart_id` 已封装该店铺与本次配送坐标，是后续 `get_shop_menu` / `quote_cart` / `preview_order` 的入口，**原样回传**即可。完整字段见 [搜索店铺](/api-reference/shops/search)。

```python
def get_shop_menu(consent_grant_id: str, shop_id: str, cart_id: str, keyword: str = None):
    """
    获取商家菜单（POST /shops/menu）
    菜单可能很大（100+ 项），可用 keyword 或 limit/offset 渐进披露

    headers = {
        "Authorization": f"Bearer {api_key}",

    }
    payload = {"shop_id": shop_id, "cart_id": cart_id, "keyword": keyword}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    return response.json()


# 使用示例
menu = get_shop_menu(consent_grant_id, "shop_...", "cart_...", keyword="拿铁")

for category in menu["categories"]:
    print(f"\n【{category['name']}】")
    for item in category["items"]:
        status = "✓ 在售" if item.get("available") else "✗ 售罄"

```

下单必须使用 `get_shop_menu` 返回的 `item_id` / `sku_id`（以及规格 / 加料的 `ingredient_option_ids`）。完整字段见 [店铺菜单](/api-reference/shops/detail)；规格 / 属性 / 加料体系见 [商品规格说明](/gateway/item-specs)。

### Phase 3：准备收货地址

```python
def search_addresses(consent_grant_id: str, keyword: str, lat: float = None, lng: float = None):
    """
    搜索地址 POI（POST /addresses/search）
    返回 saved_addresses[]（已保存地址）+ suggestions[]（POI 结果，含一次性 token）
    """
    url = f"{base_url}/addresses/search"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {"keyword": keyword, "lat": lat, "lng": lng}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()


def select_address(consent_grant_id: str, suggestion_token: str,
                   contact_name: str, contact_phone: str, address_detail: str):
    """
    登记 / 选择收货地址（POST /addresses/select）
    用 search_addresses 返回的某条 suggestion 的 token 登记，返回 address_id
    """
    url = f"{base_url}/addresses/select"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {
        "suggestion_token": suggestion_token,
        "contact_name": contact_name,
        "contact_phone": contact_phone,
        "address_detail": address_detail,
    }

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()["address_id"]


# 使用示例：地址流程 = 搜 POI 拿 token → 登记拿 address_id
result = search_addresses(consent_grant_id, keyword="光谷世界城", lat=30.5, lng=114.4)

# 已有地址可直接复用 saved_addresses[].address_id；新地址则登记一条
suggestion = result["suggestions"][0]
address_id = select_address(
    consent_grant_id,
    suggestion_token=suggestion["token"],
    contact_name="张三",
    contact_phone="13800138000",
    address_detail="3 号楼 101",
)
```

`search_addresses` 返回的 `saved_addresses[]` 可直接复用其 `address_id`；`suggestions[].token` 是一次性令牌，传给 `select_address` 登记后得到 `address_id`。详见 [搜索地址](/api-reference/addresses/search) 与 [选择/登记地址](/api-reference/addresses/select)。

### Phase 5：预览订单（下单前确认）

<Check title="生产环境最佳实践 - 下单前确认">
始终在创建订单前用 `preview_order` 校验并向用户确认最终价格，避免误操作。预览产出的 `preview_id` + `confirmation_token` 是真正下单所需的凭据。
</Check>

```python
def preview_order(consent_grant_id: str, shop_id: str, cart_id: str,
                  address_id: str, items: list, quote_id: str = None,
                  coupon_ids: list = None, order_remark: str = ""):
    """
    预览订单（POST /orders/preview）
    校验店铺 / 地址 / 商品并应用优惠券，返回最终价格 + preview_id + confirmation_token
    coupon_ids 三态：不传=自动选最优券；[]=不用券；["cpn_..."]=指定券
    """
    url = f"{base_url}/orders/preview"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {
        "shop_id": shop_id,
        "cart_id": cart_id,
        "address_id": address_id,
        "items": items,
        "quote_id": quote_id,
        "coupon_ids": coupon_ids,
        "order_remark": order_remark,
    }

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()


# 使用示例
preview = preview_order(
    consent_grant_id, "shop_...", "cart_...", address_id, items,
    quote_id=quote_id, order_remark="放门口，请按门铃",
)

# 金额单位为分，展示时除以 100
print(f"应付：¥{preview['price']['payable_price'] / 100:.2f}")
print(f"送达地址：{preview['address']['address_detail']}")

preview_id = preview["preview_id"]
confirmation_token = preview["confirmation_token"]
```

`preview_id` + `confirmation_token` 须配对使用，由同一次预览产出，有效期约 10 分钟。完整字段与 `coupon_ids` 三态说明见 [预览订单](/api-reference/orders/preview)。

### Phase 6：创建订单

```python
def create_order(consent_grant_id: str, preview_id: str, confirmation_token: str,
                 callback_url: str = None):
    """
    创建订单（POST /orders/create）
    用同一次预览的 preview_id + confirmation_token 正式下单
    """
    url = f"{base_url}/orders/create"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {
        "preview_id": preview_id,
        "confirmation_token": confirmation_token,
        "callback_url": callback_url,  # 可选：支付状态回调
    }

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    order = response.json()

    print(f"\n✓ 订单已创建")
    print(f"订单号：{order['order_id']}")
    print(f"状态：{order['status']}")

    return order


# 使用示例
order = create_order(consent_grant_id, preview_id, confirmation_token)
```

本接口以 `confirmation_token` 为幂等键：同一令牌只能下一单，再次下单需重新预览取新令牌。返回 `order_id`、`status` 与（需支付时的）`payment_action`。可选传 `callback_url`，网关会轮询订单状态并在脱离未支付态时 POST 回调；不传则自行轮询 `get_order_status`（`GET /orders/{order_id}`）。完整字段见 [创建订单](/api-reference/orders/create)。

### Phase 7：免密签约

```python
def get_sign_action(consent_grant_id: str, return_url: str):
    """
    发起免密支付签约（POST /payment/sign-action）
    返回一个 action：action_type=open_h5 时把用户引导到 action_url 完成签约
    """
    url = f"{base_url}/payment/sign-action"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {"return_url": return_url}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    action = response.json()["action"]
    if action["action_type"] == "open_h5":
        print(f"请在浏览器打开完成签约：{action['action_url']}")
    return action
```

免密签约是免密支付类订单的前置条件：`action_type=open_h5` 时把用户引导到 `action.action_url`（H5 签约页），完成后浏览器跳回 `return_url`；`none` 表示已签约。随后用 `get_sign_status`（`GET /payment/sign-status`）轮询结果。完整链路与字段见 [下单流程](/gateway/order-flow)。

## Step 4：处理边界情况

健壮的 Agent 应该优雅地处理各种边界情况，提供友好的错误提示。Gateway 的错误统一返回 `{"error": {"code", "message"}}` 结构。

### 错误处理

```python
def safe_api_call(func, *args, **kwargs):
    """
    包装 API 调用，统一处理错误
    """
    try:
        return func(*args, **kwargs)
    except requests.exceptions.Timeout:
        print("❌ 网络超时，请检查网络连接")
        return None
    except requests.exceptions.ConnectionError:
        print("❌ 无法连接到服务器，请稍后重试")
        return None
    except requests.exceptions.HTTPError as e:
        # Gateway 错误体：{"error": {"code", "message"}}
        try:
            code = e.response.json()["error"]["code"]
        except Exception:
            code = None

        if code in ("AUTH_REQUIRED", "AUTH_INVALID"):
            print("❌ API Key 缺失或无效，请检查 Authorization 头")
        elif code in ("CONSENT_GRANT_INVALID", "CONSENT_GRANT_EXPIRED"):
            print("❌ 用户授权无效或已过期，请重新发起绑定")
        elif code == "CAP_NOT_BOUND":
            print("❌ 当前 Agent 未开通该能力，请在 Portal 开通")
        elif code == "PUBLIC_REFERENCE_INVALID":
            print("❌ 平台 ID（店铺 / 地址 / 订单）无效、过期或不属于当前用户")
        elif code in ("RATE_LIMITED", "QUOTA_EXCEEDED"):
            print("❌ 请求过于频繁或配额用尽，请稍后再试")
        elif code == "ELEME_ERROR":
            print("❌ 上游服务异常，请稍后重试")
        else:
            print(f"❌ API 错误 ({e.response.status_code})：{code or e}")

        return None
    except Exception as e:
        print(f"❌ 未知错误：{e}")
        return None


# 使用
shops = safe_api_call(search_shops, consent_grant_id, keyword="奶茶", address_id=address_id)
```

### 用户授权过期处理

```python
def get_valid_consent_grant(stored_grant_id: str, phone: str) -> str:

    return stored_grant_id
```

```python
def get_order_with_retry(consent_grant_id: str, order_id: str, max_retries: int = 3):
    """
    查询订单（GET /orders/{order_id}），支持重试机制
    """
    for attempt in range(max_retries):
        try:
            url = f"{base_url}/orders/{order_id}"
            headers = {
                "Authorization": f"Bearer {api_key}",
                "X-Consent-Grant-Id": consent_grant_id,
            }
            response = requests.get(url, headers=headers, timeout=5)
            response.raise_for_status()
            return response.json()

        except requests.exceptions.Timeout:
            if attempt < max_retries - 1:
                print(f"查询超时，正在重试... ({attempt + 1}/{max_retries})")
            else:
                print("❌ 无法获取订单信息，请稍后重试")
                return None
```

## 完整示例代码

一个完整的本地生活 Agent 示例：

```python
import os
import requests
from typing import List, Dict, Optional

class LocalLifeAgent:
    def __init__(self, api_key: str = None):
        self.api_key = api_key or os.getenv("CLAWDOT_API_KEY")
        self.base_url = "http://eleme-gateway.hicaspian.com/api/v1"
        self.consent_grant_id = None
        self.user_phone = None

    def _headers(self) -> Dict[str, str]:
        headers = {
            "Authorization": f"Bearer {self.api_key}",
            "Content-Type": "application/json",
        }
        if self.consent_grant_id:
            headers["X-Consent-Grant-Id"] = self.consent_grant_id
        return headers

    def bind_user(self, phone: str) -> bool:
        """用户授权流程"""
        try:
            bind_id = self._request_bind(phone)
            code = input("请输入验证码: ")
            self.consent_grant_id = self._verify_bind(bind_id, code)
            self.user_phone = phone
            return True
        except Exception as e:
            print(f"授权失败：{e}")
            return False

    def order(self, keyword: str, address_id: str) -> Optional[Dict]:
        """搜索商家并完成下单链路"""
        if not self.consent_grant_id:
            print("请先完成用户授权")
            return None

        # 1. 搜索商家
        shops = self._search_shops(keyword, address_id)
        if not shops:
            print("未找到相关商家")
            return None
        for i, shop in enumerate(shops[:5], 1):
            print(f"{i}. {shop['name']} - 评分 {shop.get('rating')}⭐")
        shop = shops[int(input("选择商家 (1-5): ")) - 1]

        # 2. 查菜单，挑商品（金额单位为分）
        menu = self._get_shop_menu(shop["shop_id"], shop["cart_id"])
        items = self._pick_items(menu)  # 由你的 UI 收集 item_id / sku_id / quantity

        # 3. 算价
        quote = self._quote_cart(shop["shop_id"], shop["cart_id"], address_id, items)

        # 4. 预览，拿 preview_id + confirmation_token
        preview = self._preview_order(
            shop["shop_id"], shop["cart_id"], address_id, items, quote["quote_id"],
        )
        print(f"应付 ¥{preview['price']['payable_price'] / 100:.2f}")

        # 5. 下单
        return self._create_order(preview["preview_id"], preview["confirmation_token"])

    def _request_bind(self, phone: str) -> str:
        url = f"{self.base_url}/auth/bind/request"
        headers = {"Authorization": f"Bearer {self.api_key}"}
        resp = requests.post(url, json={"phone": phone, "auth_type": "sms"}, headers=headers)
        resp.raise_for_status()
        return resp.json()["bind_id"]

    def _verify_bind(self, bind_id: str, code: str) -> str:
        url = f"{self.base_url}/auth/bind/verify"
        headers = {"Authorization": f"Bearer {self.api_key}"}
        resp = requests.post(
            url, json={"auth_type": "sms", "bind_id": bind_id, "code": code}, headers=headers
        )
        resp.raise_for_status()
        return resp.json()["consent_grant_id"]

    def _search_shops(self, keyword: str, address_id: str) -> List[Dict]:
        url = f"{self.base_url}/shops/search"
        resp = requests.post(
            url, json={"keyword": keyword, "address_id": address_id}, headers=self._headers()
        )
        return resp.json().get("shops", [])

    def _get_shop_menu(self, shop_id: str, cart_id: str) -> Dict:
        url = f"{self.base_url}/shops/menu"
        resp = requests.post(
            url, json={"shop_id": shop_id, "cart_id": cart_id}, headers=self._headers()
        )
        return resp.json()

    def _quote_cart(self, shop_id: str, cart_id: str, address_id: str, items: List[Dict]) -> Dict:
        url = f"{self.base_url}/cart/quote"
        resp = requests.post(
            url,
            json={"shop_id": shop_id, "cart_id": cart_id, "address_id": address_id, "items": items},
            headers=self._headers(),
        )
        return resp.json()

    def _preview_order(self, shop_id: str, cart_id: str, address_id: str,
                       items: List[Dict], quote_id: str) -> Dict:
        url = f"{self.base_url}/orders/preview"
        resp = requests.post(
            url,
            json={
                "shop_id": shop_id, "cart_id": cart_id, "address_id": address_id,
                "items": items, "quote_id": quote_id, "order_remark": "请按门铃",
            },
            headers=self._headers(),
        )
        return resp.json()

    def _create_order(self, preview_id: str, confirmation_token: str) -> Dict:
        url = f"{self.base_url}/orders/create"
        resp = requests.post(
            url,
            json={"preview_id": preview_id, "confirmation_token": confirmation_token},
            headers=self._headers(),
        )
        return resp.json()

    def _pick_items(self, menu: Dict) -> List[Dict]:
        """示意：从菜单收集 item_id / sku_id / quantity（list，非 JSON 字符串）"""
        return []


# 使用示例

    # 用户授权

        if order:
            print(f"\n订单已创建: {order['order_id']}")
```
