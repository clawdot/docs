## 钉钉 Agent

钉钉 Agent 是企业场景中最常见的 AI 助手形式，可以集成到钉钉应用市场，为员工和用户提供本地生活服务。

### 快速开始

<Tabs>
  <Tab title="集成步骤">
    1. **注册钉钉开发者账号**
       - 访问 [钉钉开放平台](https://open.dingtalk.com)
       - 创建企业应用

    2. **创建 Agent**
       在 [Clawdot Portal](http://console.hicaspian.com) 创建专用于钉钉的 Agent，记录 API Key（`clw_` 前缀）

    3. **配置 WebHook**
       在钉钉应用设置中，配置 Clawdot Skills API 作为消息处理端点

    4. **实现消息处理**
       在你的服务端实现与钉钉消息交互的逻辑

    5. **发布应用**
       通过钉钉应用市场发布，供组织内用户或公众使用
  </Tab>

    ```python
    import requests
    import hmac
    import hashlib
    import base64
    import time

    import os

    app = Flask(__name__)

    DINGTALK_BOT_SECRET = os.getenv("DINGTALK_BOT_SECRET")
    CLAWDOT_API_KEY = os.getenv("CLAWDOT_API_KEY")
    CLAWDOT_BASE_URL = "http://eleme-gateway.hicaspian.com/api/v1"

    def sign_message(timestamp, secret):
        """钉钉消息签名验证"""
        message = f"{timestamp}\n{secret}".encode('utf-8')
        sign = hmac.new(
            secret.encode('utf-8'),
            message,
            hashlib.sha256
        ).digest()
        return base64.b64encode(sign).decode('utf-8')

    @app.route("/webhook/dingtalk", methods=["POST"])
    def handle_dingtalk_message():
        """处理钉钉 WebHook 消息"""
        timestamp = request.headers.get("X-Dingtalk-Timestamp")
        sign = request.headers.get("X-Dingtalk-Sign")

        # 验证消息完整性
        expected_sign = sign_message(timestamp, DINGTALK_BOT_SECRET)
        if sign != expected_sign:
            return {"code": 401, "message": "Unauthorized"}, 401

        data = request.json
        conversation_id = data.get("conversationId")
        sender_id = data.get("senderId")
        text = data.get("text", {}).get("content", "").strip()

        # 提取用户意图
        if "外卖" in text or "点餐" in text:
            # 搜索商店
            shops = search_shops_for_dingtalk(text, sender_id)
            reply = format_shop_list_for_dingtalk(shops)
        elif "订单" in text or "查询" in text:
            # 查询订单
            order = get_order_for_dingtalk(sender_id)
            reply = format_order_for_dingtalk(order)
        else:
            reply = "你好，我可以帮助你查询外卖、商超等本地生活服务。"

        # 发送回复到钉钉
        send_dingtalk_message(conversation_id, reply)

        return {"code": 0, "message": "ok"}, 200

    def search_shops_for_dingtalk(query, user_id):
        """调用 Clawdot API 搜索商店"""
        consent_grant_id = get_consent_grant(user_id)  # 获取该用户的授权（cg_ 前缀）

        url = f"{CLAWDOT_BASE_URL}/shops/search"
        headers = {
            "Authorization": f"Bearer {CLAWDOT_API_KEY}",
            "X-Consent-Grant-Id": consent_grant_id
        }
        payload = {
            "keyword": query,
            "lat": 39.9836,   # GCJ-02 坐标，应从用户位置服务获取
            "lng": 116.3164,
        }

        response = requests.post(url, json=payload, headers=headers)
        return response.json().get("shops", [])

    def format_shop_list_for_dingtalk(shops):
        """格式化商店列表为钉钉卡片"""
        cards = []
        for shop in shops:
            # 金额字段单位为分（整数），展示时除以 100
            delivery_fee_yuan = shop.get("delivery_fee", 0) / 100
            cards.append({
                "title": shop["name"],
                "actionURL": f"https://your-app.com/shop/{shop['shop_id']}",
                "content": f"评分: {shop.get('rating', '-')}⭐ | {shop.get('distance_text', '')} | 配送费: ¥{delivery_fee_yuan:.2f}"
            })
        return {"cards": cards}

        # 用户首次使用时走绑定流程（auth/bind/request + auth/bind/verify）
        # 拿到 consent_grant_id 后持久化，后续请求复用
    ```

## Kimi Agent

月之暗面 Kimi 是国内领先的大语言模型，支持 Agent 开发和 Function Calling。

### 快速开始

<Tabs>
  <Tab title="集成步骤">
    1. **注册 Kimi 开发者**
       - 访问 [Kimi 开放平台](https://kimi.moonshot.cn)
       - 创建应用并获取 API Key

    2. **创建 Clawdot Agent**
       在 [Clawdot Portal](http://console.hicaspian.com) 创建 Agent，记录 API Key（`clw_` 前缀）

    3. **定义 Function Schema**
       在 Kimi 应用中注册 Clawdot Gateway 的 API 为 Function Calling 工具

    4. **测试集成**
       使用 Kimi API 发送请求，验证 Function Calling 工作正常

    5. **部署上线**
       将 Agent 发布到 Kimi 应用市场
  </Tab>

  <Tab title="代码示例">
    ```python
    import requests
    import json
    import os

    KIMI_API_KEY = os.getenv("KIMI_API_KEY")
    CLAWDOT_API_KEY = os.getenv("CLAWDOT_API_KEY")
    CLAWDOT_BASE_URL = "http://eleme-gateway.hicaspian.com/api/v1"

    def call_kimi_with_function_calling(user_message, consent_grant_id):
        """使用 Kimi API 和 Function Calling"""

        # 定义可用的 Function（Clawdot Gateway 工具，与下单链路一一对应）。
        # 完整下单链路：search_shops → get_shop_menu → quote_cart →
        # select_address → preview_order → create_order → get_sign_action。
        # 这里只列搜索 / 菜单 / 预览 / 下单四步作为示例。
        tools = [
            {
                "type": "function",
                "function": {
                    "name": "search_shops",
                    "description": "搜索 / 浏览本地商家（不传 keyword 为浏览附近店铺）",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "keyword": {
                                "type": "string",
                                "description": "店名 / 品类 / 商品名；省略则浏览附近店铺"
                            },
                            "address_id": {
                                "type": "string",
                                "description": "已保存地址 ID；或改用 lat/lng（GCJ-02）"
                            },
                            "lat": {"type": "number", "description": "纬度（GCJ-02），无 address_id 时必传"},
                            "lng": {"type": "number", "description": "经度（GCJ-02），无 address_id 时必传"}
                        }
                    }
                }
            },
            {
                "type": "function",
                "function": {
                    "name": "get_shop_menu",
                    "description": "获取商家菜单（含可下单的 item_id / sku_id）",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "shop_id": {"type": "string", "description": "来自 search_shops"},
                            "cart_id": {"type": "string", "description": "来自 search_shops，已封装配送坐标"},
                            "keyword": {"type": "string", "description": "可选，按名称 / 分类 / 描述过滤"}
                        },
                        "required": ["shop_id", "cart_id"]
                    }
                }
            },
            {
                "type": "function",
                "function": {
                    "name": "preview_order",
                    "description": "预览订单，返回最终价格（单位分）与 preview_id + confirmation_token",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "shop_id": {"type": "string"},
                            "cart_id": {"type": "string"},
                            "address_id": {"type": "string", "description": "来自 select_address"},
                            "items": {
                                "type": "array",
                                "items": {
                                    "type": "object",
                                    "properties": {
                                        "item_id": {"type": "string"},
                                        "sku_id": {"type": "string"},
                                        "quantity": {"type": "integer"}
                                    }
                                }
                            }
                        },
                        "required": ["shop_id", "cart_id", "address_id", "items"]
                    }
                }
            },
            {
                "type": "function",
                "function": {
                    "name": "create_order",
                    "description": "用同一次预览的 preview_id + confirmation_token 正式下单",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "preview_id": {"type": "string", "description": "来自 preview_order"},
                            "confirmation_token": {"type": "string", "description": "来自同一次 preview_order"}
                        },
                        "required": ["preview_id", "confirmation_token"]
                    }
                }
            }
        ]

        # 调用 Kimi API
        url = "https://api.moonshot.cn/openai/v1/chat/completions"
        headers = {
            "Authorization": f"Bearer {KIMI_API_KEY}",
            "Content-Type": "application/json"
        }

        payload = {
            "model": "moonshot-v1-8k",
            "messages": [
                {"role": "user", "content": user_message}
            ],
            "tools": tools,
            "tool_choice": "auto"
        }

        response = requests.post(url, json=payload, headers=headers)
        result = response.json()

        # 处理 Function Calling 响应
        if result.get("choices"):
            choice = result["choices"][0]
            if choice.get("finish_reason") == "tool_calls":
                for tool_call in choice.get("tool_calls", []):
                    function_name = tool_call["function"]["name"]
                    function_args = json.loads(tool_call["function"]["arguments"])

                    # 调用 Clawdot Gateway API
                    function_result = call_clawdot_function(
                        function_name,
                        function_args,
                        consent_grant_id
                    )

                    print(f"Function: {function_name}")
                    print(f"Result: {function_result}")

        return result

    # 工具名 → REST 端点（全部 POST），与下单链路一一对应
    ENDPOINTS = {
        "search_shops": "/shops/search",
        "get_shop_menu": "/shops/menu",
        "quote_cart": "/cart/quote",
        "select_address": "/addresses/select",
        "preview_order": "/orders/preview",
        "create_order": "/orders/create",
    }

    def call_clawdot_function(function_name, args, consent_grant_id):
        """调用 Clawdot Gateway API"""

        headers = {
            "Authorization": f"Bearer {CLAWDOT_API_KEY}",
            "X-Consent-Grant-Id": consent_grant_id,
            "Content-Type": "application/json"
        }

        path = ENDPOINTS.get(function_name)
        if path is None:
            raise ValueError(f"未知工具: {function_name}")

        response = requests.post(
            f"{CLAWDOT_BASE_URL}{path}",
            json=args,
            headers=headers
        )
        return response.json()

    # 使用示例
    user_message = "我想在中关村点一份外卖"
    consent_grant_id = "cg_..."  # 用户授权，首次使用走绑定流程获取

    result = call_kimi_with_function_calling(user_message, consent_grant_id)
    ```
  </Tab>

  <Tab title="最佳实践">
    - **Function 超时处理**：设置合理的超时时间，避免 Kimi API 等待过长
    - **智能重试**：对于临时失败，使用指数退避重试
    - **缓存 Schema**：缓存 Function Schema，减少重复调用
    - **监控成本**：追踪 API 调用成本和使用情况

## Claude Desktop (MCP)

Claude Desktop 是 Anthropic 官方推出的客户端，原生支持 MCP（Model Context Protocol）协议。

### 快速开始

<Tabs>
  <Tab title="安装和配置">
    **1. 安装 Claude Desktop**
    - 下载 [Claude Desktop](https://claude.ai/download)
    - 按照指示完成安装和登录

    **2. 创建 Clawdot Agent**
    在 [Clawdot Portal](http://console.hicaspian.com) 创建 Agent 并获取 API Key（`clw_` 前缀）

    **3. 配置 MCP 服务器**
    Gateway 原生提供 Streamable HTTP MCP 端点（`http://eleme-gateway.hicaspian.com/mcp/v1`），
    Agent 身份通过 `Authorization: Bearer clw_...` 请求头在连接层传递。编辑
    `~/.claude-desktop/config.json`：

    ```json
    {
      "mcpServers": {
        "clawdot-skills": {
          "url": "http://eleme-gateway.hicaspian.com/mcp/v1",
          "headers": {
            "Authorization": "Bearer clw_your_api_key_here"
          }
        }
      }
    }
    ```

    **4. 重启 Claude Desktop**
    - 关闭 Claude Desktop
    - 重新打开，等待 MCP 服务器连接
    - 在工具栏中查看可用的 Gateway 技能

    **5. 开始使用**
    - 在对话中提及外卖、商超等本地生活需求
    - Claude 会自动调用相应的 Gateway 技能
  </Tab>

  <Tab title="MCP 服务器实现">
    Gateway 已原生提供 MCP 端点（`/mcp/v1`），通常**直接连接即可**（见上一标签页的配置）。
    仅当你需要把 Gateway 的 REST API 适配进自己的 MCP 进程时，才参考以下简化示例。
    每个工具都接受 `consent_grant_id` 参数（用户授权，`cg_` 前缀），在调用 REST 时
    映射为 `X-Consent-Grant-Id` 请求头：

    ```typescript
    import { Server } from "@modelcontextprotocol/sdk/server/index.js";
    import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
    import {
      CallToolRequestSchema,
      ListToolsRequestSchema,
      Tool
    } from "@modelcontextprotocol/sdk/types.js";
    import axios from "axios";

    const apiKey = process.env.CLAWDOT_API_KEY;
    const gatewayUrl = process.env.CLAWDOT_GATEWAY_URL;

    class ClawdotMCP {
      private server: Server;

      constructor() {
        this.server = new Server(
          {
            name: "clawdot-skills",
            version: "1.0.0"
          },
          {
            capabilities: {
              tools: {}
            }
          }
        );

        this.setupHandlers();
      }

      private setupHandlers() {
        this.server.setRequestHandler(
          ListToolsRequestSchema,
          async () => ({
            tools: [
              {
                name: "search_shops",
                description: "搜索 / 浏览本地商家",
                inputSchema: {
                  type: "object",
                  properties: {
                    consent_grant_id: { type: "string" },
                    keyword: { type: "string" },
                    address_id: { type: "string" },
                    lat: { type: "number" },
                    lng: { type: "number" }
                  },
                  required: ["consent_grant_id"]
                }
              },
              {
                name: "get_shop_menu",
                description: "获取商家菜单（含可下单的 item_id / sku_id）",
                inputSchema: {
                  type: "object",
                  properties: {
                    consent_grant_id: { type: "string" },
                    shop_id: { type: "string" },
                    cart_id: { type: "string" }
                  },
                  required: ["consent_grant_id", "shop_id", "cart_id"]
                }
              },
              {
                name: "create_order",
                description: "用 preview_id + confirmation_token 正式下单",
                inputSchema: {
                  type: "object",
                  properties: {
                    consent_grant_id: { type: "string" },
                    preview_id: { type: "string" },
                    confirmation_token: { type: "string" }
                  },
                  required: ["consent_grant_id", "preview_id", "confirmation_token"]
                }
              }
            ]
          })
        );

        this.server.setRequestHandler(
          CallToolRequestSchema,
          async (request) => {
            const { name, arguments: args } = request.params;

            switch (name) {
              case "search_shops":
                return await this.callGateway("/shops/search", args);
              case "get_shop_menu":
                return await this.callGateway("/shops/menu", args);
              case "create_order":
                return await this.callGateway("/orders/create", args);
              default:
                return { isError: true, content: [{ type: "text", text: "Unknown tool" }] };
            }
          }
        );
      }

      // 把工具参数转发给对应 REST 端点：consent_grant_id 走 X-Consent-Grant-Id 头，
      // 其余字段作为 JSON body。
      private async callGateway(path: string, args: any) {
        const { consent_grant_id, ...body } = args;
        const response = await axios.post(
          `${gatewayUrl}/api/v1${path}`,
          body,
          {
            headers: {
              "Authorization": `Bearer ${apiKey}`,
              "X-Consent-Grant-Id": consent_grant_id,
              "Content-Type": "application/json"
            }
          }
        );
        return { content: [{ type: "text", text: JSON.stringify(response.data) }] };
      }

      async start() {
        const transport = new StdioServerTransport();
        await this.server.connect(transport);
      }
    }

    const mcp = new ClawdotMCP();
    mcp.start();
    ```

## Cursor

Cursor 是面向开发者的 AI 代码编辑器，支持 MCP 集成。

### 快速开始

配置与 Claude Desktop 类似，直接连接 Gateway 的原生 MCP 端点：

```json
{
  "mcpServers": {
```

## 自建 Agent

如果你的 Agent 平台未在上述列表中，可以使用 **REST API** 自行集成。

### 使用 REST API 集成

参考 [接入指南 - REST API](/skills/integration-guide#rest-api) 章节。

**快速示例：**

```javascript
const axios = require('axios');

const CLAWDOT_API_KEY = process.env.CLAWDOT_API_KEY;
const CONSENT_GRANT_ID = process.env.CONSENT_GRANT_ID; // 用户授权，cg_ 前缀

async function searchShops(keyword, lat, lng) {
  const response = await axios.post(
    'http://eleme-gateway.hicaspian.com/api/v1/shops/search',
    { keyword, lat, lng },   // GCJ-02 坐标；或改用 address_id
    {
      headers: {
        'Authorization': `Bearer ${CLAWDOT_API_KEY}`,
        'X-Consent-Grant-Id': CONSENT_GRANT_ID,
        'Content-Type': 'application/json'
      }
    }
  );

  return response.data;
}

// 使用
searchShops('生椰拿铁', 39.9836, 116.3164).then(data => {
  console.log('搜索结果:', data.shops);
});
```

## 常见问题

<details>
<summary>我的 Agent 平台不在列表中怎么办？</summary>

你可以：
1. 使用 REST API 自行集成（参考 [接入指南](/skills/integration-guide)）
2. 联系我们 support@clawdot.com，申请添加新的平台集成
3. 贡献 MCP 服务器实现（开源项目）

</details>

<details>
<summary>不同平台的 API Key 是否相同？</summary>

是的，Clawdot 为每个 Agent 应用生成唯一的 API Key。你可以在多个平台使用同一个 API Key，但建议为不同平台创建不同的 Agent（便于监控和管理）。

</details>

<details>
<summary>如何在生产环境中安全地管理 API Key？</summary>

最佳实践：
- 使用环境变量或密钥管理服务（如 HashiCorp Vault、AWS Secrets Manager）
- 不要在代码中硬编码 API Key
- 在 Portal 中按需轮换 / 禁用 API Key（被禁用的 Key 立即失效）
- API Key 只标识 Agent；用户级访问由各用户的 consent grant（`cg_` 前缀）独立控制

</details>

<details>
<summary>MCP 和 REST API 有什么区别？</summary>

**MCP**：
- 标准化协议，自动工具发现
- 适合与大模型深度集成
- 配置简单，无需自行处理 HTTP

**REST API**：
- 通用 HTTP 接口，完全控制
- 适合自建应用和企业系统
- 学习成本稍高，灵活性更强

</details>
