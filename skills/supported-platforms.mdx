## 支持的平台

`takeout`（ClawDot 外卖助手）是一个**装上即用的技能包**——把它安装到你的 Agent，你的 Agent 就具备了搜店、点菜、下单、查单的外卖能力。目前支持三个平台：

<CardGroup cols={3}>
  <Card title="Claude Code" icon="terminal">
    解压到 skills 目录，含 SKILL.md + scripts/clawdot.py，靠技能 description 自动触发。
  </Card>

  <Card title="OpenClaw" icon="bot">
    安装一份 SKILL.md，由 OpenClaw 加载并按需调用。
  </Card>

  <Card title="Codex" icon="code">
    在项目根写入 AGENTS.md，供 Codex 读取技能说明。
  </Card>
</CardGroup>

<Info>
本页只讲「安装 takeout 技能」。如果你想自己编排底层的 18 个裸工具（不经技能封装），见 [MCP 概览](/mcp/overview)。
</Info>

## 一键安装

安装脚本会从最新 [Release](https://github.com/clawdot/open-gateway-clawdot-skill/releases) 下载技能包、校验 `sha256`、解压到当前平台对应的位置。命令格式统一为 `install.sh ... takeout <platform>`：

<Tabs>
  <Tab title="Claude Code">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/clawdot/open-gateway-clawdot-skill/main/install.sh | bash -s -- takeout claude-code
    ```

    - **装到哪**：解压到 Claude Code 的 skills 目录。
    - **包含什么**：`SKILL.md`（技能说明）+ `scripts/clawdot.py`（MCP CLI 执行脚本）。
    - **怎么触发**：Claude Code 读取技能的 `description`，当你提到点外卖、想吃什么、饿了等需求时**自动触发**该技能，再由它调用 `scripts/clawdot.py` 完成各个命令。
  </Tab>

  <Tab title="OpenClaw">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/clawdot/open-gateway-clawdot-skill/main/install.sh | bash -s -- takeout openclaw
    ```

    - **装到哪**：安装一份 `SKILL.md` 到 OpenClaw 的技能位置。
    - **怎么触发**：OpenClaw 加载该 `SKILL.md`，按其中的说明在需要时调用技能。
  </Tab>

  <Tab title="Codex">
    ```bash
    # 在项目根目录执行
    curl -fsSL https://raw.githubusercontent.com/clawdot/open-gateway-clawdot-skill/main/install.sh | bash -s -- takeout codex
    ```

    - **装到哪**：在项目根目录写入 `AGENTS.md`。
    - **怎么触发**：Codex 读取 `AGENTS.md` 中的技能说明，按需调用。
  </Tab>
</Tabs>

<Info>
默认安装最新版。如需固定版本，在命令末尾追加版本号，例如 `... takeout claude-code v1.0.0`。
</Info>

## 装完配置 `.env`

三个平台装完后，都在技能根目录放一个 `.env`。**唯一必填的是 `API_KEY`**（你的 Agent 身份，`clw_` 前缀）；`GATEWAY_MCP_URL` 用默认即可（可不填）。

```bash
GATEWAY_MCP_URL=https://eleme-gateway.hicaspian.com/mcp/v1  # MCP 端点（留默认即可，可不填）
API_KEY=clw_your_api_key                                    # 唯一必填：Agent 身份
# CONSENT_GRANT_ID=                                          # 只读预注入（可选）；正常流程绑定后凭证存共享缓存 ~/.clawdot/
```

- `clw_` 开头的 **API Key** 在 [控制台 → Agents](https://console.hicaspian.com/agents) 创建 Agent、开通外卖能力时获取。
- 用户授权（`cg_` 前缀）**无需配置**：用户首次走一次短信或 H5 绑定后，凭证写入共享缓存（`~/.clawdot/credentials.json`，按 API_KEY + 手机号隔离）；`CONSENT_GRANT_ID` 仅作无状态部署的只读预注入项。授权与绑定的细节见 [安全模型](/skills/security-model)。

## 安装后能做什么

装好并填好 `API_KEY` 后，你的 Agent 就能驱动 `takeout` 跑完整条外卖链路——搜店、看菜单、预览、下单、查配送状态。每个动作的参数、下单 item 模型、以及成功/失败信号，见 [外卖助手](/skills/takeout)。

## 常见问题

<details>
<summary>三个平台用的是同一个技能包吗？</summary>

是的，同一个 `takeout` 技能包，区别只在**适配层**：Claude Code 用 `SKILL.md` + `scripts/clawdot.py`，OpenClaw 用 `SKILL.md`，Codex 用 `AGENTS.md`。核心的执行脚本与交互指南（GUIDE）三平台共用。

</details>

<details>
<summary>能装到指定版本吗？</summary>

可以。默认从最新 Release 安装；在安装命令末尾追加版本号即可固定，例如 `... takeout claude-code v1.0.0`。脚本会按该版本下载并校验 `sha256`。

</details>

<details>
<summary>我想自己调用底层工具，而不是用这个技能包？</summary>

可以。网关对外还暴露一套 MCP 工具契约（18 个裸工具），适合你在自建 Agent 里自行编排下单链路。见 [MCP 概览](/mcp/overview)。技能包（本页）则是把这些动作封装好、装上即用，无需自己拼接。

</details>
