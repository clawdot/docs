## 钉钉 Agent

钉钉 Agent 是企业场景中最常见的 AI 助手形式，可以集成到钉钉应用市场，为员工和用户提供本地生活服务。

### 快速开始

<Tabs>
  <Tab title="集成步骤">
    1. **注册钉钉开发者账号**
       - 访问 [钉钉开放平台](https://open.dingtalk.com)
       - 创建企业应用

    2. **创建 Agent**
       在 [Clawdot Portal](http://console.hicaspian.com/agents) 创建专用于钉钉的 Agent，记录 API Key（`clw_` 前缀）

    3. **配置 WebHook**
       在钉钉应用设置中，配置 Clawdot Skills API 作为消息处理端点

    4. **实现消息处理**
       在你的服务端实现与钉钉消息交互的逻辑

    5. **发布应用**
       通过钉钉应用市场发布，供组织内用户或公众使用
  </Tab>

  <Tab title="代码示例">
    ```python
    import asyncio
    from flask import Flask, request
    import hmac
    import hashlib
    import base64
    import time
    import json
    import os

    from mcp import ClientSession
    from mcp.client.streamable_http import streamablehttp_client

    app = Flask(__name__)

    DINGTALK_BOT_SECRET = os.getenv("DINGTALK_BOT_SECRET")
    CLAWDOT_API_KEY = os.getenv("CLAWDOT_API_KEY")
    # Gateway 原生 MCP 端点（Streamable HTTP）
    GATEWAY_MCP_URL = "http://eleme-gateway.hicaspian.com/mcp/v1"

    def sign_message(timestamp, secret):
        """钉钉消息签名验证"""
        message = f"{timestamp}\n{secret}".encode('utf-8')
        sign = hmac.new(
            secret.encode('utf-8'),
            message,
            hashlib.sha256
        ).digest()
        return base64.b64encode(sign).decode('utf-8')

    @app.route("/webhook/dingtalk", methods=["POST"])
    def handle_dingtalk_message():
        """处理钉钉 WebHook 消息"""
        timestamp = request.headers.get("X-Dingtalk-Timestamp")
        sign = request.headers.get("X-Dingtalk-Sign")

        # 验证消息完整性
        expected_sign = sign_message(timestamp, DINGTALK_BOT_SECRET)
        if sign != expected_sign:
            return {"code": 401, "message": "Unauthorized"}, 401

        data = request.json
        conversation_id = data.get("conversationId")
        sender_id = data.get("senderId")
        text = data.get("text", {}).get("content", "").strip()

        # 提取用户意图
        if "外卖" in text or "点餐" in text:
            # 搜索商店
            shops = search_shops_for_dingtalk(text, sender_id)
            reply = format_shop_list_for_dingtalk(shops)
        elif "订单" in text or "查询" in text:
            # 查询订单
            order = get_order_for_dingtalk(sender_id)
            reply = format_order_for_dingtalk(order)
        else:
            reply = "你好，我可以帮助你查询外卖、商超等本地生活服务。"

        # 发送回复到钉钉
        send_dingtalk_message(conversation_id, reply)

        return {"code": 0, "message": "ok"}, 200

    async def call_gateway_tool(tool_name, args):
        """通过 MCP 客户端调用 Gateway 工具

        Agent 身份走连接层 Authorization 头；用户授权 consent_grant_id 作为工具参数。
        """
        headers = {"Authorization": f"Bearer {CLAWDOT_API_KEY}"}
        async with streamablehttp_client(GATEWAY_MCP_URL, headers=headers) as (read, write, _):
            async with ClientSession(read, write) as session:
                await session.initialize()
                return await session.call_tool(tool_name, args)

    def search_shops_for_dingtalk(query, user_id):
        """调用 Gateway 的 search_shops 工具搜索商店"""
        consent_grant_id = get_consent_grant(user_id)  # 获取该用户的授权（cg_ 前缀）

        # 用户授权作为工具参数传入，不走请求头
        result = asyncio.run(call_gateway_tool("search_shops", {
            "consent_grant_id": consent_grant_id,
            "keyword": query,
            "lat": 39.9836,   # GCJ-02 坐标，应从用户位置服务获取
            "lng": 116.3164,
        }))
        return result.get("shops", [])  # shops[]：shop_id、cart_id、next_offset?

    def format_shop_list_for_dingtalk(shops):
        """格式化商店列表为钉钉卡片"""
        cards = []
        for shop in shops:
            # 金额字段单位为分（整数），展示时除以 100
            delivery_fee_yuan = shop.get("delivery_fee", 0) / 100
            cards.append({
                "title": shop["name"],
                "actionURL": f"https://your-app.com/shop/{shop['shop_id']}",
                "content": f"评分: {shop.get('rating', '-')}⭐ | {shop.get('distance_text', '')} | 配送费: ¥{delivery_fee_yuan:.2f}"
            })
        return {"cards": cards}

    def send_dingtalk_message(conversation_id, content):
        """发送消息到钉钉"""
        # 钉钉 API 实现
        pass

    def get_consent_grant(user_id):
        """从数据库获取用户的 consent grant（cg_ 前缀）"""
        # 用户首次使用时走绑定流程（request_user_bind + verify_user_bind）
        # 拿到 consent_grant_id 后持久化，后续请求复用
        pass

    if __name__ == "__main__":
        app.run(port=5000)
    ```
  </Tab>

  <Tab title="最佳实践">

## Kimi Agent

月之暗面 Kimi 是国内领先的大语言模型，支持 Agent 开发和 Function Calling。

### 快速开始

<Tabs>
  <Tab title="集成步骤">
    1. **注册 Kimi 开发者**
       - 访问 [Kimi 开放平台](https://kimi.moonshot.cn)
       - 创建应用并获取 API Key

    2. **创建 Clawdot Agent**
       在 [Clawdot Portal](http://console.hicaspian.com/agents) 创建 Agent，记录 API Key（`clw_` 前缀）

    3. **定义 Function Schema**
       在 Kimi 应用中注册 Clawdot Gateway 的 API 为 Function Calling 工具

    4. **测试集成**
       使用 Kimi API 发送请求，验证 Function Calling 工作正常

    5. **部署上线**
       将 Agent 发布到 Kimi 应用市场
  </Tab>

  <Tab title="代码示例">
    ```python
    import asyncio
    import requests
    import json
    import os

    from mcp import ClientSession
    from mcp.client.streamable_http import streamablehttp_client

    KIMI_API_KEY = os.getenv("KIMI_API_KEY")
    CLAWDOT_API_KEY = os.getenv("CLAWDOT_API_KEY")
    # Gateway 原生 MCP 端点（Streamable HTTP）
    GATEWAY_MCP_URL = "http://eleme-gateway.hicaspian.com/mcp/v1"

    def call_kimi_with_function_calling(user_message, consent_grant_id):
        """使用 Kimi API 和 Function Calling"""

        # 定义可用的 Function（Clawdot Gateway 工具，与下单链路一一对应）。
        # 完整下单链路：search_shops → get_shop_menu → quote_cart →
        # select_address → preview_order → create_order → get_sign_action。
        # 这里只列搜索 / 菜单 / 预览 / 下单四步作为示例。
        tools = [
            {
                "type": "function",
                "function": {
                    "name": "search_shops",
                    "description": "搜索 / 浏览本地商家（不传 keyword 为浏览附近店铺）",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "keyword": {
                                "type": "string",
                                "description": "店名 / 品类 / 商品名；省略则浏览附近店铺"
                            },
                            "address_id": {
                                "type": "string",
                                "description": "已保存地址 ID；或改用 lat/lng（GCJ-02）"
                            },
                            "lat": {"type": "number", "description": "纬度（GCJ-02），无 address_id 时必传"},
                            "lng": {"type": "number", "description": "经度（GCJ-02），无 address_id 时必传"}
                        }
                    }
                }
            },
            {
                "type": "function",
                "function": {
                    "name": "get_shop_menu",
                    "description": "获取商家菜单（含可下单的 item_id / sku_id）",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "shop_id": {"type": "string", "description": "来自 search_shops"},
                            "cart_id": {"type": "string", "description": "来自 search_shops，已封装配送坐标"},
                            "keyword": {"type": "string", "description": "可选，按名称 / 分类 / 描述过滤"}
                        },
                        "required": ["shop_id", "cart_id"]
                    }
                }
            },
            {
                "type": "function",
                "function": {
                    "name": "preview_order",
                    "description": "预览订单，返回最终价格（单位分）与 preview_id + confirmation_token",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "shop_id": {"type": "string"},
                            "cart_id": {"type": "string"},
                            "address_id": {"type": "string", "description": "来自 select_address"},
                            "items": {
                                "type": "array",
                                "items": {
                                    "type": "object",
                                    "properties": {
                                        "item_id": {"type": "string"},
                                        "sku_id": {"type": "string"},
                                        "quantity": {"type": "integer"}
                                    }
                                }
                            }
                        },
                        "required": ["shop_id", "cart_id", "address_id", "items"]
                    }
                }
            },
            {
                "type": "function",
                "function": {
                    "name": "create_order",
                    "description": "用同一次预览的 preview_id + confirmation_token 正式下单",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "preview_id": {"type": "string", "description": "来自 preview_order"},
                            "confirmation_token": {"type": "string", "description": "来自同一次 preview_order"}
                        },
                        "required": ["preview_id", "confirmation_token"]
                    }
                }
            }
        ]

        # 调用 Kimi API
        url = "https://api.moonshot.cn/openai/v1/chat/completions"
        headers = {
            "Authorization": f"Bearer {KIMI_API_KEY}",
            "Content-Type": "application/json"
        }

        payload = {
            "model": "moonshot-v1-8k",
            "messages": [
                {"role": "user", "content": user_message}
            ],
            "tools": tools,
            "tool_choice": "auto"
        }

        response = requests.post(url, json=payload, headers=headers)
        result = response.json()

        # 处理 Function Calling 响应
        if result.get("choices"):
            choice = result["choices"][0]
            if choice.get("finish_reason") == "tool_calls":
                for tool_call in choice.get("tool_calls", []):
                    function_name = tool_call["function"]["name"]
                    function_args = json.loads(tool_call["function"]["arguments"])

                    # 调用 Clawdot Gateway API
                    function_result = call_clawdot_function(
                        function_name,
                        function_args,
                        consent_grant_id
                    )

                    print(f"Function: {function_name}")
                    print(f"Result: {function_result}")

        return result

    def call_clawdot_function(function_name, args, consent_grant_id):
        """通过 MCP 客户端调用 Clawdot Gateway 工具

        Kimi 返回的 function_name 与 Gateway 工具名一一对应，直接作为 call_tool 的工具名。
        用户授权 consent_grant_id 作为工具参数注入，不走请求头。
        """

        async def _invoke():
            headers = {"Authorization": f"Bearer {CLAWDOT_API_KEY}"}  # Agent 身份
            async with streamablehttp_client(GATEWAY_MCP_URL, headers=headers) as (read, write, _):
                async with ClientSession(read, write) as session:
                    await session.initialize()
                    return await session.call_tool(function_name, {
                        "consent_grant_id": consent_grant_id,
                        **args,
                    })

        return asyncio.run(_invoke())

    # 使用示例
    user_message = "我想在中关村点一份外卖"
    consent_grant_id = "cg_..."  # 用户授权，首次使用走绑定流程获取

    result = call_kimi_with_function_calling(user_message, consent_grant_id)
    ```
  </Tab>

  <Tab title="最佳实践">
    - **Function 超时处理**：设置合理的超时时间，避免 Kimi API 等待过长
    - **智能重试**：对于临时失败，使用指数退避重试
    - **缓存 Schema**：缓存 Function Schema，减少重复调用
    - **监控成本**：追踪 API 调用成本和使用情况

## Claude Desktop (MCP)

Claude Desktop 是 Anthropic 官方推出的客户端，原生支持 MCP（Model Context Protocol）协议。

### 快速开始

<Tabs>
  <Tab title="安装和配置">
    **1. 安装 Claude Desktop**
    - 下载 [Claude Desktop](https://claude.ai/download)
    - 按照指示完成安装和登录

    **2. 创建 Clawdot Agent**
    在 [Clawdot Portal](http://console.hicaspian.com/agents) 创建 Agent 并获取 API Key（`clw_` 前缀）

    **3. 配置 MCP 服务器**
    Gateway 原生提供 Streamable HTTP MCP 端点（`http://eleme-gateway.hicaspian.com/mcp/v1`），
    Agent 身份通过 `Authorization: Bearer clw_...` 请求头在连接层传递。编辑
    `~/.claude-desktop/config.json`：

    ```json
    {
      "mcpServers": {
        "clawdot-skills": {
          "url": "http://eleme-gateway.hicaspian.com/mcp/v1",
          "headers": {
            "Authorization": "Bearer clw_your_api_key_here"
          }
        }
      }
    }
    ```

    **4. 重启 Claude Desktop**
    - 关闭 Claude Desktop
    - 重新打开，等待 MCP 服务器连接
    - 在工具栏中查看可用的 Gateway 技能

    **5. 开始使用**
    - 在对话中提及外卖、商超等本地生活需求
    - Claude 会自动调用相应的 Gateway 技能
  </Tab>

  <Tab title="MCP 客户端调用">
    Gateway 已原生提供 MCP 端点（`/mcp/v1`），Claude Desktop **直接连接即可**（见上一
    标签页的配置），无需自己再搭一层本地代理。如果你想在脚本里手动验证连接、或在自建
    Agent 中复用同一套工具，可用任意 MCP 客户端直连。Agent 身份走连接层
    `Authorization` 头；用户授权 `consent_grant_id`（`cg_` 前缀）作为每个业务工具的参数：

    ```python
    import asyncio

    from mcp import ClientSession
    from mcp.client.streamable_http import streamablehttp_client

    GATEWAY_MCP_URL = "http://eleme-gateway.hicaspian.com/mcp/v1"
    API_KEY = "clw_your_api_key_here"            # Agent 身份，连接层请求头
    CONSENT_GRANT_ID = "cg_..."                  # 用户授权，工具参数

    async def main():
        headers = {"Authorization": f"Bearer {API_KEY}"}
        async with streamablehttp_client(GATEWAY_MCP_URL, headers=headers) as (read, write, _):
            async with ClientSession(read, write) as session:
                await session.initialize()

                # 连上即可自动发现全部 18 个工具
                tools = await session.list_tools()
                print([t.name for t in tools.tools])

                # 用户授权作为工具参数传入，不走请求头
                shops = await session.call_tool("search_shops", {
                    "consent_grant_id": CONSENT_GRANT_ID,
                    "keyword": "咖啡",
                    "lat": 39.9836,   # GCJ-02 坐标；或改用 address_id
                    "lng": 116.3164,
                })
                print(shops)   # 含 shops[]：shop_id、cart_id、next_offset?

    asyncio.run(main())
    ```

## 自建 Agent

如果你的 Agent 平台未在上述列表中，只要它支持 **MCP（Model Context Protocol）** 或通用工具调用，就能按 Gateway 的工具契约自行接入——和 Claude Desktop / Cursor 走的是同一条 MCP 通道，无需为外卖能力单独搭一套接口。

### 接入要点

1. **连接**：用任意 MCP 客户端，通过 Streamable HTTP 连到 `http://eleme-gateway.hicaspian.com/mcp/v1`。
2. **Agent 身份**：在连接层请求头携带 `Authorization: Bearer clw_...`（在 [Clawdot Portal](http://console.hicaspian.com/agents) 创建 Agent 时生成）。
3. **用户授权**：每个业务工具调用都带 `consent_grant_id` 参数（`cg_` 前缀）；首次使用先走 `request_user_bind` / `verify_user_bind` 拿到它。
4. **按链路调用工具**：`search_shops` → `get_shop_menu` → `quote_cart` → `select_address` → `preview_order` → `create_order` → `get_sign_action`。所有跨步 ID 由网关签发、原样回传。

<Info>
Gateway 已原生暴露 MCP 端点，绝大多数客户端**直接连接即可**，无需自行封装 HTTP。完整工具清单、参数与返回字段见 [MCP 概览](/mcp/overview)。
</Info>

**快速示例（MCP 客户端调用工具）：**

```python
# 任意 MCP 客户端均可，这里以官方 SDK 为例
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

GATEWAY_MCP_URL = "http://eleme-gateway.hicaspian.com/mcp/v1"
API_KEY = "clw_your_api_key_here"            # Agent 身份，连接层请求头
CONSENT_GRANT_ID = "cg_..."                  # 用户授权，工具参数

async def search_shops(keyword):
    headers = {"Authorization": f"Bearer {API_KEY}"}
    async with streamablehttp_client(GATEWAY_MCP_URL, headers=headers) as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()
            # 用户授权作为工具参数传入，不走请求头
            result = await session.call_tool("search_shops", {
                "consent_grant_id": CONSENT_GRANT_ID,
                "keyword": keyword,
                "lat": 39.9836,   # GCJ-02 坐标；或改用 address_id
                "lng": 116.3164,
            })
            return result   # 含 shops[]：shop_id、cart_id、next_offset?
```

## 常见问题

<details>
<summary>我的 Agent 平台不在列表中怎么办？</summary>

你可以：
1. 只要平台支持 MCP 或工具调用，按上文「自建 Agent」连接 `http://eleme-gateway.hicaspian.com/mcp/v1` 自行接入（参考 [接入指南](/skills/integration-guide)）
2. 联系我们 support@clawdot.com，申请添加新的平台集成

</details>

<details>
<summary>不同平台的 API Key 是否相同？</summary>

是的，Clawdot 为每个 Agent 应用生成唯一的 API Key。你可以在多个平台使用同一个 API Key，但建议为不同平台创建不同的 Agent（便于监控和管理）。

</details>

<details>
<summary>如何在生产环境中安全地管理 API Key？</summary>

最佳实践：
- 使用环境变量或密钥管理服务（如 HashiCorp Vault、AWS Secrets Manager）
- 不要在代码中硬编码 API Key
- 在 Portal 中按需轮换 / 禁用 API Key（被禁用的 Key 立即失效）
- API Key 只标识 Agent；用户级访问由各用户的 consent grant（`cg_` 前缀）独立控制

</details>

<details>
<summary>为什么统一用 MCP 接入？</summary>

Gateway 对外只暴露一套 **MCP 工具契约**，所有平台（含自建 Agent）都走同一条通道：

- **标准化协议，自动工具发现**：客户端连上即可拿到全部 18 个工具及其参数、返回字段，无需逐个对接口
- **与大模型深度集成**：工具名、参数语义对模型友好，适合直接交给 Agent 自主编排下单链路
- **配置简单**：Streamable HTTP 直连 `/mcp/v1`，Agent 身份走 `Authorization` 头、用户授权走 `consent_grant_id` 参数，无需自行封装底层调用

完整工具清单见 [MCP 概览](/mcp/overview)。

</details>
