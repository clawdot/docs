## errand_list_goods_categories

返回可选的物品品类清单，摆给用户挑要寄送的东西属于哪一类。选中项的 `code` 回填 `errand_quote` 的 `goods_category_code`。

清单共 15 项，前 7 项为贵重品类（`valuable: true`），后 8 项为普通品类，按返回顺序展示即可分成两组。挑最接近的一项即可，没有贴合的选「其他」。

<Note>
  **物品名称不影响理赔**：`errand_quote` 里的 `goods[].name` 按用户原话填写即可，平台不解析名称，理赔只看品类，所以品类务必选对。
</Note>

<Note>
  **贵重品类建议询问是否保价**：`valuable: true` 的品类单件货值通常较高，建议此时询问用户是否需要保价（下单时传 `insured: true`）。保价会额外收费，请勿代用户开启。
</Note>

清单固定不变，可以缓存，但请始终按接口返回的 `code` 渲染，不要按下标或写死的清单取值——品类清单历史上调整过数量，写死会在下次调整时失效。

### 参数

本工具无需参数，直接调用即可返回完整清单。

### 返回

| 字段 | 类型 | 说明 |
|------|------|------|
| `categories` | array | 品类清单，共 15 项；前 7 项为贵重品类 |
| `categories[].code` | integer | 品类码，回填 `errand_quote` 的 `goods_category_code` |
| `categories[].name` | string | 品类名称，展示给用户挑选 |
| `categories[].valuable` | boolean | 该品类单件货值较高；为 `true` 时建议询问用户是否需要保价 |

### 错误码

| code | 说明 |
|------|------|
| `AUTH_REQUIRED` / `AUTH_INVALID` | 缺少或无效的 API Key |
| `CAP_NOT_BOUND` | 该 Agent 未开通跑腿能力 |

完整错误码见 [错误处理](/errand/errors)。
