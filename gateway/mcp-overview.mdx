Clawdot Gateway 对外通过 **MCP (Model Context Protocol)** 提供能力，使用 **Streamable HTTP** 传输协议。MCP 暴露 **18 个工具**，覆盖授权绑定、地址、店铺、购物车、优惠券、下单到免密支付的完整外卖链路。

<Note>
  本页只是入口。完整的连接方式、认证与下单链路见 [MCP 概览](/mcp/overview)；全部 18 个工具的签名与参数见 [MCP 工具参考](/mcp/overview)，这两页是权威来源。
</Note>

## 要点速览

- **连接端点：** `http://eleme-gateway.hicaspian.com/mcp/v1`。网关把 MCP 应用挂载在 `/mcp` 下，FastMCP 的内部路由是版本化的（`/v1`），所以对外公开端点是 `/mcp/v1`。
- **认证：** 两层认证——**API Key**（连接层 `Authorization: Bearer clw_...` 请求头）标识 Agent，**consent grant**（`cg_` 前缀）标识已授权用户。详见 [认证机制](/gateway/authentication)。
- **错误：** 统一 `{"error": {"code", "message"}}` 格式，详见 [错误处理](/gateway/error-handling)。

<Warning>
  `consent_grant_id` 作为 MCP **每个工具的参数**传入，不放进请求头。
</Warning>
