Clawdot Gateway 在 REST API 之外同时提供 **MCP (Model Context Protocol)** 接口，使用 **Streamable HTTP** 传输协议，底层复用与 REST API 相同的服务层。MCP 暴露 **18 个工具**，每个对应一个 REST 端点；除 `consent_grant_id` 外，工具参数与对应 REST 端点的请求体字段一致。

<Note>
  本页只是入口。完整的连接方式、认证与下单链路见 [MCP 概览](/mcp/overview)；全部 18 个工具的签名与参数见 [MCP 工具参考](/mcp/overview)，这两页是权威来源。
</Note>

## 要点速览

- **连接端点：** `http://eleme-gateway.hicaspian.com/mcp/v1`。网关把 MCP 应用挂载在 `/mcp` 下，FastMCP 的内部路由是版本化的（`/v1`），所以对外公开端点是 `/mcp/v1`。
- **认证：** 两层认证与 REST API 一致——**API Key**（`Authorization: Bearer clw_...` 请求头）标识 Agent，**consent grant**（`cg_` 前缀）标识已授权用户。详见 [认证机制](/gateway/authentication)。
- **错误：** 统一 `{"error": {"code", "message"}}` 格式，详见 [错误处理](/gateway/error-handling)。

<Warning>
  `consent_grant_id` 是 MCP **每个工具的参数**，不是请求头；`X-Consent-Grant-Id` 请求头只用于 REST API。
</Warning>
