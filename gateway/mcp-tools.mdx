Clawdot Gateway 通过 MCP（Model Context Protocol）对外暴露 **18 个工具**，覆盖授权绑定、地址、店铺、购物车、优惠券、下单到免密支付的完整外卖链路。

<Note>
  本页只是概览。**18 个工具的完整参数与返回值以 [MCP 工具参考](/mcp/overview) 为权威**，本页不重复维护字段表。
</Note>

## 接入要点

- **挂载与端点：** MCP 应用以 `app.mount("/mcp", create_mcp_app())` 挂在网关上，FastMCP 路由版本化，公开端点是 `/mcp/v1`。传输使用 streamable HTTP。
- **Agent 身份：** 连接层通过 `Authorization: Bearer clw_...` 请求头传 API Key，标识调用方 Agent。
- **用户授权：** `consent_grant_id`（`cg_` 前缀）作为**每个工具的参数**传入，不放进请求头。
- **金额单位：** 分（整数）。
- **错误：** 统一 `{"error": {"code", "message"}}` 结构，详见 [错误处理](/gateway/error-handling)。

认证模型（API Key 标识 Agent + consent grant 标识已授权用户）详见 [认证机制](/gateway/authentication)。

## 工具一览

| MCP 工具 | 说明 |
|---|---|
| `request_user_bind` | 发起用户绑定（SMS 验证码 / H5），仅需 Agent 身份 |
| `verify_user_bind` | 确认绑定，成功铸造 `consent_grant_id` |
| `get_user_auth_status` | 查询用户授权状态 |
| `revoke_user_bind` | 解除绑定，旧授权即时失效 |
| `get_homepage_url` | 获取淘闪主页链接 |
| `search_addresses` | 搜索 / 列出收货地址 |
| `select_address` | 选择 / 保存收货地址，得 `address_id` |
| `update_address` | 编辑地址门牌 / 标签 |
| `search_shops` | 搜索 / 浏览商家，得 `shop_id` + `cart_id` |
| `get_shop_menu` | 获取商家菜单与商品规格 |
| `get_shop_share_url` | 获取商家分享链接 |
| `quote_cart` | 购物车算价，得 `quote_id` |
| `list_coupons` | 账户优惠券列表 |
| `preview_order` | 预览订单，得 `preview_id` + `confirmation_token` |
| `create_order` | 创建订单，得 `order_id` |
| `get_order_status` | 查询订单状态 |
| `get_sign_action` | 获取免密签约动作（H5 链接）|
| `get_sign_status` | 查询免密签约状态 |

## 下单链路

`search_shops` 得 `shop_id` + `cart_id` → `get_shop_menu` 选品 → `quote_cart` 得 `quote_id` → `select_address` 得 `address_id` → `preview_order` 得 `preview_id` + `confirmation_token` → `create_order` 得 `order_id` → `get_sign_action` 完成免密签约。

详见 [MCP 工具参考](/mcp/overview)。
