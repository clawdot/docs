Clawdot Gateway 通过 MCP（Model Context Protocol）暴露 **18 个工具**，每个工具一一对应一个 REST 公开端点，覆盖授权绑定、地址、店铺、购物车、优惠券、下单到免密支付的完整外卖链路。

<Note>
  本页只是概览。**18 个工具的完整参数、返回值与对应端点以 [MCP 工具参考](/mcp/overview) 为权威**，本页不重复维护字段表。
</Note>

## 接入要点

- **挂载与端点：** MCP 应用以 `app.mount("/mcp", create_mcp_app())` 挂在网关上，FastMCP 路由版本化，公开端点是 `/mcp/v1`。传输使用 streamable HTTP。
- **Agent 身份：** 与 REST 一致，通过 `Authorization: Bearer clw_...` 请求头传 API Key。
- **用户授权：** `consent_grant_id`（`cg_` 前缀）作为**每个工具的参数**传入，**不是** `X-Consent-Grant-Id` 请求头（那是 REST 的传法）。
- **参数对齐：** 除 `consent_grant_id` 外，工具参数与对应 REST 端点的请求体一致。
- **金额单位：** 分（整数）。
- **错误：** 统一 `{"error": {"code", "message"}}` 结构，详见 [错误处理](/gateway/error-handling)。

认证模型（API Key 标识 Agent + consent grant 标识已授权用户）详见 [认证机制](/gateway/authentication)。

## 工具 → 端点对照

| MCP 工具 | REST 端点 |
|---|---|
| `request_user_bind` | `POST /auth/bind/request` |
| `verify_user_bind` | `POST /auth/bind/verify` |
| `get_user_auth_status` | `GET /auth/status` |
| `revoke_user_bind` | `POST /auth/unbind` |
| `get_homepage_url` | `POST /auth/homepage-url` |
| `search_addresses` | `POST /addresses/search` |
| `select_address` | `POST /addresses/select` |
| `update_address` | `POST /addresses/update` |
| `search_shops` | `POST /shops/search` |
| `get_shop_menu` | `POST /shops/menu` |
| `get_shop_share_url` | `POST /shops/share-url` |
| `quote_cart` | `POST /cart/quote` |
| `list_coupons` | `POST /coupons/list` |
| `preview_order` | `POST /orders/preview` |
| `create_order` | `POST /orders/create` |
| `get_order_status` | `GET /orders/{order_id}` |
| `get_sign_action` | `POST /payment/sign-action` |
| `get_sign_status` | `GET /payment/sign-status` |

## 下单链路

`search_shops` 得 `shop_id` + `cart_id` → `get_shop_menu` 选品 → `quote_cart` 得 `quote_id` → `select_address` 得 `address_id` → `preview_order` 得 `preview_id` + `confirmation_token` → `create_order` 得 `order_id` → `get_sign_action` 完成免密签约。

详见 [MCP 工具参考](/mcp/overview)。
