## 什么是 Gateway

Clawdot Gateway 是 Clawdot 的**协议层 + 发现层**（Protocol Hub + Discovery Layer），位于 4 层架构的第 3 层。它的核心职责是：

1. **定义标准协议** — 制定统一的商户接口规范（菜单查询、下单履约等）
2. **连接商户** — 支持两类商户接入：
   - **Proxy 层** — 代理饿了么/美团/高德等平台商户（冷启动阶段）
   - **独立 Agent** — 大型商户自建 Agent，直接实现标准协议（长期生态）
3. **统一接口** — 为 AI Agent 提供统一的 MCP 接口，隐藏商户差异

## Gateway 帮你处理了什么

| 你需要做的 | Gateway 帮你做的 |
|-----------|-----------------|
| 传入 `shop_id` | 多种 ID 格式自动转换 |
| 传入商品列表 | 规格/属性/加料解析 + 互斥规则计算 |
| 调用一次 preview | 两次渲染 + 自动选最优优惠券 |
| 传入 API Key | Token 管理、签名、UA 适配 |
| 收到标准错误码 | 平台错误归类为统一格式 |

## 商户接入模式

Gateway 支持两种商户接入方式，灵活满足不同规模商户的需求：

<Tabs>
  <Tab title="Proxy 层（冷启动）">
    **用途：** 快速覆盖已有平台商户，无需商户改动

    - Clawdot 为饿了么、美团、高德等平台的商户提供统一代理
    - Agent 使用标准协议，Proxy 负责转换为平台 API
    - 占比逐步下降，作为过渡性方案

    → [了解 Proxy 工作原理](/gateway/merchant-onboarding)
  </Tab>

  <Tab title="独立 Agent（生态）">
    **用途：** 大型商户深度集成，完全自主

    - 大型连锁品牌（如茶百道）自建商户 Agent
    - 直接实现 Gateway 标准协议
    - 最终成为生态的主体

    → [开始独立接入](/gateway/merchant-onboarding)
  </Tab>
</Tabs>
