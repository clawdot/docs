## GET /orders/{order_id}

查询指定订单的状态和详情。

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| `Authorization` | 是 | `Bearer clw_...` |
| `X-User-Token` | 是 | 用户 Token |

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `order_id` | string | 饿了么订单号（从 [创建订单](/api-reference/orders/create) 返回的 `order_id`） |

### 响应

<Tabs>
  <Tab title="200 成功">
    ```json
    {
      "order_id": "12345678901234",
      "status": "created",
      "shop_name": "瑞幸咖啡(人民广场店)",
      "total_amount": 15.0,
      "created_at": "2026-03-30T10:15:30"
    }
    ```

    | 字段 | 类型 | 说明 |
    |------|------|------|
    | `order_id` | string | 饿了么订单号 |
    | `status` | string | 订单状态 |
    | `shop_name` | string | 商家名称 |
    | `total_amount` | float | 订单金额（元） |
    | `created_at` | string | 创建时间（ISO 8601） |
  </Tab>
  <Tab title="500 未找到">
    ```json
    {
      "error": {
        "code": "ORDER_FAILED",
        "message": "Order not found"
      }
    }
    ```
  </Tab>
</Tabs>

### 示例

```bash
curl -X GET "https://api.clawdot.ai/api/v1/orders/12345678901234" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-User-Token: your_user_token"
```
