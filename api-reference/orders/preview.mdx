## POST /orders/preview

对一个已算价的购物车做下单前预览：校验店铺 / 地址 / 商品、应用优惠券，返回最终价格明细，以及用于正式下单的 `preview_id` 与 `confirmation_token`。

<Note>
  **下单链路**：`/shops/search` 得 `shop_id` + `cart_id`（已含配送坐标）→ `/shops/menu` 选商品 → `/cart/quote` 算价得 `quote_id` → `/addresses/select` 得 `address_id` → **`/orders/preview`** 得 `preview_id` + `confirmation_token` → `/orders/create`。预览必须基于一个已存在的 `cart_id`。
</Note>

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| `Authorization` | 是 | `Bearer clw_...`（Agent 的 API Key）|
| `X-Consent-Grant-Id` | 是 | 用户授权 ID（`cg_...`）|
| `Content-Type` | 是 | `application/json` |

### 请求体

```json
{
  "shop_id": "<来自 /shops/search>",
  "cart_id": "<来自 /shops/search>",
  "quote_id": "<来自 /cart/quote，可选>",
  "address_id": "<来自 /addresses/select>",
  "items": [
    {
      "item_id": "670685166551",
      "sku_id": "5014584502270",
      "quantity": 1,
      "ingredient_option_ids": [],
      "remark": ""
    }
  ],
  "coupon_ids": null,
  "order_remark": "放门口"
}
```

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `shop_id` | string | 是 | — | 店铺 ID（来自 `/shops/search`）|
| `cart_id` | string | 是 | — | 购物车上下文 ID（来自 `/shops/search`，已封装店铺与配送坐标，故预览无需再传经纬度）|
| `quote_id` | string | 否 | `null` | 报价 ID（来自 `/cart/quote`）；提供后会校验报价上下文 |
| `address_id` | string | 是 | — | **网关地址 ID（字符串）**，原样使用 `/addresses/select` 返回的 `address_id` |
| `items` | array | 是 | — | 商品列表（见下）|
| `items[].item_id` | string | 是 | — | 商品 ID（来自 `/shops/menu`）|
| `items[].sku_id` | string | 否 | `null` | SKU ID |
| `items[].quantity` | integer | 是 | — | 数量，≥ 1 |
| `items[].ingredient_option_ids` | string[] | 否 | `[]` | 配料 / 做法选项 ID 列表（来自菜单项的可选项）|
| `items[].remark` | string | 否 | `""` | 单品备注 |
| `coupon_ids` | string[] \| null | 否 | `null` | 优惠券选择，三态见下 |
| `order_remark` | string | 否 | `""` | 订单备注（给骑手）|

<Warning>
  请求体**不接受未定义字段**（`extra=forbid`），多传会返回 422。早期文档中的 `lat` / `lng`、`specs` / `attrs` / 嵌套 `ingredients`、`note`、`session_id` 等字段均已不存在。
</Warning>

**`coupon_ids` 三态：**

- **不传该字段** → 网关自动选择最优券
- **传 `[]`（空数组）** → 明确不使用任何券
- **传 `["<coupon_id>", ...]`** → 使用指定券（券 ID 来自上一次预览返回的 `available_coupons[].coupon_id`）

### 响应

```json
{
  "preview_id": "prv_4f2a...",
  "confirmation_token": "cf_9b3e...",
  "shop": { "name": "瑞幸咖啡(人民广场店)" },
  "address": {
    "display_name": "上海市黄浦区...",
    "address_detail": "3 号楼 101",
    "city": ""
  },
  "items": [
    { "name": "生椰拿铁", "quantity": 1, "price": 1600 }
  ],
  "price": {
    "goods_price": 1600,
    "delivery_fee": 300,
    "packing_fee": 100,
    "discount": 500,
    "payable_price": 1500
  },
  "delivery": {
    "estimated_time_text": "35分钟",
    "delivery_type": null
  },
  "payment": {
    "requires_payment": true,
    "available_methods": ["default"]
  },
  "warnings": [],
  "available_coupons": [
    {
      "coupon_id": "cpn_1a2b...",
      "name": "满20减5",
      "amount": 500,
      "threshold": 2000,
      "available": true,
      "unavailable_reason": null
    }
  ],
  "selected_coupons": [
    { "coupon_id": "cpn_1a2b...", "name": "满20减5", "amount": 500 }
  ]
}
```

<Warning>
  所有金额字段单位为**分（整数）**，不是元。例如 `payable_price: 1500` 表示 ¥15.00。
</Warning>

| 字段 | 类型 | 说明 |
|------|------|------|
| `preview_id` | string | 预览 ID（`prv_`），传给 `/orders/create`；有效期约 10 分钟 |
| `confirmation_token` | string | 确认令牌（`cf_`），与 `preview_id` 一起传给 `/orders/create` |
| `shop.name` | string | 店铺名称 |
| `address.display_name` | string | 地址显示名 |
| `address.address_detail` | string | 门牌等详情 |
| `address.city` | string | 城市（当前恒为空串）|
| `items[].name` | string | 商品名 |
| `items[].quantity` | integer | 数量 |
| `items[].price` | integer | 单品价（分）|
| `price.goods_price` | integer | 商品小计（分）|
| `price.delivery_fee` | integer | 配送费（分）|
| `price.packing_fee` | integer | 打包费（分）|
| `price.discount` | integer | 优惠金额（分）|
| `price.payable_price` | integer | 应付金额（分）= 商品 + 配送 + 打包 − 优惠 |
| `delivery.estimated_time_text` | string \| null | 预计送达文案 |
| `delivery.delivery_type` | string \| null | 配送类型（当前为 `null`）|
| `payment.requires_payment` | boolean | 是否需要支付 |
| `payment.available_methods` | string[] | 可用支付方式 |
| `warnings` | array | 预览告警（如商品变更）|
| `available_coupons` | array | 可用优惠券；`coupon_id` 可回传到 `coupon_ids` |
| `available_coupons[].amount` | integer | 券面额（分）|
| `available_coupons[].threshold` | integer | 使用门槛（分）|
| `available_coupons[].available` | boolean | 是否可用 |
| `available_coupons[].unavailable_reason` | string \| null | 不可用原因 |
| `selected_coupons` | array | 本次已应用的券（含 `coupon_id` / `name` / `amount`）|

### 错误码

| HTTP | code | 说明 |
|------|------|------|
| 401 | `CONSENT_GRANT_REQUIRED` | 缺少 `X-Consent-Grant-Id` 用户授权 |
| 401 | `CONSENT_GRANT_INVALID` | 用户授权无效 |
| 401 | `CONSENT_GRANT_EXPIRED` | 用户授权已过期，需重新授权 |
| 403 | `CAP_NOT_BOUND` | 该 Agent 未开通对应能力 |
| 403 | `CONSENT_GRANT_WRONG_CAP` | 该授权属于其它能力 / 服务商 |
| 422 | （参数校验） | REST 端请求体字段类型 / 必填 / 约束不满足由 pydantic 拦截，返回 FastAPI 默认 422（结构化校验体，非 `{error:{code}}`）。例如 `items[].quantity` 非整数或 < 1（`Field(ge=1)`）、请求体本体或 `items[]` 多传未定义字段（`extra=forbid`） |
| 400 | `PUBLIC_REFERENCE_INVALID` | `cart_id` / `quote_id` 无效或过期、`shop_id` 与 `cart_id` 不匹配，或 `address_id` 无效 |
| 502 | `ELEME_ERROR` | 上游预览 API 错误；稍后重试 |

完整错误码见 [错误处理](/gateway/error-handling)。

### 示例

```bash
curl -X POST "https://api.clawdot.ai/api/v1/orders/preview" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "shop_id": "<来自 /shops/search>",
    "cart_id": "<来自 /shops/search>",
    "address_id": "<来自 /addresses/select>",
    "items": [
      {"item_id": "670685166551", "sku_id": "5014584502270", "quantity": 1}
    ]
  }'
```
