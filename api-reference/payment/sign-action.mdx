## POST /payment/sign-action

为当前授权用户发起免密支付签约：网关先查询用户签约状态，未签约则向上游申请签约地址，并签发一个用于打开签约 H5 页的 `action`。已签约的用户不会返回签约链接。

<Note>
  **签约链路**：先调用本接口拿到 `action`；若 `action.action_type` 为 `open_h5`，把用户引导到 `action.action_url`（H5 签约页）完成签约，签约完成后浏览器跳回你传入的 `return_url`。随后用 `GET /payment/sign-status` 轮询签约结果。若 `action.action_type` 为 `none`，说明用户已签约，无需再打开页面。免密签约是发起免密支付类订单的前置条件。
</Note>

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| `Authorization` | 是 | `Bearer clw_...`（Agent 的 API Key）|
| `X-Consent-Grant-Id` | 是 | 用户授权 ID（`cg_...`）|
| `Content-Type` | 是 | `application/json` |

### 请求体

```json
{
  "return_url": "https://your-app.example.com/sign/callback"
}
```

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `return_url` | string | 是 | — | 用户在 H5 签约页完成签约后浏览器跳回的地址，由调用方提供；网关原样透传给上游签约页 |

### 响应

```json
{
  "action": {
    "action_id": "act_7c1d...",
    "action_type": "open_h5",
    "action_url": "https://render.alipay.com/p/s/...",
    "expires_at": "2026-06-16T08:30:00+00:00"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `action` | object | 待执行动作对象 |
| `action.action_id` | string | 动作 ID（`act_` 前缀），网关签发，用于追踪该动作 |
| `action.action_type` | string | `open_h5`（需打开 `action_url` 完成签约）或 `none`（用户已签约，无需任何操作）|
| `action.action_url` | string \| null | 签约 H5 页地址；`action_type` 为 `none` 时为 `null`，应原样在浏览器/WebView 打开，不要改写 |
| `action.expires_at` | string | 动作过期时间（ISO 8601，UTC）；有效期 30 分钟，过期后需重新发起 |

### 错误码

| HTTP | code | 说明 |
|------|------|------|
| 401 | `CONSENT_GRANT_REQUIRED` / `CONSENT_GRANT_INVALID` / `CONSENT_GRANT_EXPIRED` | 缺少、无效或已过期的用户授权；过期需重新授权 |
| 403 | `CAP_NOT_BOUND` / `CONSENT_GRANT_WRONG_CAP` | Agent 未开通该能力，或授权属于其它能力 / 服务商 |
| 502 | `ELEME_ERROR` | 淘宝闪购 / 饿了么上游 API 错误 |
| 502 | `SIGN_ADDRESS_NOT_FOUND` | 上游响应未返回签约地址 |
| 503 | `PROVIDER_NOT_AVAILABLE` | 服务商适配器暂不可用 |

完整错误码见 [错误处理](/gateway/error-handling)。

### 示例

```bash
curl -X POST "https://api.clawdot.ai/api/v1/payment/sign-action" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "return_url": "https://your-app.example.com/sign/callback"
  }'
```
