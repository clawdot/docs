## GET /auth/status

查询一个 `consent_grant_id` 当前的授权状态：是否仍有效绑定、授权覆盖的能力范围（`scopes`）、过期时间，以及未绑定时的下一步建议动作（`next_action`）。

<Note>
  **授权链路**：`/auth/bind/request` → `/auth/bind/verify` 得 `consent_grant_id` → 业务调用前可用 **`/auth/status`** 探活。该接口需要在请求头携带要查询的 `X-Consent-Grant-Id`（必填）；缺失时返回 `CONSENT_GRANT_REQUIRED`。一个 Agent 下可绑定多个用户，不带 grant 无法指定查哪个授权。
</Note>

<Note>
  **失效/过期不报错**：当 `consent_grant_id` 无效、已过期或属于其它能力时，本接口不抛错，而是返回 `bound: false` 且 `next_action: "request_bind"`（提示重新走绑定流程）。请按响应体的 `bound` 字段判断，而非依赖 HTTP 错误码。
</Note>

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| `Authorization` | 是 | `Bearer clw_...`（Agent 的 API Key）|
| `X-Consent-Grant-Id` | 是 | 要查询的用户授权 ID（`cg_...`）；缺失返回 `CONSENT_GRANT_REQUIRED` |

### 请求体

无请求体。这是一个 GET 请求，要查询的授权由请求头 `X-Consent-Grant-Id` 指定，无路径参数与查询参数。

### 响应

仍有效绑定时：

```json
{
  "bound": true,
  "consent_grant_id": "cg_your_consent_grant",
  "scopes": ["taobao_flash.delivery"],
  "expires_at": "2026-09-14T10:00:00+00:00",
  "next_action": null
}
```

无效 / 已过期 / 能力不匹配时（不报错，返回未绑定态）：

```json
{
  "bound": false,
  "consent_grant_id": null,
  "scopes": [],
  "expires_at": null,
  "next_action": "request_bind"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `bound` | boolean | 该 `consent_grant_id` 是否仍为有效绑定。`false` 表示无效 / 已过期 / 能力不匹配 |
| `consent_grant_id` | string \| null | 已绑定时原样回传查询所用的 `consent_grant_id`；未绑定时为 `null` |
| `scopes` | string[] | 授权覆盖的能力范围，形如 `<provider_code>.<cap_code>`（例如 `taobao_flash.delivery`）；未绑定时为空数组 |
| `expires_at` | string \| null | 授权过期时间，ISO 8601 带 UTC 时区（例如 `2026-09-14T10:00:00+00:00`）；未绑定时为 `null` |
| `next_action` | string \| null | 下一步建议动作。已绑定时为 `null`；未绑定时为 `request_bind`（提示重新走绑定流程）|

### 错误码

| HTTP | code | 说明 |
|------|------|------|
| 401 | `AUTH_REQUIRED` | 缺少 `Authorization` 头 |
| 401 | `AUTH_INVALID` | API Key 无效或已禁用 |
| 401 | `CONSENT_GRANT_REQUIRED` | 缺少 `X-Consent-Grant-Id` 头 |
| 403 | `CAP_NOT_BOUND` | 当前 Agent 未开通该能力 |

`consent_grant_id` 无效 / 已过期 / 能力不匹配**不会报错**，而是返回 `bound: false`（见上文）。完整错误码见 [错误处理](/gateway/error-handling)。

### 示例

```bash
curl "https://eleme-gateway.hicaspian.com/api/v1/auth/status" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant"
```
