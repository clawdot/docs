## GET /shops/{shop_id}

获取指定商家的详细信息和完整菜单（含规格、属性、配料信息）。

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| `Authorization` | 是 | `Bearer clw_...` |
| `X-User-Token` | 是 | 用户 Token |

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `shop_id` | string | 商家 ID（来自搜索结果的 `id` 字段），ID 类型自动检测 |

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `lat` | float | 是 | 配送位置纬度 |
| `lng` | float | 是 | 配送位置经度 |

### 店铺信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 店铺 ID（与搜索结果一致） |
| `name` | string | 店铺名称 |
| `address` | string | 店铺地址 |
| `business_hours` | string | 营业时间描述 |
| `announcement` | string | 店铺公告 |

### 菜单项字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `item_id` | string | 商品 ID（Taobao ID），**下单必需** |
| `sku_id` | string | SKU ID（Taobao ID），**下单必需** |
| `name` | string | 商品名称 |
| `price` | float | 当前价格（元） |
| `original_price` | float \| null | 原价（元），无折扣时为 null |
| `sold_count` | string | 销量文本（如 "月售 2000+"） |
| `in_stock` | boolean | 是否有货 |
| `specs` | array | 规格选项组（如杯型），下单时每组选一个值 |
| `attrs` | array | 属性选项组（如温度、糖度），下单时每组选一个值 |
| `ingredients` | array | 配料选项组（完整结构，含互斥规则） |
| `default_ingredients` | array | **预计算的默认配料选择**，可直接用于快速下单 |

### 配料互斥规则（`excludes`）

部分配料选项之间存在互斥关系。每个选项的 `excludes` 字段列出了不兼容的其他选项 ID。

**选择逻辑：**
1. 维护一个 `excluded_ids` 集合（初始为空）
2. 对每个配料组，仅展示 `id` 不在 `excluded_ids` 中的选项
3. 用户选择一个选项后，将其 `excludes` 中的所有 ID 加入 `excluded_ids`
4. 重新过滤剩余组的可选项

<Tip>
  **AI Agent 快速下单**：直接使用 `default_ingredients` 字段，无需理解配料互斥规则。详见 [商品规格说明](/gateway/item-specs)。
</Tip>

### 示例

```bash
curl -X GET "https://api.clawdot.ai/api/v1/shops/E15074238835124929109?lat=31.23&lng=121.47" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-User-Token: your_user_token"
```
