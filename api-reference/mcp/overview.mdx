## MCP Server

Clawdot Gateway 同时提供 MCP (Model Context Protocol) 接口，使用 **Streamable HTTP** 传输协议，共享与 REST API 相同的服务层。

### 连接方式

**Endpoint:**

```
https://api.clawdot.ai/mcp/mcp
```

**认证：** Bearer API Key，与 REST API 使用相同的 API Key。

```
Authorization: Bearer clw_<32位hex>
```

<Note>
  FastMCP 在 mount 路径下额外添加 `/mcp`，因此实际端点为 `/mcp/mcp`。如果通过 nginx 反代，可添加 rewrite 规则简化为 `/mcp`：

  ```nginx
  location /mcp {
      rewrite ^/mcp(/.*)?$ /mcp/mcp break;
      proxy_pass http://127.0.0.1:8000;
  }
  ```
</Note>

### 与 REST API 的区别

| 特性 | REST API | MCP |
|------|----------|-----|
| 用户认证 | Header: `X-User-Token` | 参数: `user_token` |
| 商品列表 | Body: `items`（对象数组） | 参数: `items_json`（JSON 字符串） |
| 地址 ID | Body: `address_id`（integer） | 参数: `address_id`（integer） |
| 确认下单 | `POST /orders` | tool: `confirm_order` |

### 工具列表

MCP Server 暴露 **7 个工具**：

| MCP Tool | 对应 REST API | 说明 |
|----------|---------------|------|
| `search_shops` | `GET /shops/search` | 搜索附近商家 |
| `get_shop_detail` | `GET /shops/{id}` | 商家详情和菜单 |
| `search_addresses` | `POST /addresses/search` | 搜索地址 |
| `select_address` | `POST /addresses/select` | 保存地址 |
| `preview_order` | `POST /orders/preview` | 预览订单 |
| `confirm_order` | `POST /orders` | 确认下单 |
| `get_order` | `GET /orders/{id}` | 查询订单 |

详见 [MCP 工具参考](/api-reference/mcp/tools)。
