每个 MCP 工具都需要 `user_token` 参数来标识用户身份（对应 REST API 中的 `X-User-Token` header）。

## search_shops

搜索附近外卖商家。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `lat` | float | 是 | — | 配送位置纬度 |
| `lng` | float | 是 | — | 配送位置经度 |
| `user_token` | string | 是 | — | 用户绑定 token |
| `keyword` | string | 否 | null | 搜索关键词（如 "咖啡"、"星巴克"） |
| `offset` | int | 否 | 0 | 分页偏移量 |
| `limit` | int | 否 | 20 | 每页数量 |

**返回：** 与 [`GET /shops/search`](/api-reference/shops/search) 相同的 `{"shops": [...]}` 结构。

---

## get_shop_detail

获取商家详情和完整菜单（含规格、属性、配料信息）。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shop_id` | string | 是 | 搜索结果中的 `id` |
| `lat` | float | 是 | 配送位置纬度 |
| `lng` | float | 是 | 配送位置经度 |
| `user_token` | string | 是 | 用户绑定 token |

**返回：** 与 [`GET /shops/{id}`](/api-reference/shops/detail) 相同的 `{"shop": {...}, "menu": [...]}` 结构。

每个菜单项包含 `default_ingredients` — 预计算的默认配料选择，可直接用于快速下单。

---

## search_addresses

搜索配送地址。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `user_token` | string | 是 | — | 用户绑定 token |
| `keyword` | string | 否 | `""` | 搜索关键词 |
| `lat` | float | 有 keyword 时必填 | null | 纬度 |
| `lng` | float | 有 keyword 时必填 | null | 经度 |

**返回：** 与 [`POST /addresses/search`](/api-reference/addresses/search) 相同的 `{"saved": [...], "suggestions": [...]}` 结构。

---

## select_address

保存地址建议到网关地址簿。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `source` | string | 是 | — | `"poi"` 或 `"eleme_history"` |
| `user_token` | string | 是 | — | 用户绑定 token |
| `poi_data` | dict | source=poi 时必填 | null | POI 完整对象 |
| `contact_name` | string | 否 | `""` | 收件人姓名 |
| `contact_phone` | string | 否 | `""` | 收件人电话 |
| `address` | string | 否 | `""` | 地址文本 |
| `detail` | string | 否 | `""` | 门牌号/楼层 |
| `tag` | string | 否 | `""` | 标签：home/work/school |
| `lat` | float | 否 | null | 纬度 |
| `lng` | float | 否 | null | 经度 |
| `eleme_address_id` | string | source=eleme_history 时必填 | null | 饿了么地址 ID |

**返回：** 网关地址对象，含 `id` 字段（用于 `preview_order` 的 `address_id`）。

---

## preview_order

预览外卖订单 — 获取价格明细。

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `shop_id` | string | 是 | — | 商家 ID |
| `address_id` | int | 是 | — | 网关地址 ID（来自 `select_address`） |
| `items_json` | string | 是 | — | 订单商品列表的 **JSON 字符串** |
| `lat` | float | 是 | — | 配送位置纬度 |
| `lng` | float | 是 | — | 配送位置经度 |
| `user_token` | string | 是 | — | 用户绑定 token |
| `note` | string | 否 | `""` | 备注 |

<Warning>
  MCP 版本的商品列表参数是 `items_json`（**JSON 字符串**），不是 REST API 中的 `items` 对象数组。
</Warning>

**`items_json` 格式示例（快速下单）：**

```json
[{"item_id": "670685166551", "sku_id": "5014584502270", "quantity": 1, "ingredients": [{"item_id": "...", "sku_id": "...", "package_id": "...", "buy_amount": 1}]}]
```

**返回：** 与 [`POST /orders/preview`](/api-reference/orders/preview) 相同的价格明细 + `session_id`。

---

## confirm_order

使用 `session_id` 确认下单。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | 来自 `preview_order` 的 session_id |
| `user_token` | string | 是 | 用户绑定 token |

**返回：** 与 [`POST /orders`](/api-reference/orders/create) 相同的订单创建结果。

<Note>
  MCP 中此工具命名为 `confirm_order`，对应 REST API 的 `POST /orders`。
</Note>

---

## get_order

查询订单状态和详情。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `order_id` | string | 是 | 饿了么订单号 |
| `user_token` | string | 是 | 用户绑定 token |

**返回：** 与 [`GET /orders/{id}`](/api-reference/orders/get) 相同的订单状态信息。

---

## AI Agent 快速下单流程

最简 5 步下单路径，无需理解配料互斥规则：

```
1. search_shops(lat, lng)
   → 获取 shop.id

2. get_shop_detail(shop_id, lat, lng)
   → 获取 item.item_id, item.sku_id, item.default_ingredients

3. search_addresses() → select_address(...)
   → 获取 address.id

4. preview_order(shop_id, address_id, items_json)
   → 获取 session_id（items 中使用 default_ingredients）

5. confirm_order(session_id)
   → 完成下单
```
