## POST /addresses/delete

删除用户某个已保存地址。删除后该 `address_id` 立即失效，不再出现在 `/addresses/search` 的已保存列表中。

<Note>
  **地址链路**：`/addresses/search` 搜地点得到 `suggestion_token` → `/addresses/select` 保存地址得到 `address_id` → `/addresses/update` 编辑 → **`/addresses/delete`** 删除已保存地址。
</Note>

<Note>
  **只删当前授权用户自己的地址，不影响他人**。`address_id` 按授权用户隔离，删除只会移除当前用户名下的这条保存记录。上游配送地址簿按手机号共享（一个手机号 = 一个饿了么账户），网关仅在该地址**不再被任何记录引用**时才回收上游地址，因此删除不会破坏同账户其它用途仍在使用的配送地址。
</Note>

<Note>
  **不影响已下订单**。订单在下单时已记录配送地址，删除已保存地址只影响「之后再用这个 `address_id` 下单」，不影响已经提交的订单。
</Note>

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| `Authorization` | 是 | `Bearer clw_...`（Agent 的 API Key）|
| `X-Consent-Grant-Id` | 是 | 用户授权 ID（`cg_...`）|
| `Content-Type` | 是 | `application/json` |

### 请求体

```json
{
  "address_id": "<来自 /addresses/select>"
}
```

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `address_id` | string | 是 | — | 要删除的已保存地址 ID，原样使用 `/addresses/select` / `/addresses/search` 返回的 `address_id` |

<Warning>
  请求体**不接受未定义字段**（`extra=forbid`），多传会返回 422。
</Warning>

### 响应

```json
{
  "address_id": "addr_7c1e...",
  "deleted": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `address_id` | string | 被删除的网关地址 ID（`addr_`），即入参原值 |
| `deleted` | boolean | 恒为 `true`，表示删除成功 |

### 错误码

| HTTP | code | 说明 |
|------|------|------|
| 401 | `CONSENT_GRANT_REQUIRED` | 缺少 `X-Consent-Grant-Id` |
| 401 | `CONSENT_GRANT_INVALID` | 授权 ID 无效 |
| 401 | `CONSENT_GRANT_EXPIRED` | 授权已过期，需重新授权 |
| 403 | `CAP_NOT_BOUND` | 该 Agent 未开通外卖能力 |
| 403 | `CONSENT_GRANT_WRONG_CAP` | 该授权属于其它能力 / 渠道 |
| 400 | `PUBLIC_REFERENCE_INVALID` | `address_id` 无效、过期、不属于当前授权用户，或已被删除 |

<Note>
  公开端点的 `address_id` 一律先经公共引用解析，地址不存在 / 不属于当前授权用户 / 已删除时统一返回 400 `PUBLIC_REFERENCE_INVALID`。仅在极端并发竞态下（解析通过后、内部删除前该地址恰被另一请求删除）才会出现 404 `ADDRESS_NOT_FOUND`，正常调用不会遇到。
</Note>

完整错误码见 [错误处理](/gateway/error-handling)。

### 示例

```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/addresses/delete" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "address_id": "<来自 /addresses/select>"
  }'
```
