## POST /addresses/select

将搜索建议中的地址保存到网关地址簿。返回的 `id` 可直接用于下单。

<Note>
  这是地址管理的核心操作。只有通过此接口保存的地址才能在下单时使用。
</Note>

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| `Authorization` | 是 | `Bearer clw_...` |
| `X-User-Token` | 是 | 用户 Token |
| `Content-Type` | 是 | `application/json` |

### 请求体

<Tabs>
  <Tab title="POI 来源">
    保存 POI 搜索结果中的地址：

    ```json
    {
      "source": "poi",
      "poi_data": {
        "id": "poi-123456",
        "name": "国贸大厦",
        "address": "上海市黄浦区...",
        "latitude": 31.2304,
        "longitude": 121.4737
      },
      "contact_name": "张三",
      "contact_phone": "13800138000",
      "detail": "3楼301室",
      "tag": "work"
    }
    ```
  </Tab>
  <Tab title="饿了么历史来源">
    保存饿了么历史地址：

    ```json
    {
      "source": "eleme_history",
      "eleme_address_id": "22872378801",
      "contact_name": "张三",
      "contact_phone": "13800138000",
      "address": "上海市黄浦区人民大道200号",
      "detail": "3楼301室"
    }
    ```
  </Tab>
</Tabs>

### 参数说明

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `source` | string | 是 | — | `"poi"` 或 `"eleme_history"` |
| `poi_data` | object | source=poi 时必填 | null | 搜索建议中的完整 POI 对象 |
| `eleme_address_id` | string | source=eleme_history 时必填 | null | 饿了么地址 ID |
| `contact_name` | string | 否 | `""` | 收件人姓名 |
| `contact_phone` | string | 否 | `""` | 收件人电话 |
| `address` | string | 否 | `""` | 地址文本（source=poi 时自动从 POI 填充） |
| `detail` | string | 否 | `""` | 门牌号/楼层/房间号 |
| `tag` | string | 否 | `""` | 标签：`"home"`、`"work"`、`"school"` 或空 |
| `lat` | float | 否 | null | 纬度（source=poi 时自动从 POI 填充） |
| `lng` | float | 否 | null | 经度（source=poi 时自动从 POI 填充） |

### 响应

```json
{
  "id": 1,
  "contact_name": "张三",
  "contact_phone": "13800138000",
  "address": "上海市黄浦区人民大道200号",
  "detail": "3楼301室",
  "lat": 31.2304,
  "lng": 121.4737,
  "tag": "work"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | integer | **网关地址 ID**，用于下单时的 `address_id` 参数 |

### 行为说明

- **source=poi**：先尝试复用附近 100m 内已有的饿了么地址（避免重复创建）。无匹配时调用饿了么 API 创建新地址。创建失败时放宽到 200m 查找备用地址
- **source=eleme_history**：地址已存在于饿了么，仅在网关创建映射记录
- **幂等性**：同一 agent + user + eleme_address_id 的组合不会重复创建，返回已有记录

### 完整地址流程

```
1. POST /addresses/search         → 搜索地址建议
2. POST /addresses/select          → 保存建议到网关 → 获得 id
3. POST /orders/preview            → 使用 address_id=id 预览订单
```

### 示例

```bash
curl -X POST "https://api.clawdot.ai/api/v1/addresses/select" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-User-Token: your_user_token" \
  -H "Content-Type: application/json" \
  -d '{
    "source": "poi",
    "poi_data": {"id": "poi-123", "name": "国贸大厦", "address": "上海市黄浦区...", "latitude": 31.23, "longitude": 121.47},
    "contact_name": "张三",
    "contact_phone": "13800138000",
    "detail": "3楼301室",
    "tag": "work"
  }'
```
