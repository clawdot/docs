搜商品与选规格。先挑商品，再定地址。action=search 搜商品（keyword，可带 category、brand、price_min / price_max（元）、in_stock_only、sort_by、page）；action=item 看一件商品的规格、价格与库存（ref 取自 search 的候选）；action=select 选定规格与数量（ref 取自 item 的候选，qty 默认 1）。

## 工具说明（与线上 tools/list 同源）

```text
先调 create_task 拿 task_id，再带着它调本工具。
零售第一组：先挑商品，再定地址。action=search 搜商品（keyword，可带 category、brand、price_min / price_max（元）、in_stock_only、sort_by、page）；action=item 看一件商品的规格、价格与库存（ref 取自 search 的候选）；action=select 选定规格与数量（ref 取自 item 的候选，qty 默认 1）。一笔只买一个规格：要换先 action=remove 清掉。库存显示「未知」的照实告诉用户。
```
