查单与预检取消。查单与预检取消。status / list / rider 任何时候、任何 task 里都能调，不影响这个 task 走到哪一步：action=status 查一单（不带 order_id 查本 task 这一单，带了查别的单；取消后也能查退款）；action=list 列最近跑腿单（结果不明时请用户核对）；action=rider 看骑手位置（同 status 带不带 order_id）；action=pre_cancel 预检取消：摆违约金和可退金额，出确认页，确认页那一项的 ref 就是取消用的 confirm_ref。（只读）
