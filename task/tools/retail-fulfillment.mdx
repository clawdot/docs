查单与物流。任何时候、任何 task 里都能调，不影响这个 task 走到哪一步。action=status 查一张收款单的付款与下单进度（不带 order_id 查本 task 的，带了查别的）；action=list 列最近的收款单；action=logistics 看物流（同 status 带不带 order_id，可带 sub_order_id）。（只读）

## 工具说明（与线上 tools/list 同源）

```text
先调 create_task 拿 task_id，再带着它调本工具。
零售第五组：任何时候、任何 task 里都能调，不影响这个 task 走到哪一步。action=status 查一张收款单的付款与下单进度（不带 order_id 查本 task 的，带了查别的）；action=list 列最近的收款单；action=logistics 看物流（同 status 带不带 order_id，可带 sub_order_id）。付没付只以 status 查到的为准，从支付页跳回来不算付款成功。
```

## 参数

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `task_id` | string | 是 | create_task 返回的 task_id |
