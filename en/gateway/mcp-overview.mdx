Clawdot Gateway exposes its capabilities through **MCP (Model Context Protocol)** over the **Streamable HTTP** transport. MCP exposes **18 tools** covering the full delivery flow — consent binding, addresses, shops, cart, coupons, ordering, and password-free payment.

## Quick facts

- **Connection endpoint:** `http://eleme-gateway.hicaspian.com/mcp/v1`. The gateway mounts the MCP app under `/mcp`, and FastMCP's inner route is versioned (`/v1`), so the public endpoint is `/mcp/v1`.
- **Authentication:** two-layer auth — an **API Key** (`Authorization: Bearer clw_...` header at the connection layer) identifies the Agent, and a **consent grant** (`cg_` prefix) identifies the authorized user. See [Authentication](/en/gateway/authentication).
- **Errors:** unified `{"error": {"code", "message"}}` format. See [Error Handling](/en/gateway/error-handling).

<Warning>
  `consent_grant_id` is passed as a **parameter on each MCP tool**, never in a header.
</Warning>
