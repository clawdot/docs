Alongside the REST API, Clawdot Gateway exposes an **MCP (Model Context Protocol)** interface over the **Streamable HTTP** transport, reusing the same service layer as the REST API. MCP exposes **18 tools**, each mapping to one REST endpoint; apart from `consent_grant_id`, a tool's parameters match the request body fields of its corresponding REST endpoint.

<Note>
  This page is just an entry point. For the full connection details, authentication, and ordering flow see [MCP Overview](/en/mcp/overview); for the signatures and parameters of all 18 tools see [MCP Tools Reference](/en/mcp/overview). Those two pages are the authoritative source.
</Note>

## Quick facts

- **Connection endpoint:** `http://eleme-gateway.hicaspian.com/mcp/v1`. The gateway mounts the MCP app under `/mcp`, and FastMCP's inner route is versioned (`/v1`), so the public endpoint is `/mcp/v1`.
- **Authentication:** the two-layer auth matches the REST API — an **API Key** (`Authorization: Bearer clw_...` header) identifies the Agent, and a **consent grant** (`cg_` prefix) identifies the authorized user. See [Authentication](/en/gateway/authentication).
- **Errors:** unified `{"error": {"code", "message"}}` format. See [Error Handling](/en/gateway/error-handling).

<Warning>
  `consent_grant_id` is a **parameter on each MCP tool**, not a header; the `X-Consent-Grant-Id` header is only used by the REST API.
</Warning>
