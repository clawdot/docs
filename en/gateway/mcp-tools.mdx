Clawdot Gateway exposes **18 tools** over MCP (Model Context Protocol), covering the full delivery flow — consent binding, addresses, shops, cart, coupons, ordering, and password-free payment.

<Note>
  This page is an overview only. The **complete parameters and return values for all 18 tools are authoritatively documented in the [MCP Tool Reference](/en/mcp/overview)** — this page does not duplicate field tables.
</Note>

## Integration essentials

- **Mount and endpoint:** The MCP app is mounted on the gateway via `app.mount("/mcp", create_mcp_app())`. FastMCP versions its route, so the public endpoint is `/mcp/v1`. Transport is streamable HTTP.
- **Agent identity:** Pass the API Key via the `Authorization: Bearer clw_...` header at the connection layer to identify the calling Agent.
- **User authorization:** `consent_grant_id` (`cg_` prefix) is passed as a **parameter on every tool**, never in a header.
- **Amount unit:** cents (integer).
- **Errors:** Unified `{"error": {"code", "message"}}` shape; see [Error Handling](/en/gateway/error-handling).

The auth model (API Key identifies the Agent + consent grant identifies the authorized user) is detailed in [Authentication](/en/gateway/authentication).

## Tool overview

| MCP Tool | Description |
|---|---|
| `request_user_bind` | Start user binding (SMS code / H5); needs Agent identity only |
| `verify_user_bind` | Confirm binding; mints `consent_grant_id` on success |
| `get_user_auth_status` | Query the user's authorization status |
| `revoke_user_bind` | Unbind a user; the old grant becomes invalid immediately |
| `get_homepage_url` | Get the Taobao Flash homepage URL |
| `search_addresses` | Search / list delivery addresses |
| `select_address` | Select / save a delivery address, returns `address_id` |
| `update_address` | Edit an address's detail / tag |
| `search_shops` | Search / browse merchants, returns `shop_id` + `cart_id` |
| `get_shop_menu` | Get a merchant's menu and item specs |
| `get_shop_share_url` | Get a merchant's share URL |
| `quote_cart` | Price the cart, returns `quote_id` |
| `list_coupons` | List the account's coupons |
| `preview_order` | Preview an order, returns `preview_id` + `confirmation_token` |
| `create_order` | Create an order, returns `order_id` |
| `get_order_status` | Query order status |
| `get_sign_action` | Get the password-free signing action (H5 link) |
| `get_sign_status` | Query password-free signing status |

## Ordering flow

`search_shops` returns `shop_id` + `cart_id` → `get_shop_menu` to pick items → `quote_cart` returns `quote_id` → `select_address` returns `address_id` → `preview_order` returns `preview_id` + `confirmation_token` → `create_order` returns `order_id` → `get_sign_action` completes password-free signing.

See the [MCP Tool Reference](/en/mcp/overview).
