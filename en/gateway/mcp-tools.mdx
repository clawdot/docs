Clawdot Gateway exposes **18 tools** over MCP (Model Context Protocol). Each tool maps one-to-one to a public REST endpoint, covering the full delivery flow — consent binding, addresses, shops, cart, coupons, ordering, and password-free payment.

<Note>
  This page is an overview only. The **complete parameters, return values, and endpoint mapping for all 18 tools are authoritatively documented in the [MCP Tool Reference](/en/mcp/overview)** — this page does not duplicate field tables.
</Note>

## Integration essentials

- **Mount and endpoint:** The MCP app is mounted on the gateway via `app.mount("/mcp", create_mcp_app())`. FastMCP versions its route, so the public endpoint is `/mcp/v1`. Transport is streamable HTTP.
- **Agent identity:** Same as REST — pass the API Key via the `Authorization: Bearer clw_...` header.
- **User authorization:** `consent_grant_id` (`cg_` prefix) is passed as a **parameter on every tool**, **not** the `X-Consent-Grant-Id` header (that's the REST convention).
- **Parameter parity:** Apart from `consent_grant_id`, tool parameters match the request body of the corresponding REST endpoint.
- **Amount unit:** cents (integer).
- **Errors:** Unified `{"error": {"code", "message"}}` shape; see [Error Handling](/en/gateway/error-handling).

The auth model (API Key identifies the Agent + consent grant identifies the authorized user) is detailed in [Authentication](/en/gateway/authentication).

## Ordering flow

`search_shops` returns `shop_id` + `cart_id` → `get_shop_menu` to pick items → `quote_cart` returns `quote_id` → `select_address` returns `address_id` → `preview_order` returns `preview_id` + `confirmation_token` → `create_order` returns `order_id` → `get_sign_action` completes password-free signing.

See the [MCP Tool Reference](/en/mcp/overview).
