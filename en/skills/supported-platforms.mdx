## Supported Platforms

`takeout` (the ClawDot food-delivery assistant) is an **install-and-go skill package** — install it into your Agent and your Agent gains the ability to search shops, pick dishes, place orders, and track them. It supports three platforms today:

<CardGroup cols={3}>
  <Card title="Claude Code" icon="terminal">
    Unpacked into the skills directory, with SKILL.md + scripts/takeout.py; triggered automatically by the skill description.
  </Card>

  <Card title="OpenClaw" icon="bot">
    Installs a SKILL.md that OpenClaw loads and invokes on demand.
  </Card>

  <Card title="Codex" icon="code">
    Writes an AGENTS.md at the project root for Codex to read the skill instructions.
  </Card>
</CardGroup>

<Info>
This page only covers **installing the takeout skill**. If you'd rather orchestrate the 18 low-level raw tools yourself (without the skill wrapper), see the [MCP Overview](/en/mcp/overview).
</Info>

## One-line install

The install script downloads the skill package from the latest [Release](https://github.com/clawdot/open-gateway-clawdot-skill/releases), verifies its `sha256`, and unpacks it to the right location for the current platform. The command always follows the shape `install.sh ... takeout <platform>`:

<Tabs>
  <Tab title="Claude Code">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/clawdot/open-gateway-clawdot-skill/main/install.sh | bash -s -- takeout claude-code
    ```

    - **Where it lands**: unpacked into Claude Code's skills directory.
    - **What's inside**: `SKILL.md` (the skill instructions) + `scripts/takeout.py` (the executor script).
    - **How it triggers**: Claude Code reads the skill's `description` and **triggers it automatically** when you mention ordering food, what you'd like to eat, being hungry, etc.; the skill then calls `scripts/takeout.py` to carry out each action.
  </Tab>

  <Tab title="OpenClaw">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/clawdot/open-gateway-clawdot-skill/main/install.sh | bash -s -- takeout openclaw
    ```

    - **Where it lands**: installs a `SKILL.md` to OpenClaw's skill location.
    - **How it triggers**: OpenClaw loads that `SKILL.md` and invokes the skill when needed, following its instructions.
  </Tab>

  <Tab title="Codex">
    ```bash
    # Run from the project root
    curl -fsSL https://raw.githubusercontent.com/clawdot/open-gateway-clawdot-skill/main/install.sh | bash -s -- takeout codex
    ```

    - **Where it lands**: writes an `AGENTS.md` at the project root.
    - **How it triggers**: Codex reads the skill instructions in `AGENTS.md` and invokes it on demand.
  </Tab>
</Tabs>

<Info>
The latest version is installed by default. To pin a version, append the version number to the command, e.g. `... takeout claude-code v1.0.0`.
</Info>

## Configure `.env` after installing

On all three platforms, after installing you drop a `.env` in the skill root. **The only required field is `API_KEY`** (your Agent identity, `clw_` prefix); `GATEWAY_URL` can stay at its default.

```bash
GATEWAY_URL=https://eleme-gateway.hicaspian.com   # Gateway URL (the script appends /api/v1; leave as default)
API_KEY=clw_your_api_key                          # Required: Agent identity
CONSENT_GRANT_ID=                                  # Leave empty; written back automatically after a user binds (cg_ prefix)
```

- The `clw_` **API Key** is obtained when you create an Agent and enable food-delivery in the [Console → Agents](https://console.hicaspian.com/agents).
- `CONSENT_GRANT_ID` (user consent, `cg_` prefix) **starts empty**: after a user completes a one-time SMS or H5 bind, the script writes it back into `.env` automatically. See the [Security Model](/en/skills/security-model) for the consent and binding details.

## What you can do after installing

Once installed with `API_KEY` filled in, your Agent can drive `takeout` through the full delivery chain — search shops, view menus, preview, place orders, and track delivery status. For each action's parameters, the order item model, and the success/failure signals, see the [Food-Delivery Assistant](/en/skills/takeout).

## FAQ

<details>
<summary>Do all three platforms use the same skill package?</summary>

Yes — it's the same `takeout` package; the only difference is the **adapter layer**: Claude Code uses `SKILL.md` + `scripts/takeout.py`, OpenClaw uses `SKILL.md`, and Codex uses `AGENTS.md`. The core executor script and interaction guide (GUIDE) are shared across all three.

</details>

<details>
<summary>Can I install a specific version?</summary>

Yes. By default it installs from the latest Release; append a version number to the install command to pin it, e.g. `... takeout claude-code v1.0.0`. The script downloads that version and verifies its `sha256`.

</details>

<details>
<summary>I want to call the low-level tools myself instead of using this skill package?</summary>

You can. The Gateway also exposes an MCP tool contract (18 raw tools), suitable for orchestrating the ordering chain yourself inside a custom Agent. See the [MCP Overview](/en/mcp/overview). The skill package (this page) instead wraps those actions for install-and-go use, with no wiring to assemble yourself.

</details>
