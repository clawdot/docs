## Overview

This guide will walk you through using the Clawdot Gateway to build a complete local life Agent from scratch. By following best practices and handling edge cases, you will be able to create a robust, user-friendly application.

The examples below use the **REST API**; the same capabilities are also exposed as **MCP** tools, with identical parameters except for `consent_grant_id` (an MCP tool argument, vs the `X-Consent-Grant-Id` header in REST), so you can switch as needed.

## Architecture Design

A complete local life Agent consists of the following modules:

```
┌─────────────────────────────────────────────┐
│         User Interaction Layer (Agent App)  │
│  Claude Desktop / Kimi / DingTalk / Custom  │
└────────────────────┬────────────────────────┘
                     │
┌────────────────────▼────────────────────────┐
│        Business Logic Layer (Your Code)     │
│  • User consent mgmt    • Order chain mgmt  │
│  • Local caching        • Error handling    │
└────────────────────┬────────────────────────┘
                     │
┌────────────────────▼────────────────────────┐
│     Clawdot Gateway (REST / MCP)            │
│  • Shop search      • Order preview/create  │
│  • Menu queries     • Payment sign          │
│  • Address mgmt     • Coupon management     │
└─────────────────────────────────────────────┘
```

<Info>
The Gateway provides 18 REST endpoints and 18 one-to-one MCP tools, covering exactly the same capabilities. This page demonstrates REST; the MCP tool-to-endpoint mapping is in the [MCP Overview](/en/mcp/overview).
</Info>

## Step 2: Get User Consent

Acting on user resources (search shops, place orders, query addresses, etc.) requires two-layer authentication: the API Key identifies the Agent, and the **user consent grant** identifies the authorized delivery user. After a user completes a binding flow once, you get a `consent_grant_id` (prefixed `cg_`) to use for all subsequent business calls.

Binding supports two modes: `sms` (sends a verification code to the phone) and `h5` (returns an authorization link the user logs in through). The example below uses `sms`.

### Binding Flow

```python
import requests
import os

api_key = os.getenv("CLAWDOT_API_KEY")
base_url = "http://eleme-gateway.hicaspian.com/api/v1"

# Step 2a: Initiate binding, send SMS verification code
def request_user_bind(phone: str) -> str:
    """
    Initiate SMS consent binding
    Return: bind_id (for subsequent verification)
    """
    url = f"{base_url}/auth/bind/request"
    payload = {"phone": phone, "auth_type": "sms"}
    headers = {"Authorization": f"Bearer {api_key}"}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    data = response.json()
    print(f"Code sent to {data['masked_phone']}, valid for {data['expires_in']} seconds")
    return data["bind_id"]  # Return to user, wait for code input


# Step 2b: Confirm binding, exchange for consent_grant_id
def verify_user_bind(bind_id: str, code: str) -> str:
    """
    Verify SMS code, exchange for consent_grant_id
    Return: consent_grant_id (required for subsequent API calls)
    """
    url = f"{base_url}/auth/bind/verify"
    payload = {"auth_type": "sms", "bind_id": bind_id, "code": code}
    headers = {"Authorization": f"Bearer {api_key}"}

    response = requests.post(url, json=payload, headers=headers)

    if response.status_code == 400:
        # Code invalid or expired
        raise ValueError("Code incorrect or expired, please re-request")

    response.raise_for_status()

    data = response.json()
    consent_grant_id = data["consent_grant_id"]

    # Store consent_grant_id (for subsequent API calls)
    # Recommend using secure local storage or session management
    print(f"Consent granted! Scopes: {data['scopes']}, expires_at: {data['expires_at']}")
    return consent_grant_id
```

### Complete Interactive Binding UI Flow

```python
def bind_user_interactive():
    """
    Interactive user consent (Agent conversation flow)
    """
    print("Welcome to Local Life Agent, please authorize your account")
    print("=" * 50)

    # Step 1: Get user phone number
    phone = input("Enter your phone number: ").strip()

    # Step 2: Initiate binding, send code
    try:
        bind_id = request_user_bind(phone)
    except requests.exceptions.RequestException as e:
        print(f"Binding request failed: {e}")
        return None

    # Step 3: User enters verification code
    max_attempts = 3
    for attempt in range(max_attempts):
        code = input(f"\nEnter verification code ({max_attempts - attempt} attempts left): ").strip()

        try:
            consent_grant_id = verify_user_bind(bind_id, code)
            print("\nConsent granted! You can now use local life services.")
            return consent_grant_id
        except ValueError as e:
            print(f"Verification failed: {e}")

    print("\nToo many attempts, please retry later or re-initiate binding")
    return None


# Usage example
consent_grant_id = bind_user_interactive()
if consent_grant_id:
    # Save consent_grant_id for later use
    # e.g. store to file or database
    pass
```

<Info>
The `expires_at` returned on success is the consent expiry (ISO 8601). **Re-authorization rotates the grant**: each successful binding for the same user mints a new `consent_grant_id` and immediately invalidates the old one. The `consent_grant_id` plaintext is returned only once; only a hash is stored — keep it safe. Consent can be revoked any time via `POST /auth/unbind`.
</Info>

## Step 3: Core Business Flow

Implement the complete chain from search, browse, quote, preview, to order and sign. The whole chain is **stateful**: each step's returned ID must be passed verbatim to the next — never fabricate one or mix IDs across chains.

```
search_shops → get_shop_menu → quote_cart → select_address
            → preview_order → create_order → get_sign_action
```

<Warning>
All amount fields are in **cents (integer)**, not yuan. For example `payable_price: 1500` means ¥15.00.
</Warning>

Every request below carries both auth headers:

```python
headers = {
    "Authorization": f"Bearer {api_key}",
    "X-Consent-Grant-Id": consent_grant_id,
    "Content-Type": "application/json"
}
```

### Phase 1: Search Shops

```python
def search_shops(consent_grant_id: str, keyword: str = None, address_id: str = None):
    """
    Search / browse nearby shops
    - Without keyword: browse mode, returns up to 20 nearby shops
    - With keyword: precise search (~5 shops), accepts shop name / category / item name
    """
    url = f"{base_url}/shops/search"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {"keyword": keyword, "address_id": address_id}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    shops = response.json()["shops"]
    return shops


# Usage example
shops = search_shops(consent_grant_id, keyword="iced latte", address_id="addr_...")

for shop in shops[:5]:  # Show top 5
    # Amount fields are in cents; divide by 100 for display
    print(f"""
    【{shop['name']}】
    Rating: {shop.get('rating')}⭐
    Distance: {shop.get('distance_text')}
    Delivery time: {shop.get('delivery_time_text')}
    Min order: ¥{shop['min_order_amount'] / 100:.2f} | Delivery fee: {shop.get('delivery_fee_text')}
    """)
```

Each result carries a `shop_id` and a `cart_id`: the `cart_id` already encapsulates that shop plus the delivery coordinates, and is the entry point for the later `get_shop_menu` / `quote_cart` / `preview_order` — pass it **verbatim**. Full fields in [Search Shops](/en/mcp/shops/search).

```python
def search_addresses(consent_grant_id: str, keyword: str, lat: float = None, lng: float = None):
    """
    Search address POIs (POST /addresses/search)
    Returns saved_addresses[] (already-saved) + suggestions[] (POI results with single-use token)
    """
    url = f"{base_url}/addresses/search"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {"keyword": keyword, "lat": lat, "lng": lng}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()


def select_address(consent_grant_id: str, suggestion_token: str,
                   contact_name: str, contact_phone: str, address_detail: str):
    """
    Register / select a delivery address (POST /addresses/select)
    Register using a suggestion's token from search_addresses; returns address_id
    """
    url = f"{base_url}/addresses/select"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {
        "suggestion_token": suggestion_token,
        "contact_name": contact_name,
        "contact_phone": contact_phone,
        "address_detail": address_detail,
    }

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()["address_id"]


# Usage example: address flow = search POIs for a token → register for an address_id
result = search_addresses(consent_grant_id, keyword="Optics Valley", lat=30.5, lng=114.4)

# Existing addresses can reuse saved_addresses[].address_id; register a new one otherwise
suggestion = result["suggestions"][0]
address_id = select_address(
    consent_grant_id,
    suggestion_token=suggestion["token"],
    contact_name="Zhang San",
    contact_phone="13800138000",
    address_detail="Building 3, Room 101",
)
```

The `saved_addresses[]` returned by `search_addresses` can be reused directly via their `address_id`; `suggestions[].token` is a single-use token — pass it to `select_address` to register and get an `address_id`. See [Search Addresses](/en/mcp/addresses/search) and [Select/Register Address](/en/mcp/addresses/select).

### Phase 5: Preview Order (Pre-Order Confirmation)

<Check title="Production Best Practice - Confirm Before Ordering">
Always validate and show the final price with `preview_order` before creating the order to avoid mistakes. The `preview_id` + `confirmation_token` it produces are the credentials required to actually place the order.
</Check>

```python
def preview_order(consent_grant_id: str, shop_id: str, cart_id: str,
                  address_id: str, items: list, quote_id: str = None,
                  coupon_ids: list = None, order_remark: str = ""):
    """
    Preview the order (POST /orders/preview)
    Validates shop / address / items and applies coupons; returns final price + preview_id + confirmation_token
    coupon_ids tri-state: omitted = auto-pick best; [] = no coupon; ["cpn_..."] = specific coupon
    """
    url = f"{base_url}/orders/preview"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {
        "shop_id": shop_id,
        "cart_id": cart_id,
        "address_id": address_id,
        "items": items,
        "quote_id": quote_id,
        "coupon_ids": coupon_ids,
        "order_remark": order_remark,
    }

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()
    return response.json()


# Usage example
preview = preview_order(
    consent_grant_id, "shop_...", "cart_...", address_id, items,
    quote_id=quote_id, order_remark="Leave at door, please ring bell",
)

# Amounts are in cents; divide by 100 for display
print(f"Payable: ¥{preview['price']['payable_price'] / 100:.2f}")
print(f"Delivery address: {preview['address']['address_detail']}")

preview_id = preview["preview_id"]
confirmation_token = preview["confirmation_token"]
```

`preview_id` + `confirmation_token` must be used as a pair, are produced by the same preview, and are valid for about 10 minutes. Full fields and the `coupon_ids` tri-state are in [Preview Order](/en/mcp/orders/preview).

### Phase 6: Create Order

```python
def create_order(consent_grant_id: str, preview_id: str, confirmation_token: str,
                 callback_url: str = None):
    """
    Create the order (POST /orders/create)
    Place the order with the preview_id + confirmation_token from the same preview
    """
    url = f"{base_url}/orders/create"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {
        "preview_id": preview_id,
        "confirmation_token": confirmation_token,
        "callback_url": callback_url,  # optional: payment status callback
    }

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    order = response.json()

    print(f"\n✓ Order created")
    print(f"Order ID: {order['order_id']}")
    print(f"Status: {order['status']}")

    return order


# Usage example
order = create_order(consent_grant_id, preview_id, confirmation_token)
```

This endpoint uses `confirmation_token` as the idempotency key: a token can place only one order; re-ordering requires a fresh preview for a new token. Returns `order_id`, `status`, and (when payment is needed) `payment_action`. You may pass `callback_url`; the gateway polls order status and POSTs a callback once it leaves the unpaid state — otherwise poll `get_order_status` (`GET /orders/{order_id}`) yourself. Full fields in [Create Order](/en/mcp/orders/create).

### Phase 7: Password-Free Sign

```python
def get_sign_action(consent_grant_id: str, return_url: str):
    """
    Initiate password-free payment signing (POST /payment/sign-action)
    Returns an action: when action_type=open_h5, direct the user to action_url to sign
    """
    url = f"{base_url}/payment/sign-action"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "X-Consent-Grant-Id": consent_grant_id,
        "Content-Type": "application/json"
    }
    payload = {"return_url": return_url}

    response = requests.post(url, json=payload, headers=headers)
    response.raise_for_status()

    action = response.json()["action"]
    if action["action_type"] == "open_h5":
        print(f"Open in browser to sign: {action['action_url']}")
    return action
```

Password-free signing is a prerequisite for password-free payment orders: when `action_type=open_h5`, direct the user to `action.action_url` (the H5 sign page); the browser returns to `return_url` afterwards. `none` means already signed. Then poll the result with `get_sign_status` (`GET /payment/sign-status`). Full chain and fields in [Order Flow](/en/gateway/order-flow).

## Step 4: Handle Edge Cases

Robust Agents gracefully handle edge cases and provide friendly error messages. Gateway errors return a uniform `{"error": {"code", "message"}}` structure.

### Error Handling

```python
def safe_api_call(func, *args, **kwargs):
    """
    Wrap API call, handle errors uniformly
    """
    try:
        return func(*args, **kwargs)
    except requests.exceptions.Timeout:
        print("❌ Network timeout, check connection")
        return None
    except requests.exceptions.ConnectionError:
        print("❌ Cannot connect to server, retry later")
        return None
    except requests.exceptions.HTTPError as e:
        # Gateway error body: {"error": {"code", "message"}}
        try:
            code = e.response.json()["error"]["code"]
        except Exception:
            code = None

        if code in ("AUTH_REQUIRED", "AUTH_INVALID"):
            print("❌ API Key missing or invalid, check the Authorization header")
        elif code in ("CONSENT_GRANT_INVALID", "CONSENT_GRANT_EXPIRED"):
            print("❌ User consent invalid or expired, please re-initiate binding")
        elif code == "CAP_NOT_BOUND":
            print("❌ This Agent has not enabled the capability, enable it in the Portal")
        elif code == "PUBLIC_REFERENCE_INVALID":
            print("❌ Platform ID (shop / address / order) invalid, expired, or not the user's")
        elif code in ("RATE_LIMITED", "QUOTA_EXCEEDED"):
            print("❌ Too many requests or quota exhausted, retry later")
        elif code == "ELEME_ERROR":
            print("❌ Upstream error, retry later")
        else:
            print(f"❌ API error ({e.response.status_code}): {code or e}")

        return None
    except Exception as e:
        print(f"❌ Unknown error: {e}")
        return None


# Usage
shops = safe_api_call(search_shops, consent_grant_id, keyword="milk tea", address_id=address_id)
```

```python
def get_order_with_retry(consent_grant_id: str, order_id: str, max_retries: int = 3):
    """
    Query order (GET /orders/{order_id}) with retry mechanism
    """
    for attempt in range(max_retries):
        try:
            url = f"{base_url}/orders/{order_id}"
            headers = {
                "Authorization": f"Bearer {api_key}",
                "X-Consent-Grant-Id": consent_grant_id,
            }
            response = requests.get(url, headers=headers, timeout=5)
            response.raise_for_status()
            return response.json()

        except requests.exceptions.Timeout:
            if attempt < max_retries - 1:
                print(f"Query timeout, retrying... ({attempt + 1}/{max_retries})")
            else:
                print("❌ Cannot get order info, retry later")
                return None
```

A complete local life Agent example:

```python
import os
import requests
from typing import List, Dict, Optional

class LocalLifeAgent:
    def __init__(self, api_key: str = None):
        self.api_key = api_key or os.getenv("CLAWDOT_API_KEY")
        self.base_url = "http://eleme-gateway.hicaspian.com/api/v1"
        self.consent_grant_id = None
        self.user_phone = None

    def _headers(self) -> Dict[str, str]:
        headers = {
            "Authorization": f"Bearer {self.api_key}",
            "Content-Type": "application/json",
        }
        if self.consent_grant_id:
            headers["X-Consent-Grant-Id"] = self.consent_grant_id
        return headers

    def bind_user(self, phone: str) -> bool:
        """User consent flow"""
        try:
            bind_id = self._request_bind(phone)
            code = input("Enter verification code: ")
            self.consent_grant_id = self._verify_bind(bind_id, code)
            self.user_phone = phone
            return True
        except Exception as e:
            print(f"Consent failed: {e}")
            return False

    def order(self, keyword: str, address_id: str) -> Optional[Dict]:
        """Search shops and complete the order chain"""
        if not self.consent_grant_id:
            print("Please complete user consent first")
            return None

        # 1. Search shops
        shops = self._search_shops(keyword, address_id)
        if not shops:
            print("No matching shops found")
            return None
        for i, shop in enumerate(shops[:5], 1):
            print(f"{i}. {shop['name']} - Rating {shop.get('rating')}⭐")
        shop = shops[int(input("Select shop (1-5): ")) - 1]

        # 2. Get menu, pick items (amounts in cents)
        menu = self._get_shop_menu(shop["shop_id"], shop["cart_id"])
        items = self._pick_items(menu)  # your UI collects item_id / sku_id / quantity

        # 3. Quote
        quote = self._quote_cart(shop["shop_id"], shop["cart_id"], address_id, items)

        # 4. Preview, get preview_id + confirmation_token
        preview = self._preview_order(
            shop["shop_id"], shop["cart_id"], address_id, items, quote["quote_id"],
        )
        print(f"Payable ¥{preview['price']['payable_price'] / 100:.2f}")

        # 5. Create order
        return self._create_order(preview["preview_id"], preview["confirmation_token"])

    def _request_bind(self, phone: str) -> str:
        url = f"{self.base_url}/auth/bind/request"
        headers = {"Authorization": f"Bearer {self.api_key}"}
        resp = requests.post(url, json={"phone": phone, "auth_type": "sms"}, headers=headers)
        resp.raise_for_status()
        return resp.json()["bind_id"]

    def _verify_bind(self, bind_id: str, code: str) -> str:
        url = f"{self.base_url}/auth/bind/verify"
        headers = {"Authorization": f"Bearer {self.api_key}"}
        resp = requests.post(
            url, json={"auth_type": "sms", "bind_id": bind_id, "code": code}, headers=headers
        )
        resp.raise_for_status()
        return resp.json()["consent_grant_id"]

    def _search_shops(self, keyword: str, address_id: str) -> List[Dict]:
        url = f"{self.base_url}/shops/search"
        resp = requests.post(
            url, json={"keyword": keyword, "address_id": address_id}, headers=self._headers()
        )
        return resp.json().get("shops", [])

    def _get_shop_menu(self, shop_id: str, cart_id: str) -> Dict:
        url = f"{self.base_url}/shops/menu"
        resp = requests.post(
            url, json={"shop_id": shop_id, "cart_id": cart_id}, headers=self._headers()
        )
        return resp.json()

    def _quote_cart(self, shop_id: str, cart_id: str, address_id: str, items: List[Dict]) -> Dict:
        url = f"{self.base_url}/cart/quote"
        resp = requests.post(
            url,
            json={"shop_id": shop_id, "cart_id": cart_id, "address_id": address_id, "items": items},
            headers=self._headers(),
        )
        return resp.json()

    def _preview_order(self, shop_id: str, cart_id: str, address_id: str,
                       items: List[Dict], quote_id: str) -> Dict:
        url = f"{self.base_url}/orders/preview"
        resp = requests.post(
            url,
            json={
                "shop_id": shop_id, "cart_id": cart_id, "address_id": address_id,
                "items": items, "quote_id": quote_id, "order_remark": "Please ring doorbell",
            },
            headers=self._headers(),
        )
        return resp.json()

    def _create_order(self, preview_id: str, confirmation_token: str) -> Dict:
        url = f"{self.base_url}/orders/create"
        resp = requests.post(
            url,
            json={"preview_id": preview_id, "confirmation_token": confirmation_token},
            headers=self._headers(),
        )
        return resp.json()

    def _pick_items(self, menu: Dict) -> List[Dict]:
        """Illustrative: collect item_id / sku_id / quantity from the menu (list, not a JSON string)"""
        return []
```
