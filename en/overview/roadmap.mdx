### Phase 2: This Year (Ecosystem Expansion) - 2025 Q3 ~ 2026 Q2

#### Layer 2: Skills Platform Opening

<AccordionGroup>
  <Accordion title="Skills SDK Release" defaultOpen>

    - Define interface specifications for restricted skills
    - Establish one-to-one authorization binding mechanism
    - Complete security isolation design
  </Accordion>

  <Accordion title="Personal Agent Integration">

    - Kimi Agent: Knowledge Q&A assistant integration

  </Accordion>

  <Accordion title="Skills Marketplace Building">
    - Establish skills application marketplace
    - Build skill review and listing process
    - Establish skill developer feedback mechanism
    - Support skill version management and upgrades
  </Accordion>
</AccordionGroup>

#### Layer 3: Gateway Multi-Service Expansion

<AccordionGroup>
  <Accordion title="Independent Merchant Agent Support">

    - Support merchant customization capabilities
    - Establish merchant Agent incentive system

  <Accordion title="Standard Protocol Documentation">

  <Accordion title="Scenario Expansion">

</AccordionGroup>

#### Layer 4: ISV SDK Open Source

<AccordionGroup>

## Near-term Focus (Q3-Q4 2025)

Three core tasks this quarter:

<AccordionGroup>
  <Accordion title="Multi-modal Super Agent" icon="🎤" defaultOpen>
    **Goal**: Go beyond text, support voice, images, video and other input types

    **Work items**:
    - Voice recognition and voice interaction
    - Image recognition and image-based search (photo-based merchant search, dish search)
    - Video content understanding (recommend merchants from livestream watching)
    - Multi-modal input context fusion

    **Expected benefits**:
    - Significant user experience improvement
    - Coverage of more use scenarios
    - Clear competitive advantage
  </Accordion>

  <Accordion title="Skills Platform & Authorization System" icon="🔐">
    **Goal**: Complete Skills Platform MVP, support first batch of Personal Agent integration

    **Work items**:
    - Complete Skills SDK design and initial implementation
    - Establish one-to-one authorization binding mechanism
    - Complete security isolation design review
    - Integrate Dingtalk Agent (first partner)

    **Expected benefits**:
    - Reduce developer integration barrier
    - Validate Personal Agent market demand
    - Build confidence for open ecosystem
  </Accordion>

  <Accordion title="Independent Merchant Agent Support" icon="🏪">
    **Goal**: Establish independent merchant Agent onboarding channel, serve top chain merchants

    **Work items**:
    - Define merchant Agent onboarding specification
    - Provide merchant Agent development guidelines
    - Implement pilot onboarding of 2-3 top merchants (e.g., Chagee)
    - Establish merchant support and incentive system

    **Expected benefits**:
    - Prove Gateway's merchant appeal
    - Gain endorsement from top merchants
    - Demonstration effect drives more merchant participation
  </Accordion>
</AccordionGroup>

## Technical Debt and Optimization Tasks

Beyond new feature development, we also focus on system stability and performance:

- **Performance optimization**: Optimize gateway routing, reduce P99 latency to below 500ms
- **Capacity planning**: Support infrastructure expansion for 10x user growth
- **Reliability**: Establish 99.95% availability target
- **Monitoring and alerts**: Improve distributed tracing and alert system
- **Documentation**: Update API docs, best practices, and incident handling guides
