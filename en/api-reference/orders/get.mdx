## GET /orders/{order_id}

Query the status and details of a specified order.

### Request Headers

| Name | Required | Description |
|------|------|------|
| `Authorization` | Yes | `Bearer clw_...` |
| `X-User-Token` | Yes | User Token |

### Path Parameters

| Parameter | Type | Description |
|------|------|------|
| `order_id` | string | Food delivery order ID (from create order response) |

### Response

```json
{
  "order_id": "1234567890",
  "status": "created",
  "shop_name": "Luckin Coffee (Guomao Branch)",
  "total_amount": 8.4,
  "created_at": "2026-03-23T10:15:30.123Z"
}
```

| Field | Type | Description |
|------|------|------|
| `order_id` | string | Food delivery order ID |
| `status` | string | Order status |
| `shop_name` | string | Shop name |
| `total_amount` | float | Order total |
| `created_at` | string | Creation time (ISO 8601) |

### Example

```bash
curl -X GET "https://your-gateway/api/v1/orders/1234567890" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-User-Token: your_user_token"
```
