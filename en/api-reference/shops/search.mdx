## GET /shops/search

Search food delivery shops near specified coordinates.

### Request Headers

| Name | Required | Description |
|------|------|------|
| `Authorization` | Yes | `Bearer clw_...` |
| `X-User-Token` | Yes | User Token |

### Query Parameters

| Parameter | Type | Required | Default | Description |
|------|------|------|--------|------|
| `lat` | float | Yes | — | Latitude |
| `lng` | float | Yes | — | Longitude |
| `keyword` | string | No | — | Search keyword |
| `offset` | integer | No | 0 | Pagination offset |
| `limit` | integer | No | 20 | Results per page (maximum 20) |

### Search Behavior

<Tabs>
  <Tab title="Keyword Search">
    When `keyword` is provided, performs a single precise search returning up to 5 shops.

    ```bash
    GET /shops/search?lat=39.9&lng=116.4&keyword=Starbucks
    ```
  </Tab>
  <Tab title="Default Category Search">
    When `keyword` is omitted, the system searches 10 default categories in parallel:

    > Recommended, Fast Food, Stir-fry, Western, Light Meals, Desserts, Milk Tea, Coffee, Congee, BBQ

    Results are deduplicated by `id` and return approximately 50 shops (approximately 1.3 seconds).
  </Tab>
</Tabs>

### Example

```bash
curl -X GET "https://your-gateway/api/v1/shops/search?lat=39.9&lng=116.4&keyword=coffee" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-User-Token: your_user_token"
```
