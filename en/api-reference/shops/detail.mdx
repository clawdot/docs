## POST /shops/menu

Fetches a shop's menu. Each returned item carries a gateway-minted `item_id` (plus optional `sku_id` / `option_id`); these IDs are the only valid order references for the downstream `/cart/quote`, `/orders/preview`, and `/orders/create` calls. Menus can be large (100+ items), so it supports `keyword` filtering and `limit` / `offset` paging (progressive disclosure).

<Note>
  **Order flow**: `/shops/search` → `shop_id` + `cart_id` (carries delivery coordinates) → **`/shops/menu`** to pick items and get `item_id` / `sku_id` → `/cart/quote` to price and get `quote_id` → `/addresses/select` to get `address_id` → `/orders/preview` → `preview_id` + `confirmation_token` → `/orders/create`. The menu must be based on an existing `cart_id`, and `shop_id` must match that `cart_id` (both returned by the same `/shops/search`).
</Note>

### Request Headers

| Name | Required | Description |
|------|----------|-------------|
| `Authorization` | Yes | `Bearer clw_...` (the Agent's API Key) |
| `X-Consent-Grant-Id` | Yes | User consent grant ID (`cg_...`) |
| `Content-Type` | Yes | `application/json` |

### Request Body

```json
{
  "shop_id": "<from /shops/search>",
  "cart_id": "<from /shops/search>",
  "address_id": "<from /addresses/select, optional>",
  "lat": null,
  "lng": null,
  "keyword": "latte",
  "limit": 20,
  "offset": 0
}
```

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `shop_id` | string | Yes | — | Shop ID (from `/shops/search`), passed back as-is |
| `cart_id` | string | Yes | — | Cart context ID (from `/shops/search`; carries shop & delivery coordinates) |
| `address_id` | string \| null | No | `null` | Gateway address ID (from `/addresses/select`); when provided, its coordinates resolve the delivery location |
| `lat` | float \| null | No | `null` | Delivery latitude; falls back to the coordinates carried by `cart_id` when omitted |
| `lng` | float \| null | No | `null` | Delivery longitude; falls back to the coordinates carried by `cart_id` when omitted |
| `keyword` | string \| null | No | `null` | Keyword filter, matched against item name / category / description (case-insensitive) |
| `limit` | integer \| null | No | `null` | Items per page, ≥ 1; returns all (filtered) items when omitted |
| `offset` | integer | No | `0` | Paging offset, ≥ 0; pair with the previous response's `next_offset` to page |

<Note>
  `address_id` / `lat` / `lng` resolve the delivery coordinates and are usually unnecessary: the `cart_id` already carries the coordinates from search. When all three are omitted, the `cart_id` coordinates are used.
</Note>


<Warning>
  All amount fields (`price` / `original_price` / `price_delta`) are in **cents (integer)**, not yuan. e.g. `price: 1600` means ¥16.00.
</Warning>

<Note>
  **Ingredients are per-SKU.** Ingredients are bound to a specific SKU — which ingredients are available, and their internal IDs, can differ per SKU (e.g. cup size). For multi-SKU items, **every SKU (including the default) carries its own `items[].sku_options[].ingredient_options`** — read the chosen SKU's `option_id`s from there. The top-level `items[].ingredient_options` is the default SKU's set (same `option_id`s, kept for backward compatibility); a **single-SKU item** (no `sku_options`) also carries its ingredients there. If you use one SKU's `option_id` on another SKU, the gateway maps it by (group name + option name); an ingredient that doesn't exist on the chosen SKU is rejected at `quote_cart` / `preview_order` (not at `create_order`).
</Note>

| Field | Type | Description |
|-------|------|-------------|
| `shop.shop_id` | string | Shop ID (echoes the request `shop_id`) |
| `shop.cart_id` | string | Cart context ID (echoes the request `cart_id`) |
| `shop.name` | string | Shop name |
| `shop.available` | boolean | Whether the shop is orderable (currently always `true`) |
| `categories` | array | Lightweight index of this page's items by category |
| `categories[].name` | string | Category name |
| `categories[].items` | array | Items in this category (only `item_id` + `name`) |
| `items` | array | Full item list for this page (see below) |
| `items[].item_id` | string | Item ID (`item_`), **required to order**; pass as `items[].item_id` to `/cart/quote` and `/orders/preview` |
| `items[].name` | string | Item name |
| `items[].category_name` | string \| null | Category this item belongs to |
| `items[].description` | string \| null | Item description |
| `items[].image_url` | string \| null | Item image URL |
| `items[].price` | integer | Current price (cents) |
| `items[].original_price` | integer \| null | Original price (cents); `null` when not discounted |
| `items[].available` | boolean | Whether in stock |
| `items[].unavailable_reason` | string \| null | Reason if unavailable; `"sold_out"` when out of stock, otherwise `null` |
| `items[].sku_options` | array | SKU options (e.g. cup size); pass the chosen `sku_id` as `items[].sku_id` when ordering |
| `items[].sku_options[].sku_id` | string | SKU ID (`sku_`), passed back as-is to the order `sku_id` |
| `items[].sku_options[].name` | string | SKU name (e.g. "Large") |
| `items[].sku_options[].price` | integer | Price for this SKU (cents) |
| `items[].sku_options[].available` | boolean | Whether this SKU is selectable |
| `items[].sku_options[].ingredient_options` | array | This SKU's ingredient/option choices (same fields as `items[].ingredient_options`). **Returned for every SKU** (including the default — its set shares the SAME `option_id`s as the top-level `items[].ingredient_options`). Ingredients vary by SKU (e.g. different cup sizes allow different "temperature"); use these `option_id`s when ordering this SKU. |
| `items[].ingredient_options` | array | Ingredient / option choices (e.g. temperature, sugar) = the **default SKU**'s set (same `option_id`s as that SKU's `sku_options[].ingredient_options`); also where a **single-SKU item** (no `sku_options`) carries its ingredients. For multi-SKU items, prefer reading from `sku_options[].ingredient_options` |
| `items[].ingredient_options[].option_id` | string | Option ID (`opt_`), passed back as-is to the order `items[].ingredient_option_ids` |
| `items[].ingredient_options[].group_name` | string | Option group name (e.g. "Sugar") |
| `items[].ingredient_options[].name` | string | Option name (e.g. "Standard") |
| `items[].ingredient_options[].price_delta` | integer | Surcharge for this option (cents), defaults to `0` |
| `items[].ingredient_options[].selected_by_default` | boolean | Whether this is the default option |
| `items[].ingredient_options[].available` | boolean | Whether this option is selectable |
| `total_items` | integer | Total item count after `keyword` filtering |
| `has_more` | boolean | Whether there is a next page |
| `next_offset` | integer \| null | The `offset` for the next page; `null` when `has_more` is `false` |

<Tip>
  **Progressive disclosure**: use `keyword` to narrow results, or `limit` + `offset` to page. While `has_more` is `true`, keep calling with `offset=next_offset` until `has_more` is `false`. Item IDs returned by earlier calls on the same `cart_id` stay orderable for the cart's lifetime.
</Tip>

### Error Codes

| HTTP | code | Description |
|------|------|-------------|
| 401 | `CONSENT_GRANT_REQUIRED` / `CONSENT_GRANT_INVALID` / `CONSENT_GRANT_EXPIRED` | Missing / invalid / expired consent grant (expired requires re-authorization) |
| 403 | `CAP_NOT_BOUND` / `CONSENT_GRANT_WRONG_CAP` | Capability not enabled for the agent, or grant does not match the capability |
| 400 | `PUBLIC_REFERENCE_INVALID` | `cart_id` invalid or expired, `shop_id` invalid, or `shop_id` and `cart_id` mismatch |
| 502 | `ELEME_ERROR` | Upstream menu fetch failed |

See [Error Handling](/en/gateway/error-handling) for the full list.

### Example

```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/shops/menu" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "shop_id": "<from /shops/search>",
    "cart_id": "<from /shops/search>",
    "keyword": "latte",
    "limit": 20,
    "offset": 0
  }'
```
