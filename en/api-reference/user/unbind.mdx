## POST /auth/unbind

Revokes the current user's authorization: clears the credential on the binding row so the `consent_grant_id` used for this call is invalidated immediately on both the REST and MCP surfaces. The Agent's API Key is unaffected.

<Note>
  **Authorization flow**: `/auth/bind/request` → `/auth/bind/verify` to get `consent_grant_id` → business calls → **`/auth/unbind`** to revoke. After revocation the `consent_grant_id` is invalid immediately; to act for this user again, run the bind flow (`request_user_bind` + `verify_user_bind`) to mint a NEW `consent_grant_id`. The user's saved addresses and order history are kept and become reachable again after re-binding the same phone number.
</Note>

### Request Headers

| Name | Required | Description |
|------|----------|-------------|
| `Authorization` | Yes | `Bearer clw_...` (the Agent's API Key) |
| `X-Consent-Grant-Id` | Yes | User consent grant ID (`cg_...`); this is the grant being revoked |

### Request Body

No request body. The grant to revoke is identified by the `X-Consent-Grant-Id` header.

### Response

```json
{
  "revoked": true,
  "next_action": "request_user_bind"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `revoked` | boolean | Whether the grant was revoked; always `true` |
| `next_action` | string | Suggested next action, always `request_user_bind` (start the bind flow again) |

### Error Codes

| HTTP | code | Description |
|------|------|-------------|
| 401 | `AUTH_REQUIRED` | Missing `Authorization` header |
| 401 | `AUTH_INVALID` | API Key invalid or disabled |
| 401 | `CONSENT_GRANT_REQUIRED` | Missing `X-Consent-Grant-Id` header |
| 401 | `CONSENT_GRANT_INVALID` | `consent_grant_id` invalid or no longer valid (e.g. already revoked) |
| 401 | `CONSENT_GRANT_EXPIRED` | User consent grant has expired |
| 403 | `CAP_NOT_BOUND` | The Agent has not been granted this capability |
| 403 | `CONSENT_GRANT_WRONG_CAP` | The grant belongs to a different capability / provider |

See [Error Handling](/en/gateway/error-handling) for the full list.

### Example

```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/auth/unbind" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant"
```
