## POST /auth/homepage-url

Generates a ready-to-open Eleme H5 homepage link for the consented user, wrapped as an `action` (`open_h5`). The link carries a channel JWT signed locally for the user's identity; hand it to the frontend / IM so the user can tap to land on their Eleme homepage.

<Note>
  **Dependency**: complete user binding to obtain a `consent_grant_id` first (`/auth/bind/request` → `/auth/bind/verify`). Once opened, the user's Eleme session is tied to this consent grant — the caller does not assemble any parameters. Pass the returned `action_url` to the user as-is; do not rewrite it or append query parameters.
</Note>

### Request Headers

| Name | Required | Description |
|------|----------|-------------|
| `Authorization` | Yes | `Bearer clw_...` (the Agent's API Key) |
| `X-Consent-Grant-Id` | Yes | User consent grant ID (`cg_...`) |
| `Content-Type` | No | `application/json` when a body is sent; the body may be omitted for this endpoint |

### Request Body

The body may be omitted (the whole object can be empty). There is a single optional field:

```json
{
  "scene": null
}
```

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `scene` | string \| null | No | `null` | Scene marker (placeholder). The server does not consume this value yet; sending it has no effect on the returned link |

### Response

```json
{
  "action": {
    "action_id": "act_3f9a...",
    "action_type": "open_h5",
    "action_url": "https://h5.ele.me/minisite/?from=...&opensite_source=...&jwt=...",
    "expires_at": "2026-07-16T08:30:00+00:00"
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `action` | object | Action object for the frontend to execute |
| `action.action_id` | string | Action ID (`act_`), a handle to the action context |
| `action.action_type` | string | Action type; always `open_h5` for this endpoint (open `action_url` in a browser / WebView) |
| `action.action_url` | string | The Eleme H5 homepage link to open; an empty string `""` when the user has no platform identity yet |
| `action.expires_at` | string | Action expiry (ISO 8601, UTC); valid for 30 days |

### Error Codes

| HTTP | code | Description |
|------|------|-------------|
| 401 | `AUTH_REQUIRED` | Missing `Authorization` header |
| 401 | `AUTH_INVALID` | API Key invalid or disabled |
| 401 | `CONSENT_GRANT_REQUIRED` | Missing `X-Consent-Grant-Id` header |
| 401 | `CONSENT_GRANT_INVALID` | `consent_grant_id` invalid or revoked |
| 401 | `CONSENT_GRANT_EXPIRED` | Consent grant expired |
| 403 | `CAP_NOT_BOUND` | The Agent has not enabled this capability |
| 403 | `CONSENT_GRANT_WRONG_CAP` | Consent grant belongs to another capability / provider |
| 503 | `HOMEPAGE_URL_CONFIG_MISSING` | Server missing the secret required to generate the link; contact the platform |

See [Error Handling](/en/gateway/error-handling) for the full list.

### Example

```bash
curl -X POST "https://eleme-gateway.hicaspian.com/api/v1/auth/homepage-url" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant"
```
