## POST /payment/sign-action

Starts passwordless-payment signing for the current authorized user: the gateway first checks the user's signing status, requests a signing address upstream if not yet signed, and issues an `action` that opens the signing H5 page. Already-signed users get no signing link.

<Note>
  **Signing flow**: call this endpoint to get an `action`; if `action.action_type` is `open_h5`, send the user to `action.action_url` (the H5 signing page) to complete signing, after which the browser returns to the `return_url` you provided. Then poll the result with `GET /payment/sign-status`. If `action.action_type` is `none`, the user is already signed and no page needs to be opened. Signing is a prerequisite for placing passwordless-payment orders.
</Note>

### Request Headers

| Name | Required | Description |
|------|----------|-------------|
| `Authorization` | Yes | `Bearer clw_...` (the Agent's API Key) |
| `X-Consent-Grant-Id` | Yes | User consent grant ID (`cg_...`) |
| `Content-Type` | Yes | `application/json` |

### Request Body

```json
{
  "return_url": "https://your-app.example.com/sign/callback"
}
```

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `return_url` | string | Yes | — | The URL the browser returns to after the user completes signing on the H5 page; provided by the caller and passed through to the upstream signing page as-is |

### Response

```json
{
  "action": {
    "action_id": "act_7c1d...",
    "action_type": "open_h5",
    "action_url": "https://render.alipay.com/p/s/...",
    "expires_at": "2026-06-16T08:30:00+00:00"
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `action` | object | The action to perform |
| `action.action_id` | string | Action ID (`act_` prefix), issued by the gateway, used to track this action |
| `action.action_type` | string | `open_h5` (open `action_url` to complete signing) or `none` (user already signed, no action needed) |
| `action.action_url` | string \| null | Signing H5 page URL; `null` when `action_type` is `none`. Open it in the browser/WebView as-is; do not rewrite it |
| `action.expires_at` | string | Action expiry time (ISO 8601, UTC); valid for 30 minutes, after which you must start again |

### Error Codes

| HTTP | code | Description |
|------|------|-------------|
| 401 | `CONSENT_GRANT_REQUIRED` / `CONSENT_GRANT_INVALID` / `CONSENT_GRANT_EXPIRED` | Missing, invalid, or expired consent grant; an expired grant requires re-authorization |
| 403 | `CAP_NOT_BOUND` / `CONSENT_GRANT_WRONG_CAP` | Agent lacks the capability, or the grant belongs to a different capability / provider |
| 502 | `ELEME_ERROR` | Taobao Instant Commerce / Ele.me upstream API error |
| 502 | `SIGN_ADDRESS_NOT_FOUND` | Upstream response did not return a signing address |
| 503 | `PROVIDER_NOT_AVAILABLE` | Provider adapter temporarily unavailable |

See [Error Handling](/en/gateway/error-handling) for the full list.

### Example

```bash
curl -X POST "https://api.clawdot.ai/api/v1/payment/sign-action" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "return_url": "https://your-app.example.com/sign/callback"
  }'
```
