## POST /addresses/search

Lists the consenting user's gateway-saved delivery addresses (`saved_addresses`) and, when a `keyword` is given, returns POI candidate addresses (`suggestions`). When `lat`/`lng` are passed, each saved address is annotated with `distance_meters` and the closest one's ID is surfaced at the top level as `nearest_address_id`.

<Note>
  **Position in the order flow**: the `address_id` (a saved address) or `suggestions[].token` (a POI candidate) returned here feeds the next step, `/addresses/select`, which returns the canonical `address_id` used by `/orders/preview` and `/orders/create`.
</Note>

### Request Headers

| Name | Required | Description |
|------|----------|-------------|
| `Authorization` | Yes | `Bearer clw_...` (the Agent's API Key) |
| `X-Consent-Grant-Id` | Yes | User consent grant ID (`cg_...`) |
| `Content-Type` | Yes | `application/json` |

### Request Body

```json
{
  "keyword": "光谷世界城",
  "lat": 30.5,
  "lng": 114.4,
  "city": "武汉"
}
```

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `keyword` | string \| null | No | `null` | POI search keyword; omit to only list saved addresses (no `suggestions` returned) |
| `lat` | number \| null | No | `null` | User latitude (GCJ-02); enables `distance_meters` and `nearest_address_id`, and biases POI search |
| `lng` | number \| null | No | `null` | User longitude (GCJ-02) |
| `city` | string \| null | No | `null` | City name to scope POI search; when provided it wins over `lat`/`lng` for the search scope |

<Note>
  All fields are optional. POI `suggestions` are returned only when both a `keyword` and a scope signal (a `lat`+`lng` pair, or a resolvable `city`) are present; otherwise `suggestions` is an empty array and only `saved_addresses` is returned.
</Note>

### Response

```json
{
  "saved_addresses": [
    {
      "address_id": "addr_8f3c...",
      "display_name": "武汉市洪山区光谷世界城",
      "address_detail": "Building 3, Room 101",
      "city": "",
      "lat": 30.5,
      "lng": 114.4,
      "contact_name": "张三",
      "contact_phone_masked": "138****8000",
      "distance_meters": 120
    }
  ],
  "suggestions": [
    {
      "token": "sug_1a2b...",
      "display_name": "光谷世界城",
      "address": "武汉市洪山区珞喻路",
      "city": "",
      "lat": 30.5,
      "lng": 114.4
    }
  ],
  "nearest_address_id": "addr_8f3c..."
}
```

| Field | Type | Description |
|-------|------|-------------|
| `saved_addresses` | array | Saved addresses, ordered most-recently-used first |
| `saved_addresses[].address_id` | string | Gateway address ID (`addr_` prefix); pass as-is to `/addresses/select` or `/orders/preview` |
| `saved_addresses[].display_name` | string | Address display name |
| `saved_addresses[].address_detail` | string | Door number / floor details |
| `saved_addresses[].city` | string | City (currently always an empty string) |
| `saved_addresses[].lat` | number \| null | Latitude (GCJ-02) |
| `saved_addresses[].lng` | number \| null | Longitude (GCJ-02) |
| `saved_addresses[].contact_name` | string \| null | Recipient name |
| `saved_addresses[].contact_phone_masked` | string | Recipient phone, masked (e.g. `138****8000`) |
| `saved_addresses[].distance_meters` | integer \| null | Distance from the request `lat`/`lng` (meters, integer); `null` when no coords were sent or the address has no coords |
| `suggestions` | array | POI candidate addresses; non-empty only when `keyword` is given and a scope is resolvable |
| `suggestions[].token` | string | Single-use suggestion token; pass to `/addresses/select` as `suggestion_token` to materialise it into a saved address |
| `suggestions[].display_name` | string | POI name |
| `suggestions[].address` | string | POI full address text |
| `suggestions[].city` | string | City (currently always an empty string) |
| `suggestions[].lat` | number \| null | POI latitude (GCJ-02) |
| `suggestions[].lng` | number \| null | POI longitude (GCJ-02) |
| `nearest_address_id` | string \| null | ID of the saved address closest to the request coords; `null` when no coords were sent or no address is comparable |

<Warning>
  Always sanity-check the chosen address's `distance_meters` before using `nearest_address_id`: if even the nearest is far away (e.g. tens of km — all saved addresses are in another city), do not auto-pick; ask the user or search a new address by `keyword` instead.
</Warning>

### Error Codes

| HTTP | code | Description |
|------|------|-------------|
| 401 | `CONSENT_GRANT_REQUIRED` / `CONSENT_GRANT_INVALID` / `CONSENT_GRANT_EXPIRED` | Missing, invalid, or expired consent grant |
| 403 | `CAP_NOT_BOUND` / `CONSENT_GRANT_WRONG_CAP` | Agent lacks the capability, or the grant does not match the capability |
| 422 | — | Invalid request body field types (e.g. non-numeric `lat`/`lng`) |

See [Error Handling](/en/gateway/error-handling) for the full list.

### Example

```bash
curl -X POST "http://eleme-gateway.hicaspian.com/api/v1/addresses/search" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-Consent-Grant-Id: cg_your_consent_grant" \
  -H "Content-Type: application/json" \
  -d '{
    "keyword": "光谷世界城",
    "lat": 30.5,
    "lng": 114.4,
    "city": "武汉"
  }'
```
