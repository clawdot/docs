## POST /addresses/search

Search for points of interest (POIs) near specified coordinates for creating delivery addresses.

### Request Headers

| Name | Required | Description |
|------|------|------|
| `Authorization` | Yes | `Bearer clw_...` |
| `X-User-Token` | Yes | User Token |
| `Content-Type` | Yes | `application/json` |

### Request Body

```json
{
  "lat": 39.9,
  "lng": 116.4,
  "keyword": "Guomao Tower"
}
```

| Field | Type | Required | Description |
|------|------|------|------|
| `lat` | float | Yes | Latitude |
| `lng` | float | Yes | Longitude |
| `keyword` | string | Yes | Search keyword |

### Response

```json
{
  "pois": [
    {
      "id": "poi-123456",
      "name": "Guomao Tower",
      "address": "1 Jianguo Men Wai Avenue, Chaoyang District, Beijing",
      "latitude": 39.9087,
      "longitude": 116.4549,
      "city": "Beijing",
      "district": "Chaoyang District"
    }
  ]
}
```

### Notes

After searching for a POI, follow these steps:

1. Call [Select POI](/api-reference/addresses/select) to save the selection
2. Call [Create Address](/api-reference/addresses/create) to fill in recipient information

### Example

```bash
curl -X POST "https://your-gateway/api/v1/addresses/search" \
  -H "Authorization: Bearer clw_your_api_key" \
  -H "X-User-Token: your_user_token" \
  -H "Content-Type: application/json" \
  -d '{"lat": 39.9, "lng": 116.4, "keyword": "Guomao Tower"}'
```
