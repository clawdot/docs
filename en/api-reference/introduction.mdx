## Base URL

```
https://your-gateway/api/v1
```

## Authentication

All endpoints (except Agent registration) require API Key authentication. Most business endpoints also require a User Token.

```bash
# API Key authentication
Authorization: Bearer clw_your_api_key

# User Token authentication (required for business endpoints)
X-User-Token: your_user_token
```

See [Authentication Mechanism](/gateway/authentication) for details.

## Unified Error Format

```json
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error description"
  }
}
```

See [Error Handling](/gateway/error-handling) for details.

## Rate Limiting

| Operation | Limit |
|------|------|
| Place order (`POST /orders`) | 10 requests/minute/Agent |
| Other endpoints | 60 requests/minute/Agent |
| SMS sending | 60 second cooldown/phone number |

Exceeding limits returns `429` status code and `RATE_LIMITED` error code.
