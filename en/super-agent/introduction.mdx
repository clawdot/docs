## What is Super Agent?

Super Agent is a C-facing product built by Clawdot for consumer users. It is not a general chatbot, but a **truly action-oriented intelligent assistant**.

Each Super Agent instance is an independent network node, exclusively serving one user:

## Full-Featured Skills · One-to-Many

Super Agent has **full-featured skills** —— each instance is equipped with a complete capability matrix:

| Capability | Status | Description |
|------|------|------|
| 🍽️ Food Delivery | ✅ Live | Search merchants, browse menu, smart ordering, order tracking |
| 📅 Shop Reservation | 🔜 Coming Soon | Search reservation slots, select time, confirm reservation |
| 🚗 Ride-hailing | 🔜 Coming Soon | Location identification, route planning, ride service |
| ✨ Recommendations | 🔜 Coming Soon | AI-powered recommendations based on user preferences |
| 💬 Social Memory | 🔜 Coming Soon | Remember user habits, taste preferences, common addresses |

The one-to-many relationship is embodied in: each Super Agent can connect to multiple food delivery platforms, reservation systems, and ride services.
